# 5.3.1a 理解财务报表

> 本文件覆盖 5.3.1「读懂会计报表」的第一个四级节点 5.3.1.1。会计数字怎样调整成"真实盈利"，从 5.3.1.2 接着讲。

> **本节新教**：三张表及勾稽（资产负债表、利润表、现金流量表的结构与中国准则下的科目，三表之间的勾稽关系）；资产的会计计量（历史成本、折旧方法、坏账准备、存货计价、金融资产分类、权益法与合并、无形资产与商誉）；负债与权益的会计计量（负债确认条件、经营性负债、债务的账面值与市场值、租赁、养老金与递延所得税、股东权益）；收入确认与费用配比、扣非净利润（定义）；盈利能力比率（利润率 / ROA / ROE，含杜邦分解和杠杆公式）；风险比率（或有负债、流动比率与速动比率、周转天数与现金转换周期、利息保障倍数与负债率）；会计准则差异
> **调用前文**：机会资本成本与 WACC 的直觉、ROIC 的经济含义、经济利润、净投资与 FCF、价值守恒与"金融工程"（5.2.1）；年金现值系数（5.1.2.1）；高 ROIC 的来源（5.2.2.2–5.2.2.5，只作指引）
> **在估值流程中的位置**：5.1.1.5 第 2 步（重组财务报表）的前置功课。重组之前，你得先读懂原始报表上每一行是什么、怎么计量的；第 3 步（分析历史 ROIC、增长和现金流）要用的基础比率，也在这里定义。

5.2.1 讲价值创造时，所有数字都是现成的：投入资本 660 万元、税后经营利润 112.5 万元，一张小表就列清楚了。可你真正拿到的是一份两三百页的年报：合并资产负债表四五十行，利润表二十多行，现金流量表三十多行，后面还有上百页附注。估值所需的每一个数字都藏在这些表里，但没有一个是直接写好的。

这一节先不急着调整，只做一件事：**弄清楚会计是怎样记账的**。会计报表回答的是四个问题：公司有哪些资产、值多少？这些资产是谁出钱买的？它们赚了多少钱？赚钱的过程中有多大风险？会计对这四个问题都有自己的答法，而且答法里有一套固定的习惯：相信历史成本，不信任市场价值，宁可低估也不高估。估值要回答的是同样四个问题，只是眼光朝前看。两者之间的距离，就是后面 5.3.1.2 和 5.3.2 要做的调整。

所以读懂报表有两层。第一层是知道每个科目**记的是什么、按什么规则记**；第二层是知道这个规则**在哪里会偏离经济现实**。本节两层都讲，但第二层只点出问题，怎么调整留给后面的章节。

## 本节的例子：青禾厨具（设想）

为了让三张表从一笔笔交易里"长"出来，先构造一家很小的公司。**这是虚构的公司，所有数字都是为教学设计的**，单位为万元，不考虑增值税。

青禾厨具外购半成品，组装成锅具，卖给各地经销商。2025 年初它的资产负债表如下。

**表 1　青禾厨具 2025 年初资产负债表（万元）**

| 资产 | 金额 | 负债和股东权益 | 金额 |
|---|---|---|---|
| 货币资金 | 100 | 应付账款 | 60 |
| 应收账款 | 80 | 合同负债（经销商预付货款） | 20 |
| 存货 | 120 | 短期借款 | 100 |
| 固定资产（原值 500，累计折旧 100） | 400 | 长期借款 | 120 |
| | | 股本及资本公积 | 200 |
| | | 未分配利润 | 200 |
| **资产合计** | **700** | **负债和股东权益合计** | **700** |

2025 年它做了这些事：

1. **卖货**：确认营业收入 1000。年末应收账款升到 100（多赊出去 20）；经销商为了抢旺季备货，年末预付款升到 30（多预收了 10）。
2. **进货**：营业成本 600。年末存货升到 140，所以全年采购了 $600 + 20 = 620$。年末应付账款升到 70（多欠供应商 10）。
3. **费用**：销售和管理费用 230，其中 50 是厂房设备折旧，另外 180 是工资、运费、广告等，用现金付清。
4. **利息**：短期借款利率 4%，长期借款利率 5%，利息 $100 \times 4\% + 120 \times 5\% = 10$，现金支付。
5. **纳税**：所得税税率 25%，全年所得税 40，当年交清。
6. **投资**：买新设备 150，现金支付。
7. **还款与分红**：提前还长期借款 20；给股东分红 40。

下面三个四级小节都用这家公司。

## 5.3.1.1.1 三张基本会计报表

三张表各回答一个问题。**资产负债表**是一张照片：某一天，公司拥有什么、欠别人什么、剩下多少归股东。**利润表**是一段录像：一段时期里，公司卖了多少、花了多少、赚了多少。**现金流量表**也是一段录像，但只盯着现金：钱从哪里来、花到哪里去。

A股的年报其实有四张主表，第四张是**所有者权益变动表**，它把股东权益从年初到年末的每一笔变化（净利润、分红、增发、回购、其他综合收益）列出来。另外，A股年报会同时给出**合并报表**和**母公司报表**。估值几乎只用合并报表：母公司报表只反映上市公司这个法人本身，子公司在里面只是一笔"长期股权投资"，子公司的收入和利润都看不到。初学者最常见的错误之一，就是拿母公司报表的数字去算指标。

### 5.3.1.1.1.1 资产负债表：公司拥有多少资源、由谁提供资本

资产负债表只有一个等式：

$$
\text{资产} = \text{负债} + \text{所有者权益}
$$

左边是公司**拿钱买了什么**，右边是**这些钱是谁出的**。出钱的人分两类：债权人（负债）和股东（所有者权益）。这正是 5.2.1.1 里 WACC（加权平均资本成本）的两类出资人；只不过会计把供应商、客户、员工这些"不收利息的出资人"也算进了负债。

中国准则下的资产负债表按**流动性**排列：一年内能变现或耗用的列为流动资产，否则列为非流动资产；一年内要偿还的列为流动负债，否则列为非流动负债。常见科目如下：

| 区域 | 常见科目 | 它们是什么 |
|---|---|---|
| 流动资产 | 货币资金、交易性金融资产、应收票据、应收账款、应收款项融资、预付款项、其他应收款、存货、合同资产 | 现金、短期投资、客户欠的钱、预付给供应商的钱、库存 |
| 非流动资产 | 债权投资、其他权益工具投资、长期股权投资、投资性房地产、固定资产、在建工程、使用权资产、无形资产、开发支出、商誉、长期待摊费用、递延所得税资产 | 长期投资、厂房设备、租入资产、土地使用权和专利、并购溢价等 |
| 流动负债 | 短期借款、应付票据、应付账款、合同负债、应付职工薪酬、应交税费、其他应付款、一年内到期的非流动负债 | 短期借款，以及欠供应商、客户、员工、政府的钱 |
| 非流动负债 | 长期借款、应付债券、租赁负债、长期应付款、预计负债、递延所得税负债 | 长期借款和债券、租赁义务、或有义务、递延的税 |
| 所有者权益 | 股本、其他权益工具、资本公积、库存股、其他综合收益、盈余公积、未分配利润；少数股东权益 | 股东投入的钱、累积的利润，以及子公司其他股东的份额 |

两个读表习惯值得早点养成。第一，**按"谁出的钱"重新看右边**。青禾年初的负债和权益合计 700，其中应付账款 60、合同负债 20 是供应商和经销商垫的，不收利息；短期借款和长期借款共 220 是付息的；股东的钱是 400。5.2.1.1 已经说过，不付息的经营负债可以从投入资本里扣掉。青禾年初的投入资本是：

$$
\underbrace{80 + 120 + 400}_{\text{经营资产}} - \underbrace{(60 + 20)}_{\text{经营负债}} = 520
$$

它和"付息债务 + 股东权益 − 现金"$= 220 + 400 - 100 = 520$ 完全相等，一个从资产端算，一个从资金来源端算。（这里把 100 的现金全部当成经营不需要的富余现金。哪些现金算经营需要、哪些负债算经营、哪些算融资，判断规则见 5.3.2.1–5.3.2.2。）

第二，**资产负债表上的数字大多是历史成本，不是今天的价值**。青禾的固定资产写着 400，意思是"当初花了 500，已经按规则折旧掉了 100"，而不是"今天能卖 400"。股东权益 400 也只是股东投入加累积留存利润的会计记录，和公司市值没有关系。这一点在 5.3.1.1.2 和 5.3.1.1.3 展开。

### 5.3.1.1.1.2 利润表：一段时期赚了多少钱、利润从哪里来

利润表从收入开始，一层层扣费用，最后得到净利润。中国准则下它的结构是固定的：

| 层次 | 项目 | 说明 |
|---|---|---|
| | **营业收入** | |
| 减 | 营业成本、税金及附加 | 卖出产品的成本；消费税、城建税等 |
| 减 | 销售费用、管理费用、研发费用 | 三项期间费用；折旧和摊销分散在营业成本和这些费用里，没有单独一行 |
| 减 | 财务费用 | **利息费用减去利息收入**的净额，有时为负 |
| 加 | 其他收益 | 主要是政府补助 |
| 加 | 投资收益 | 理财收益、联营合营企业的利润份额、卖出投资的收益 |
| 加 | 公允价值变动收益 | 按市值计量的金融资产的涨跌 |
| 减 | 信用减值损失、资产减值损失 | 应收账款坏账；存货、固定资产、商誉等的减值 |
| 加 | 资产处置收益 | 卖固定资产等的盈亏 |
| = | **营业利润** | |
| 加减 | 营业外收入、营业外支出 | 罚款、捐赠、非常损失等 |
| = | **利润总额** | |
| 减 | 所得税费用 | 当期应交税 + 递延所得税 |
| = | **净利润** | 再分为持续经营 / 终止经营净利润，以及归属于母公司股东 / 少数股东的部分 |
| | 其他综合收益、综合收益总额、每股收益 | |

有一点必须先说清：**中国报表上的"营业利润"不是经营利润**。它已经扣了利息（财务费用），又加进了理财收益、政府补助、金融资产涨跌和联营企业的利润。估值需要的经营利润是 EBIT（息税前利润），即只由主营业务产生、扣利息之前的利润。它得自己算。青禾 2025 年的利润表：

**表 2　青禾厨具 2025 年利润表（万元）**

| 项目 | 金额 |
|---|---|
| 营业收入 | 1000 |
| 减：营业成本 | (600) |
| **毛利** | **400** |
| 减：销售和管理费用（含折旧 50） | (230) |
| **EBIT（息税前利润）** | **170** |
| 减：财务费用（利息） | (10) |
| **营业利润 = 利润总额** | **160** |
| 减：所得税费用（25%） | (40) |
| **净利润** | **120** |

青禾没有理财、补贴和投资，所以 EBIT 就是营业利润加回财务费用。真实公司要多走几步：从营业利润出发，加回财务费用，再减掉投资收益、公允价值变动收益、其他收益中与主业无关的部分，才接近 EBIT。完整的做法和税的调整见 5.3.2.3。

利润表的数字是按**权责发生制**记的：货卖出去就算收入，不管钱收没收到；费用跟着收入走，不管钱付没付出去（规则见 5.3.1.1.4.1）。所以利润 120 并不等于青禾这一年多了 120 的现金。差多少，要看第三张表。

### 5.3.1.1.1.3 现金流量表：利润怎样变成现金

现金流量表把一年的现金进出分成三类：

| 类别 | 记什么 | 青禾 2025 |
|---|---|---|
| **经营活动** | 卖货收的钱、买货付的钱、工资、税费 | 收到经销商 990，付供应商 610，付费用 180，交税 40，净额 **+160** |
| **投资活动** | 买卖固定资产、无形资产、子公司，买卖理财和股权投资，收到的利息和投资分红 | 买设备 **−150** |
| **筹资活动** | 借款和还款、发股和回购、分红、**支付利息**、偿还租赁负债 | 还款 −20、付利息 −10、分红 −40，净额 **−70** |
| **现金净变动** | | $160 - 150 - 70 = -60$ |

经营活动的几个数是这样来的。收到经销商的钱 = 收入 1000 − 应收增加 20 + 预收增加 10 = 990：多赊出去的 20 还没收回，多预收的 10 却已经进账。付给供应商的钱 = 采购 620 − 应付增加 10 = 610。

中国准则要求主表用**直接法**列示经营现金流，就是上面这种"收了多少、付了多少"的写法；附注里的"补充资料"再用**间接法**，从净利润倒推出经营现金流。间接法更能看出利润和现金的差别在哪里：

| 从净利润到经营现金流 | 金额 | 为什么 |
|---|---|---|
| 净利润 | 120 | |
| 加：折旧 | 50 | 折旧是费用，但这一年没有付现金（现金在买设备时就付了） |
| 加：财务费用 | 10 | 利息是付了现金的，但中国准则把它算在筹资活动里，所以先从经营里加回来 |
| 减：应收账款增加 | (20) | 收入记了，钱没收到 |
| 减：存货增加 | (20) | 买了货付了钱（或欠了钱），但还没卖出去，没进营业成本 |
| 加：应付账款增加 | 10 | 进了货，钱还欠着 |
| 加：合同负债增加 | 10 | 钱收了，货还没发 |
| **经营活动现金流** | **160** | 与直接法相同 |

有几处分类规则会影响你对数字的理解：

- **利息放在哪里，各准则不同。** 中国准则下，支付的利息算筹资活动；收到的投资利息和分红通常列投资活动，但银行存款利息不少公司列在经营活动（"收到其他与经营活动有关的现金"）。国际准则（港股多用）目前允许公司在经营和筹资之间选择，有的港股公司把付息放在经营活动里（2027 年起 IFRS 18 生效后，一般企业须统一列入筹资活动）。拿两家公司比"经营现金流"之前，先看利息放在了哪一类。
- **"现金及现金等价物"不等于货币资金。** 被冻结的存款、票据保证金这些受限资金不算现金；期限超过三个月的定期存款、多数银行理财也不算。所以现金流量表上的期末现金，常常小于资产负债表上的货币资金。
- **新租赁准则让经营现金流变大了。** 租金的本金和利息都改记到筹资活动（见 5.3.1.1.3.4），租赁多的零售、餐饮公司，经营现金流因此显著上升，但生意本身没有任何变化。

青禾这一年的利润是 120，现金却**少了** 60。原因一目了然：经营本身带来了 160 的现金（比利润还多，主要靠折旧加回），但买设备花了 150，还款、付息、分红又花了 70。经营活动现金流减去资本开支，$160 - 150 = 10$，是对"自由现金流"最粗糙的估计。它不精确（没扣税后利息的调整，也没区分维持性和扩张性开支），严格的推导见 5.3.2.4；直觉版在 5.2.1.2 已经讲过：自由现金流是经营赚的钱扣掉再投资之后，剩给出资人的部分。

### 5.3.1.1.1.4 三张表之间的基本勾稽关系

三张表是同一套账的三个视角，彼此必须对得上。走完 2025 年，青禾的年末资产负债表是：

**表 3　青禾厨具 2025 年末资产负债表（万元）**

| 资产 | 年初 | 年末 | 负债和股东权益 | 年初 | 年末 |
|---|---|---|---|---|---|
| 货币资金 | 100 | 40 | 应付账款 | 60 | 70 |
| 应收账款 | 80 | 100 | 合同负债 | 20 | 30 |
| 存货 | 120 | 140 | 短期借款 | 100 | 100 |
| 固定资产净值 | 400 | 500 | 长期借款 | 120 | 100 |
| | | | 股本及资本公积 | 200 | 200 |
| | | | 未分配利润 | 200 | 280 |

| 勾稽关系 | 青禾的核对 |
|---|---|
| ① 现金：期初现金 + 现金流量表净变动 = 期末现金 | $100 - 60 = 40$ ✓ |
| ② 留存利润：期初未分配利润 + 净利润 − 分红 = 期末未分配利润 | $200 + 120 - 40 = 280$ ✓ |

| ④ 营运资本：资产负债表上应收、存货、应付、合同负债的变动，就是间接法里的那几行调整 | $-20 - 20 + 10 + 10 = -20$ ✓ |
| ⑤ 债务和股本：期初借款 + 新借 − 偿还 = 期末借款；股本变动对应筹资活动的发股或回购 | $220 - 20 = 200$ ✓ |

这五根线有一个合起来的说法：**资产负债表上每一行从年初到年末的变化，要么来自利润表，要么来自现金流量表，要么两者都有。** 把青禾的每一行列出来，就是一张"变动解释表"：

| 科目 | 年初 | 来自利润表 | 来自现金流量表 | 年末 |
|---|---|---|---|---|
| 货币资金 | 100 | | 经营 +160，投资 −150，筹资 −70 | 40 |
| 应收账款 | 80 | 收入 +1000 | 收款 −980（不含预收的 10） | 100 |
| 存货 | 120 | 结转营业成本 −600 | 采购 +620（其中 10 还欠着） | 140 |
| 固定资产 | 400 | 折旧 −50 | 买设备 +150 | 500 |
| 合同负债 | 20 | | 净增预收 +10 | 30 |
| 未分配利润 | 200 | 净利润 +120 | 分红 −40 | 280 |

勾稽关系对估值有三个实际用处。

**第一，检查数据。** 你从数据库下载的数字、自己录入的数字，只要有一根线对不上，一定有地方出错了。做预测模型时更是如此：资产负债表配不平，十有八九是某根线断了（5.4.2.10）。

**第二，发现会计问题。** 真实公司的线常常对不上，原因多半在附注里：固定资产除了资本开支和折旧，还有减值、处置、并购带入、汇率变动；应收账款的变动和经营现金流里的"经营性应收项目增加"对不上，可能是有一部分应收被保理或者用票据结算，没有经过现金。对不上的地方，往往就是最值得追问的地方。

**第三，看利润的含金量。** 线②和线④合起来说的是：利润只有经过营运资本这一关，才能变成现金。连续几年净利润远大于经营现金流，差额主要堆在应收账款和存货上，说明利润很大一部分还"挂在账上"，没有收回来。这是 A股财务造假案例里出现频率最高的特征之一（康得新等事件中出现过利润与现金长期背离；康美药业的问题则主要是货币资金虚增，即现金真实性存疑，两类情况常常相伴出现）。反过来，经营现金流长期大于净利润，可能是因为折旧多（重资产公司），也可能是因为对上下游占款多（预收多、应付多），后者往往是议价能力强的表现。

> **投资者怎么用**：拿到一家公司，先算三个数，看五年：净利润、经营活动现金流、资本开支。经营现金流 ÷ 净利润长期低于 1，要找出差额堆在了哪个科目；经营现金流 − 资本开支长期为负，要问钱是靠借款还是增发补上的、投下去的钱有没有回报。这三行数字花不了十分钟，却能筛掉相当一部分问题公司。

## 5.3.1.1.2 资产的衡量与估价

会计对资产的定义很宽：凡是能在未来带来现金流入或减少现金流出的资源都是资产。但它加了两个限制：资产必须是**过去的交易**形成的，未来的收益必须能**比较可靠地计量**。就这两条限制，已经把公司自己培育的品牌、积累的技术、建立的客户关系挡在了资产负债表外面。

在怎么给资产定价上，会计有三条贯穿始终的习惯：

1. **相信账面价值。** 资产按买入时的成本入账，此后只做两类调整：加上后续改良，减去损耗（折旧、摊销、减值）。这个调整后的历史成本就是"账面价值"。
2. **不信任市场价值和估算价值。** 市价波动大、容易被操纵；用未来现金流估出来的价值更主观。所以除非有充分理由，会计不用它们。
3. **宁可低估，不要高估。** 有两个数可选时，取较低的那个。存货按"成本与可变现净值孰低"，资产只减值、不增值，都是这条原则。

这三条习惯让会计报表在资产上表现出一种不对称：**给资产分类做得很好，给资产估值做得一般，反映资产的不确定性做得很差。** 它还告诉你另一件事：会计报表记录的几乎全是**已经投下去的资产**（现有资产），对公司**将来要做的投资**（增长资产）几乎什么都没说。而对一家高增长公司来说，后者可能占了价值的大头。估值就是要把这两部分都看到。

### 5.3.1.1.2.1 历史成本、折旧与账面价值

历史成本的好处是客观：发票、合同、银行流水都可以核对。代价是它会随着时间越来越偏离经济现实，偏离的方向有两种。

**账面价值远低于经济价值。** 一家 1990 年代在城市中心拿到土地的老字号企业，土地使用权按当年的成本入账、还在逐年摊销，今天的账面价值可能只是市价的零头。一家白酒企业窖藏多年的基酒，按生产成本记在存货里，而它的售价往往是成本的许多倍。一家医药企业自己研发成功的药品专利，研发支出早已费用化，资产负债表上根本没有。

**账面价值高于经济价值。** 一条产能过剩行业里的生产线，按成本扣折旧后仍挂着 10 亿元，但它产生的现金流已经撑不起这个数。会计用**减值测试**来处理这种情况：当资产的可收回金额（公允价值减处置费用，与未来现金流现值，两者取高）低于账面价值时，把差额计入资产减值损失。问题在于，减值测试的输入（未来现金流、折现率）由管理层估计，什么时候减、减多少，弹性很大。

中国准则有一条和国际准则不同的规定：**固定资产、无形资产、商誉、长期股权投资等长期资产的减值一旦计提，以后不得转回**；国际准则允许除商誉外的长期资产在条件满足时转回。存货跌价准备和应收账款坏账准备则在中国准则下也可以转回。这条规定的初衷是防止公司用"先减值、后转回"调节利润；副作用是，有的公司会在业绩本来就差的年份一次性大额减值（俗称"洗大澡"），为以后几年的利润"轻装上阵"腾出空间。这类问题怎样识别、怎样把一次性减值从盈利里剔除，见 5.3.1.2.4.3。

> **投资者怎么用**：账面价值是一个起点，不是答案。PB（市净率）低于 1，可能是市场错杀，也可能是账面资产本身就虚高、还没减值；PB 很高，可能是泡沫，也可能是公司最值钱的资产（品牌、技术、网络）根本不在账上。PB 怎样用、和 ROE（净资产收益率）是什么关系，见 5.5.4.3。

### 5.3.1.1.2.2 固定资产及折旧方法

固定资产（厂房、机器、运输设备、办公设备）按买入成本入账，然后在使用年限内通过**折旧**逐年转为费用。理论上，折旧应该反映资产创造利润能力的下降；实际上，它取决于公司选择的方法和年限。

中国准则允许四种折旧方法。拿一台 100 万元、使用 5 年、不留残值的设备算一遍（单位：万元）：

| 年份 | 年限平均法（直线法） | 双倍余额递减法 | 年数总和法 |
|---|---|---|---|
| 第 1 年 | 20 | $100 \times 40\% = 40$ | $100 \times 5/15 = 33.3$ |
| 第 2 年 | 20 | $60 \times 40\% = 24$ | $100 \times 4/15 = 26.7$ |
| 第 3 年 | 20 | $36 \times 40\% = 14.4$ | $100 \times 3/15 = 20.0$ |
| 第 4 年 | 20 | 10.8 | $100 \times 2/15 = 13.3$ |
| 第 5 年 | 20 | 10.8 | $100 \times 1/15 = 6.7$ |
| 合计 | 100 | 100 | 100 |

- **直线法**：每年折旧相同，$100 / 5 = 20$。A股绝大多数公司用它。
- **双倍余额递减法**：每年按期初账面净值的固定比例折旧，比例是直线法的两倍（$2 / 5 = 40\%$）。按中国准则，最后两年改为把剩余净值平均分摊，所以第 4、5 年各是 $21.6 / 2 = 10.8$。
- **年数总和法**：把年数加总（$1 + 2 + 3 + 4 + 5 = 15$），第 1 年折 5/15，第 2 年折 4/15，依次递减。
- 第四种**工作量法**按实际产量或行驶里程折旧，常见于运输和采掘业。

双倍余额递减法和年数总和法合称**加速折旧**：前几年多折、后几年少折（工作量法不属于加速折旧，它的折旧额随产量起伏，没有固定的先多后少）。五年加起来都是 100，但利润的时间分布完全不同。设这台设备每年带来扣折旧前的利润 50 万元：直线法下每年利润 30；双倍余额递减法下第 1 年只有 10，第 5 年有 39.2。

折旧**年限**的影响往往比方法更大。设想一家公司新购设备 1000 万元，原定按 10 年直线折旧，每年 100 万元；公司公告"会计估计变更"，把年限改为 15 年，每年折旧降到 66.7 万元。如果它的 EBIT（息税前利润）原本是 200 万元，现在变成 233.3 万元，增加了六分之一，而设备、产量、售价都没有变。A股每年都有公司公告延长固定资产折旧年限，这类变更按准则只影响未来，不追溯调整以前年度，所以变更当年的利润增长会显得格外好看。同行之间比较利润率之前，先翻附注里的"固定资产折旧政策"表，看看大家的年限是不是一样。

**税法折旧和会计折旧可以不同。** 中国税法对符合条件的设备允许加速折旧，对单位价值不超过一定标准的新购设备还允许一次性税前扣除；会计上却可以照旧按直线法慢慢折。于是前几年报税时扣得多、交税少，利润表上的所得税费用却按会计利润算，两者的差额形成**递延所得税负债**（算例见 5.3.1.1.3.5）。

还有一个 A股常见的细节：**在建工程不计提折旧**，只有转入固定资产后才开始折旧，所以已经投产却迟迟不"转固"的生产线会高估当期利润（识别方法见 5.3.1.2.4.2）。

> **投资者怎么用**：折旧是把过去的资本开支摊到今天的利润里。估值最终看现金流，折旧方法本身不改变现金（税法折旧除外），但它会改变你看到的利润率、ROIC（投入资本回报率）和 PE（市盈率）。比较两家公司时，要么把折旧政策对齐，要么直接比较 EBITDA（息税折旧摊销前利润）和资本开支。

### 5.3.1.1.2.3 应收账款、坏账准备与回收质量

应收账款是公司赊销后客户欠的钱，按销售时的金额入账。它最大的会计问题不是怎么记，而是**什么时候承认收不回来**。

公司有两种处理方式。一种是在确认收入的同时，预估一部分会变成坏账，提前从利润里扣掉，记为**坏账准备**，应收账款按扣除准备后的净额列示。另一种是等坏账真的发生了再核销。前者更稳健；后者的风险在于，公司明知某些款项收不回来，却继续把它们挂在应收账款里。

中国准则 2017 年修订金融工具准则（境内外同时上市的公司 2018 年起执行，其他上市公司 2019 年起执行），要求按**预期信用损失**计提坏账准备：不等损失发生，而是按"未来可能损失多少"提前计提。A股公司最常见的做法是**账龄组合**：按欠款时间长短分组，每组用一个计提比例。设想一家公司年末应收账款 1000 万元：

| 账龄 | 余额 | 本公司计提比例 | 坏账准备 | 同行计提比例 | 坏账准备 |
|---|---|---|---|---|---|
| 1 年以内 | 800 | 5% | 40 | 1% | 8 |
| 1–2 年 | 150 | 20% | 30 | 20% | 30 |
| 2–3 年 | 40 | 50% | 20 | 50% | 20 |
| 3 年以上 | 10 | 100% | 10 | 100% | 10 |
| **合计** | **1000** | | **100** | | **68** |

同样的应收账款，只因为 1 年以内那一档的比例不同，坏账准备就差了 32 万元，利润也差了 32 万元（税前）。计提比例是管理层定的，附注里会披露。坏账准备的变动计入利润表的"信用减值损失"。

看应收账款的回收质量，可以从四个角度入手：

- **增速对比**：应收账款增速长期快于收入增速，说明公司在用更宽松的信用条件换收入。
- **账龄结构**：1 年以上的占比在上升，说明回款在变慢。
- **客户集中度**：附注会披露应收账款前五名。如果大客户本身财务紧张（比如给困难房企供货的建材公司），账龄再短也有风险。
- **票据结构**：应收票据里，银行承兑汇票几乎没有信用风险，商业承兑汇票要看出票企业的信用。2021 年前后不少地产链上游公司收到大量地产商开出的商业承兑汇票，后来出现大面积逾期。

收入确认激进、准备金计提和转回被用来调节利润，这些"从会计盈利到真实盈利"的问题见 5.3.1.2.4.1 和 5.3.1.2.4.4。应收账款周转天数的算法见 5.3.1.1.5.3。

### 5.3.1.1.2.4 存货：计价方法与库存价值

存货包括原材料、在产品、产成品，按成本入账。难点在于：同一种货在不同时间以不同价格买进，卖出去的那一批算多少成本？

中国准则允许**先进先出法**、**加权平均法**和**个别计价法**（适用于珠宝、房地产这类可以逐件辨认的存货）。**后进先出法在中国准则和国际准则下都不允许**，只有美国准则还允许。用一个设想的例子算一遍：年初没有库存，一季度以每件 10 元买进 100 件，三季度以每件 14 元买进 100 件，全年以每件 20 元卖出 150 件。

| | 先进先出 FIFO | 加权平均 | 后进先出 LIFO（中国不允许） |
|---|---|---|---|
| 营业成本 | $100 \times 10 + 50 \times 14 = 1700$ | $150 \times 12 = 1800$ | $100 \times 14 + 50 \times 10 = 1900$ |
| 期末存货 | $50 \times 14 = 700$ | $50 \times 12 = 600$ | $50 \times 10 = 500$ |
| 毛利（收入 3000） | 1300 | 1200 | 1100 |

在价格上涨时，先进先出用的是较早、较便宜的成本，所以营业成本最低、利润最高，期末存货最接近当前的重置成本；后进先出相反。价格下跌时，结论倒过来。不管用哪种方法，**买货付出的现金都是 2400**，方法只决定这 2400 有多少进了今年的成本、多少留在存货里。

（后进先出法在美国常被用来省税：营业成本高，应税利润就低。比较美国公司时，附注里会披露"后进先出储备"，即按先进先出法计算的存货与后进先出法存货的差额，可以用它把存货和营业成本调回先进先出口径。）

**期末再按"成本与可变现净值孰低"计量。** 可变现净值是存货的预计售价减去完工成本和销售费用。假如上例的 50 件存货年末只能卖 13 元一件，扣掉 1 元销售费用后可变现净值是 600，先进先出法下的成本 700 就要减记 100，计入"资产减值损失"。如果第二年价格回升，这笔存货跌价准备可以转回。

存货在不同行业里的含义差别很大，读表时要结合生意来看：

| 行业 | 存货里是什么 | 读表时问什么 |
|---|---|---|
| 白酒 | 基酒、包装材料 | 基酒按生产成本计量，越陈越值钱，账面价值远低于经济价值 |
| 房地产 | 土地、在建的"开发成本"、建成未售的"开发产品" | 存货就是项目本身；地价和房价下跌时，跌价准备是否计提充分 |
| 生猪养殖 | 种猪、育肥猪等生物资产 | 猪价周期里，存货价值随猪价大幅波动 |
| 电子、服装 | 产成品 | 技术迭代和款式过季很快，存货跌价风险高 |
| 超市 | 商品 | 周转很快，存货多为供应商赊销而来 |

### 5.3.1.1.2.5 现金、有价证券与金融投资

这一类资产是资产负债表上**最接近市场价值**的部分，也是会计真正使用市价的少数地方。

**货币资金**按面值记。要看附注里的构成：库存现金、银行存款、**其他货币资金**（票据保证金、信用证保证金等）。后者通常是受限的，不能自由动用。

**金融资产**按 2017 年修订的金融工具准则（多数 A股公司 2019 年起执行，读更早的年报会看到"可供出售金融资产"等旧科目）分为三类，计量方式各不相同。拿一笔 100 万元的投资、年末市值涨了 20% 来说：

| 分类 | 常见报表科目 | 资产负债表 | 涨的 20 万元记在哪里 |
|---|---|---|---|
| 以摊余成本计量 | 债权投资、部分定期存款 | 按成本加应计利息 | 不记（只确认利息收入） |
| 以公允价值计量且变动计入其他综合收益（FVOCI） | 其他债权投资、**其他权益工具投资** | 按市值 | 其他综合收益，进股东权益，**不进利润** |
| 以公允价值计量且变动计入当期损益（FVTPL） | 交易性金融资产、其他非流动金融资产 | 按市值 | 公允价值变动收益，**进利润** |

分类由公司的持有目的和资产的现金流特征决定，公司有一定的选择余地。这带来一个对读利润很重要的结果：同样买了 100 万元的某只股票，记作"交易性金融资产"，股价的涨跌每年都进利润，利润跟着股市波动；指定为"其他权益工具投资"，涨跌只进其他综合收益，而且**卖出时的累计盈亏也不经过利润表，直接转入留存收益**。所以，一家公司持有大量股票投资，它的利润可能被市场行情放大或抹平，也可能完全看不到这些投资的盈亏，取决于它怎么分类。

市值计量也不是万能的。逐日盯市让投资银行等金融机构的资产按市价反映，但 2008 年金融危机前，盯市并没能提醒投资者次级抵押贷款证券已经被高估；市场本身错了，盯市只是把错误照搬进了报表。

估值时，这些金融资产通常不属于经营资产，要单独估值后加回（5.3.2.2.6.1、5.5.3.4.2.1）。账上现金很多、借款也很多的"存贷双高"信号，见 5.3.2.2.6.1。

### 5.3.1.1.2.6 少数股权投资和非并表投资

一家公司持有另一家公司的股份，会计处理按**影响力大小**分三层。这三层决定了被投资公司的收入、利润、资产以什么形式出现在你的报表上。

| 持股（大致） | 会计判断 | 处理方法 | 在报表上的样子 |
|---|---|---|---|
| 低于 20% | 无重大影响 | 按金融资产，以公允价值计量（见上一小节） | 一行金融资产；分红进投资收益 |
| 20%–50% | 重大影响（联营企业）或共同控制（合营企业） | **权益法** | 一行"长期股权投资"；按持股比例享有的利润进"投资收益" |
| 50% 以上，或其他方式取得控制 | 控制（子公司） | **合并** | 子公司的全部资产、负债、收入、利润逐行并入；其他股东的份额单列为少数股东权益 / 少数股东损益 |

百分比只是经验线，中国准则看的是实质：持股 40% 但通过协议控制了董事会，也要合并；持股 15% 但派了董事、能参与决策，也可能用权益法。

**权益法**用一个例子说明。设想 A 公司花 300 万元买下 B 公司 30% 的股份。B 公司当年净利润 100 万元，分红 40 万元：

- A 的投资收益：$100 \times 30\% = 30$ 万元，计入利润；
- A 收到的分红：$40 \times 30\% = 12$ 万元，这是现金，同时冲减长期股权投资；
- A 的长期股权投资年末：$300 + 30 - 12 = 318$ 万元。

A 的利润表多了 30，现金只多了 12。一家投资收益占利润很大比例、但收到的分红很少的公司，利润的含金量要打折扣。权益法下的长期股权投资不反映市价，只有在卖出时才确认市价与账面的差额。

**合并**再看一个例子。设想 A 公司持有 C 公司 60% 的股份，C 公司收入 500 万元、净利润 50 万元、净资产 200 万元。A 的合并报表把 C 的 500 万元收入全部并进来；净利润 50 万元也全部计入合并净利润，再拆成归属于母公司股东的 30 万元和少数股东损益 20 万元；C 的净资产中属于其他股东的 $200 \times 40\% = 80$ 万元，列为**少数股东权益**。按中国准则和国际准则，少数股东权益列在**所有者权益**里（美国准则过去曾把它列在负债和权益之间）。

这三种处理会让同样的经济实质看起来很不一样：合并让收入和资产变大，杠杆、利润率都按 100% 口径算；权益法只留下一行投资和一行收益，被投资公司的债务完全不出现在你的报表上。两个对读表最实用的提醒：

- **净利润和归母净利润不是一回事。** 每股收益、PE、ROE 都应该用归属于母公司股东的净利润，股东权益也应该用归属于母公司的那部分。
- **少数股东权益占比大的公司，合并报表的数字有一部分不属于你。** 合并报表的 ROIC 可能主要来自一个只持股 51% 的子公司（算例见 5.3.2.8.6）。

估值时，联营企业和其他股权投资要单独估值后加回，少数股东权益要按价值扣除（5.3.2.2.6.2、5.5.3.4.2.3、5.5.3.4.3.3）。

### 5.3.1.1.2.7 无形资产、专利、商标与商誉

无形资产的会计处理，关键在于它是**自己做出来的**还是**买来的**。

**自己做出来的，大多不在资产负债表上。** 品牌的建设费用（广告、渠道）、客户关系的维护费用、技术的研究费用，发生当期就计入费用。中国准则（和国际准则一样）在研发上留了一道口子：研究阶段的支出全部费用化，**开发阶段**的支出在技术可行性、使用或出售意图、经济利益、资源支持、可靠计量五个条件都满足时，可以资本化，先记"开发支出"，完成后转入无形资产再摊销。美国准则则基本要求研发全部费用化。这道口子让资本化比例成为管理层的一个选择：同行业两家药企，一家研发全部费用化，一家资本化一半以上，利润和资产都没法直接比（影响见 5.3.1.1.4.2）。

所以，一家消费品公司最值钱的品牌、一家科技公司最值钱的技术，在资产负债表上往往不存在，或者只是一个很小的数字。这不是会计错了，而是会计"只记可靠计量的过去交易"这条原则的必然结果。估值时怎样看待这些表外的无形资产，见 5.3.1.2.1 和 5.3.2.8.2。

**买来的，按成本入账。** 外购的专利、商标、软件按购买价格记为无形资产，有确定使用寿命的在寿命内摊销（通常直线法），寿命不确定的（比如可以无限续期的商标）不摊销、每年做减值测试。

中国报表上有一项特殊的无形资产：**土地使用权**。中国的土地所有权不能买卖，企业买到的是若干年（工业用地通常 50 年）的使用权，记为无形资产按年限摊销。所以 A股制造业公司的"无形资产"里，大头往往是土地，而不是专利。

**商誉是并购的副产品。** 收购一家公司时，收购价首先分配给被收购方可辨认的资产和负债（按公允价值，包括对方账上没有、但可以单独辨认的商标、客户关系、技术），剩下的差额就是商誉：

$$
\text{商誉} = \text{收购对价} - \text{被收购方可辨认净资产的公允价值} \times \text{持股比例}
$$

设想一家公司花 10 亿元买下一家游戏公司 100% 的股权。对方账面净资产 2 亿元，评估后发现它的游戏版权和用户资源还值 1 亿元（为简化，不考虑评估增值带来的递延所得税），可辨认净资产公允价值 3 亿元，商誉就是 $10 - 3 = 7$ 亿元。会计上说商誉代表"无法单独辨认的无形资产"，比如协同效应、团队；更直白地说，它是**收购方多付的溢价**。

商誉在中国准则和国际准则下**不摊销**，每年做减值测试；减值一旦计提，**不得转回**。假如第三年游戏公司业绩大幅下滑，测试后计提商誉减值 4 亿元，利润表就多出 4 亿元的资产减值损失。这笔损失不涉及现金，钱早在三年前收购时就付出去了；它只是会计**迟到地承认**：当初付多了。

A股在 2013–2016 年经历了一轮并购高峰，大量收购以高溢价进行，并附有被收购方三年业绩承诺。承诺期结束后业绩变脸，2018 年前后出现了集中的商誉减值潮，许多公司当年由盈转亏。这段历史给读表留下两个习惯：**商誉占净资产比例高的公司，要查清它来自哪些收购、这些子公司的业绩承诺何时到期、实际完成情况如何**；**商誉减值是一个滞后指标**，价值在付出溢价的那一刻就已经决定了。

> **投资者怎么用**：商誉在 ROIC 分析里有两种口径。含商誉的 ROIC 回答"管理层花出去的全部钱赚了多少"，不含商誉的 ROIC 回答"业务本身的回报怎样"。两者的区别和用法见 5.3.2.5.1；商誉在投入资本中的处理见 5.3.2.2.3。

## 5.3.1.1.3 衡量融资结构

资产负债表的右边告诉你公司的钱从哪里来。会计在这里也有两条原则。

**第一，负债的确认门槛很高。** 一项义务要记为负债，必须同时满足：预计会在未来某个确定或可以确定的日期导致现金流出；公司无法回避；形成义务的交易已经发生。达不到这个门槛的义务，比如未决诉讼的可能赔偿、对外担保、长期采购承诺，只在附注里披露（5.3.1.1.5.1）。这和资产端"宁可低估"是一致的保守：只有躲不掉的义务才算负债。

**第二，负债和权益也按历史成本计量。** 借款按借入时的金额记，股东权益按投入的钱加上累积的利润记，都不随市场变化调整。

### 5.3.1.1.3.1 流动负债与经营性负债

流动负债是一年内要偿付的义务。从估值的角度，它要拆成两类。

**经营性负债**是经营中自然形成、通常不付利息的负债：欠供应商的**应付账款**和**应付票据**，欠客户的**合同负债**（2018–2020 年分批执行新收入准则后，大部分"预收账款"改叫合同负债；境内外同时上市的公司 2018 年起执行，其他 A股上市公司 2020 年起执行），欠员工的**应付职工薪酬**，欠政府的**应交税费**，以及与经营相关的**其他应付款**（如经销商保证金）。

**融资性负债**是付息的借款：**短期借款**、**一年内到期的非流动负债**（长期借款和债券中一年内要还的部分）、短期融资券等。

在资产负债表的所有科目里，流动负债的账面价值和市场价值最接近：要还的金额是确定的，时间又很短。这是它和资产端最大的不同。

经营性负债的经济含义，5.2.1.1 已经说过：它是别人替你垫的钱，可以从投入资本里扣掉。A股和港股里，很多好生意的特征恰恰写在这几行上：

- **合同负债大**：客户先付钱后拿货。高端白酒的经销商要先打款再提货；房地产预售收到的房款在交房前都挂在合同负债里；教育培训、健身、会员制零售收的是预付费。合同负债大，说明公司议价能力强、营运资本占用少；合同负债突然下降，可能是需求转弱的早期信号（经销商不愿意先打款了）。
- **应付账款和应付票据大**：对上游占款。家电、汽车整车、大型零售企业常常凭借规模，对供应商形成很长的付款周期。

但"不付息"也有例外，要警惕两种情况。一是**应付票据**里可能藏着变相借款：公司向银行存入保证金、开出票据，再通过关联方贴现拿到现金，这时票据更像借款（判断规则见 5.3.2.2.1）。二是**供应链金融**：公司把对供应商的付款周期大幅拉长，再由合作平台向供应商提供贴现融资，账面上仍是应付账款，实质上是公司借了供应商的钱、由供应商承担利息。哪些负债算经营、哪些算融资，判断原则见 5.3.2.1.2。

### 5.3.1.1.3.2 短期债务与长期债务

有息债务有两种来源：银行等金融机构的**贷款**，和在市场上发行的**债券**（A股公司常见的有公司债、企业债、中期票据、超短期融资券，以及可转换公司债券）。按期限，一年内到期的列为短期借款或一年内到期的非流动负债，一年以上的列为长期借款、应付债券。

银行贷款按借入的本金入账。债券则按**发行时实际收到的钱**入账，然后用**实际利率法**逐年摊销到面值，这叫"摊余成本"。用一个零息债券的例子最容易看清：设想公司发行 3 年期零息债券，面值 100 元，市场要求的收益率 5%，发行价是

$$
\frac{100}{1.05^3} = 86.38 \text{ 元}
$$

| 年份 | 期初账面价值 | 当年利息费用（5%） | 期末账面价值 |
|---|---|---|---|
| 1 | 86.38 | 4.32 | 90.70 |
| 2 | 90.70 | 4.54 | 95.24 |
| 3 | 95.24 | 4.76 | 100.00 |

公司三年里一分钱利息都没付，但每年利润表里都有利息费用，债务的账面价值逐年增加，到期时正好等于要偿还的面值 100。溢价或折价发行的普通债券道理相同。

短期和长期的划分，对判断风险比对估值更重要。估值时，所有有息债务都是对公司价值的索取权，不分长短一起扣除。但看风险时，期限结构很关键：用短期借款支撑长期投资（"短债长投"）的公司，资产要很多年才能回本，借款却每年都要续，一旦银行收紧就可能出现流动性危机。期限结构怎样分析，见 5.3.2.7.4。

### 5.3.1.1.3.3 债务账面价值与市场价值

摊余成本有一个后果：**债务的账面价值在整个期限内不随利率和信用变化**。但债务对债权人的"价值"会变。

设想公司按面值发行了 5 年期债券，面值 100 元，每年付息 4 元。一年后，市场利率（或者市场对这家公司要求的收益率）升到 6%。剩下 4 年的现金流按 6% 折现：

$$
4 \times \frac{1 - 1.06^{-4}}{0.06} + \frac{100}{1.06^4} = 4 \times 3.4651 + 79.21 = 93.07 \text{ 元}
$$

账面上仍然是 100，市场价值只有 93.07。利率上升或者公司信用变差，债务的市场价值都会低于账面；反之则高于账面。2021–2022 年一批高杠杆房企的美元债和境内债大幅折价交易，有的跌到面值的两三成甚至一成以下，就是信用恶化让市场价值和账面价值严重背离的例子。

这对估值有两个影响。一是 WACC（加权平均资本成本）的权重应该用市场价值（5.5.2.3.3）；二是从企业价值里扣除债务时，原则上也应该用市场价值（5.5.3.4.3.1）。实务中，多数 A股公司的债务是银行贷款，没有市价，信用状况也没有大的变化，账面价值就是很好的近似。真正需要按市价处理的，是利率大幅变化之后的长期固定利率债务，和陷入困境的公司的债务。对于没有公开交易的贷款，可以把它当作一只债券，用当前适合这家公司的利率对剩余本息折现，估出一个市场价值。

### 5.3.1.1.3.4 租赁与类似债务承诺

公司可以买资产，也可以租资产。租来的门店、飞机、仓库，和借钱买来的资产在经济上很像：都要按合同长期付钱，付不出来都会出事。

**旧的做法**区分两类租赁：**融资租赁**（实质上转移了所有权的风险和报酬，比如租期接近资产寿命、期末转移所有权、有优惠购买选择权、租金现值接近资产公允价值）要把资产和负债放上资产负债表；**经营租赁**只在利润表里记租金费用，资产负债表上什么都没有。结果是公司有强烈动机把租赁安排成经营租赁，让大量实际上的"负债"留在表外。

**新租赁准则**基本取消了承租人这一侧的区分。国际准则 2019 年起实施（港股公司随之执行），A股上市公司 2021 年起全面执行。承租人对几乎所有租赁都要确认两项：

- **使用权资产**：租入资产的使用权，在租期内折旧；
- **租赁负债**：未来租金按适当利率折现的现值，此后按实际利率法确认利息、随付款减少。

**短期租赁**（12 个月以内）和**低价值资产租赁**可以选择不上表，照旧记租金费用；与销售额挂钩的**可变租金**（商场里常见的"按营业额提成"）也不进租赁负债。

用一个设想的例子看新准则怎样改变报表。一家餐饮公司租一间门店，每年年末付租金 100 万元，租期 5 年，折现率 5%：

$$
\text{租赁负债} = \text{使用权资产} = 100 \times \frac{1 - 1.05^{-5}}{0.05} = 100 \times 4.3295 = 432.95 \text{ 万元}
$$

| 第 1 年 | 旧准则（经营租赁） | 新准则 |
|---|---|---|
| 资产负债表 | 无 | 使用权资产 432.95，租赁负债 432.95 |
| 利润表费用 | 租金 100 | 折旧 $432.95 / 5 = 86.59$ + 利息 $432.95 \times 5\% = 21.65$，合计 108.24 |
| EBITDA | 扣了 100 | 不扣（折旧和利息都在 EBITDA 之下），**高出 100** |
| EBIT | 扣了 100 | 只扣折旧 86.59，**高出 13.41** |
| 税前利润 | 扣了 100 | 扣了 108.24，**低了 8.24** |
| 经营活动现金流 | 流出 100 | **0**（本金和利息都改记筹资活动） |
| 筹资活动现金流 | 0 | 流出 100 |

利息逐年下降，所以新准则下的费用前高后低：第 5 年的利息只剩 $95.24 \times 5\% = 4.76$，费用合计 91.35。五年加起来，折旧 432.95 加利息 67.05，正好等于租金总额 500。**现金一分没变，变的只是它在报表上出现的位置**：EBITDA（息税折旧摊销前利润）和经营现金流显著变大，负债率显著上升，利润在租期前段略低、后段略高。

对读表的影响很直接：拿 2021 年前后的 A股零售、餐饮、航空公司数据比较，或者拿执行新准则的公司和按美国准则编表的公司比较（美国准则下经营租赁虽然也上表，但利润表仍记一笔直线租金费用），EBITDA、经营现金流、负债率都不能直接比。

为什么租赁在经济上应当视为融资、而不是经营费用，见 5.3.1.2.3.3；估值时使用权资产、租赁负债和租赁利息怎样处理，以及 2021 年以前的历史数据怎样补做资本化，见 5.3.2.2.5 和 5.3.2.8.1。

**类似债务的承诺**还有几种，不一定在表上，要到附注的"承诺事项"里找：长期**照付不议**合同（不管用不用都要付钱的采购，常见于天然气、电力、原材料长协）、已签约未支付的**资本承诺**、带有回购义务的融资安排。它们和租赁一样，是固定的未来现金流出。

### 5.3.1.1.3.5 养老金、医疗福利等长期承诺

除了借款和租赁，公司还有一些长期义务，会计把它们放在"其他非流动负债"一类里。

**养老金和退休福利。** 养老金计划有两种。**设定提存计划**：公司每期按规定缴一笔钱，缴完就没有后续义务，未来员工能领多少与公司无关。**设定受益计划**：公司承诺员工退休后领取确定的福利，钱不够由公司补。后者的负债很难估计，取决于员工寿命、工资增长、计划资产的投资收益和折现率。计划资产超过负债叫"盈余"，少于负债叫"缺口"。

中国企业为员工缴纳的基本养老保险属于设定提存计划，所以绝大多数 A股公司没有大额养老金负债。设定受益计划主要出现在两类公司：一是部分历史较长的国有企业，对离退休人员承诺了补充福利，体现为"长期应付职工薪酬"；二是在欧美、日本有大量雇员的港股或 A股公司（比如收购了海外制造企业的公司），沿用当地的设定受益计划。设想一家公司的设定受益义务现值 500 万元，计划资产 380 万元，表上就有 120 万元的净负债。这 120 万元和债务一样，是公司未来必须拿现金填的窟窿。估值时怎样把它作为债务等价物处理，见 5.3.2.8.5 和 5.5.3.4.3.2。

**递延所得税。** 会计上的利润和税法上的应税所得常常不同，最典型的就是 5.3.1.1.2.2 提到的折旧差异。设想公司买了一台 100 万元的设备，税法允许当年一次性扣除，会计上按 5 年直线折旧；公司每年扣折旧前利润 200 万元，税率 25%：

| | 第 1 年 | 第 2–5 年（每年） |
|---|---|---|
| 会计利润 | $200 - 20 = 180$ | 180 |
| 利润表的所得税费用（按会计利润） | 45 | 45 |
| 应税所得 | $200 - 100 = 100$ | 200 |
| 实际应交所得税 | 25 | 50 |
| 递延所得税负债（年末余额） | $45 - 25 = 20$ | 每年减少 5，第 5 年末为 0 |

第 1 年少交的 20 万元税，并没有免掉，而是推迟到以后几年交。会计把它记为**递延所得税负债**。反过来，如果公司先交了税、以后才能抵扣（比如计提的坏账准备在税法上要等实际发生才能扣、可以抵扣的亏损），就形成**递延所得税资产**。

递延所得税负债算不算负债，有不同的看法。一方面，公司并不欠任何人这笔钱，税务局也没有来要；另一方面，它终归要交，当作负债更保守。如果公司持续投资，新的差异不断产生，这笔递延的税会一直滚动、很难真正交出去，它就更像一笔无息的长期资金。估值的处理是：NOPLAT（税后经营利润）用实际交的现金税，递延所得税负债则挪到权益一侧（5.3.2.2.8、5.3.2.3.4）。

**预计负债**也属于这一类：产品质量保证、未决诉讼、亏损合同、环境恢复义务，满足"很可能发生、金额能可靠估计"时，要计提为预计负债（5.3.1.1.5.1）。

### 5.3.1.1.3.6 股东权益及其账面值

股东权益的账面价值，是股东历年投入的钱，加上累积留存的利润，再加减一些不经过利润表的项目。中国报表上的结构是：

| 科目 | 是什么 |
|---|---|
| 股本 | 股票面值（通常每股 1 元）× 股数 |
| 其他权益工具 | 公司发行的**永续债**、**优先股**等，满足权益定义的部分 |
| 资本公积 | 发行价超过面值的部分（股本溢价）等 |
| 减：库存股 | 回购后尚未注销的股票，按回购价冲减权益 |
| 其他综合收益 | 不进利润表的损益：FVOCI 金融资产的涨跌、外币报表折算差额、设定受益计划重新计量等 |
| 专项储备 | 煤炭、建筑等行业按规定计提的安全生产费 |
| 盈余公积、未分配利润 | 累积留存的利润 |
| **归属于母公司所有者权益合计** | 估值和 ROE、PB 应该用这个数 |
| 少数股东权益 | 子公司其他股东的份额（5.3.1.1.2.6） |

账面权益的变动有一条简单的规律：**期末权益 = 期初权益 + 净利润 − 分红 + 增发 − 回购 ± 其他综合收益**。几个常被忽略的点：

**回购按市价冲减权益，可能让账面权益变得很小甚至为负。** 设想一家公司年初账面权益 1500 万元、股数 100 万股，当年净利润 150 万元，分红 50 万元，又以每股 49 元回购了 10 万股（490 万元）并注销。年末账面权益是 $1500 + 150 - 50 - 490 = 1110$ 万元。股价远高于每股账面价值（年初是 15 元）时，回购会大幅压缩账面权益。一些持续大额回购的美股公司账面权益已经为负，但这并不代表它们资不抵债。所以回购频繁的公司，ROE（净资产收益率）和 PB（市净率）都会失真：分母变小了，ROE 被抬高，PB 被抬高，生意本身未必有变化。

**永续债和优先股记在权益里，但对普通股股东来说更像债务。** A股不少国有企业、地产公司发行永续债，记入"其他权益工具"，因为它没有固定到期日、发行人可以递延付息。可它的票面利率往往比普通债务还高，而且常有利率跳升条款，逼着发行人到期赎回。A股银行发行的优先股也记在其他权益工具里。对普通股股东而言，这些都是排在自己前面的索取权：算 ROE 时，分子要扣掉它们的股息或利息，分母要扣掉它们的金额；算负债率时，最好把永续债当作债务（为什么这类"金融工程"不创造价值，见 5.2.1.7）。

**账面价值和市场价值是两回事。** 青禾 2025 年末的账面权益是 480 万元，如果有人愿意以 1500 万元买下它，这多出来的 1020 万元，就是市场对青禾未来超额回报的定价，会计报表里不会有它。PB 背后的经济含义见 5.5.4.3。

## 5.3.1.1.4 衡量盈利和盈利能力

利润表回答"一段时期赚了多少"，但它衡量的是**现有资产**的盈利，不是未来的盈利。它背后有两条基本原则：**权责发生制**，以及**把支出分成经营性、融资性和资本性三类**。理解这两条原则，你才知道利润表上的数字在什么地方会偏离经济现实。

### 5.3.1.1.4.1 收入确认与费用配比

**权责发生制**的意思是：收入在商品或服务**交付的那一期**确认，不管钱是什么时候收的；与收入直接相关的费用（原材料、生产工人工资）在**同一期**确认，叫作**配比**；与收入没有直接对应关系的费用（管理人员工资、房租）在发生的那一期确认。与之相对的是**收付实现制**：收到钱算收入，付出钱算费用。

青禾 2025 年赊销了 100 万元货款还没收回，收入照样确认；经销商预付的 30 万元货还没发，不算收入，挂在合同负债里。这就是利润和现金流不一样的根本原因。

中国准则从 2018 年起（A股上市公司分批执行）实行新收入准则，核心是**五步法**：识别合同 → 识别合同里的各项**履约义务** → 确定交易价格 → 把价格分摊到各项履约义务 → 在履约时确认收入。关键的判断是履约义务是**在某一时点**完成，还是**在一段时间内**完成：

| 情形 | 确认方式 | 例子 |
|---|---|---|
| 某一时点履约 | 控制权转移给客户时一次确认 | 卖白酒、卖手机；房地产公司在**交房**时确认收入 |
| 一段时间内履约 | 按履约进度分期确认 | 建筑工程、大型设备制造、定制软件开发 |
| 预收款 | 收钱时记合同负债，履约时转为收入 | 会员费、储值卡、预售房款、课程费 |
| 一份合同多项义务 | 把价格分摊到每项义务，各自确认 | 卖设备附带三年维保：设备交付时确认一部分，维保在三年内确认 |
| 总额法与净额法 | 公司是"主要责任人"按总额确认，是"代理人"只确认佣金 | 电商自营按商品全价确认收入，电商平台只确认佣金和服务费 |

这些规则会让同样的生意在不同时间、以不同规模出现在利润表上。两个例子：

**房地产的收入滞后。** 设想一家房企 2024 年预售了一个楼盘，收到房款 10 亿元，2026 年交房。2024 年它的收入是 0，合同负债增加 10 亿元；2026 年交房时，合同负债转为 10 亿元收入。所以房企当年的利润表反映的是两三年前的销售，要看它最近的经营，得看合同负债和销售金额，而不是营业收入。

**总额法与净额法让收入规模差几倍。** 两家公司都撮合了 100 亿元的交易，赚了 5 亿元的差价：按总额法确认的公司收入 100 亿元、毛利率 5%；按净额法的公司收入 5 亿元、毛利率可能接近 100%。经济实质完全一样，收入、利润率、PS（市销率）却天差地别。

有了收入确认的弹性，就有了被滥用的空间：提前确认（期末向经销商压货、按进度确认时高估进度）、虚增（循环交易、无商业实质的贸易收入）。识别方法见 5.3.1.2.4.1。

### 5.3.1.1.4.2 经营性支出与资本性支出的区分

会计把支出分成三类：

- **经营性支出**：只为当期带来收益的支出，比如生产当期产品的原材料和人工。它们直接从当期收入里扣除。
- **融资性支出**：为使用非股东资金付出的代价，最典型的是利息。经营利润扣掉它，才得到属于股东的利润。
- **资本性支出**：预期在多个期间带来收益的支出，比如买土地、建厂房、买设备。它们先记为资产，再通过**折旧和摊销**分摊到受益的各期。

用公式表达：收入 − 经营性支出 = 经营利润；经营利润 − 融资性支出 − 税 = 净利润；资本性支出不直接扣，而是通过折旧逐年扣。

这个分类的原则是对的，但执行上有两个系统性的偏差。

**第一，按历史成本算的折旧，和资产实际的经济损耗关系不大**（5.3.1.1.2.2 的例子）。

**第二，有些明明在多个期间带来收益的支出被当成了经营性支出。** 最典型的是**研发**：今年的研发投入可能在未来十年带来收入，会计却要求大部分在当期费用化，理由是未来收益难以可靠计量。广告和品牌建设、获客补贴、员工培训，也是同样的情况。反方向的偏差也存在：中国准则允许开发支出资本化，资本化比例越高，当期利润越高。设想两家公司今年都投入研发 100 万元。甲全部费用化；乙资本化 60 万元、按 5 年摊销，今年只摊 12 万元。乙今年的研发相关费用是 $40 + 12 = 52$ 万元，比甲少 48 万元，利润就高 48 万元，而两家公司花的现金一样多。

类似的"资本化还是费用化"的选择还有：**借款费用资本化**（在建工程期间的借款利息计入工程成本，不进财务费用）、**大修理支出**、**软件开发成本**。每多资本化一块，当期利润就多一块，资产也多一块，未来折旧摊销也多一块。

这种误分会扭曲利润和投入资本，进而扭曲 ROIC（投入资本回报率）：研发全部费用化的公司，利润被低估，投入资本也被低估（研发形成的"资产"不在表上），ROIC 可能被**高估**。为什么要纠正、纠正的思路，见 5.3.1.2.3；具体怎样把研发和广告资本化、怎样调整 ROIC，见 5.3.2.8.2。

### 5.3.1.1.4.3 持续性利润与一次性项目

预测未来盈利，几乎都是从今年的盈利出发。所以要知道今年的利润里，多少来自**持续经营**，多少来自**难以重复的事件**。会计上把后一类大致分成四种：

| 类别 | 例子 |
|---|---|
| 异常或不常见的项目 | 出售资产或业务的盈亏、资产核销、重组费用 |
| 偶发项目 | 性质异常、不常发生但影响大的事件：自然灾害损失、债务重组利得、所持证券的大幅涨跌 |
| 终止经营 | 已经出售或决定关停的业务的损益 |
| 会计变更 | 会计政策变更（按准则通常追溯调整以前年度报表）、会计估计变更（如折旧年限，只影响当期和以后） |

中国准则要求在利润表里把**持续经营净利润**和**终止经营净利润**分开列示。对 A股投资者更常用的工具是**扣除非经常性损益后的净利润**，简称"扣非净利润"。证监会的规定列出了哪些属于非经常性损益，并要求上市公司在年报里披露明细。常见的有：非流动资产处置损益；计入当期损益的政府补助（与正常经营密切相关、按标准持续享受的除外）；交易性金融资产的公允价值变动和处置收益；委托理财收益；单独进行减值测试的应收款项减值准备转回；债务重组损益；与正常经营无关的营业外收支。

设想一家公司 2025 年归母净利润 5.0 亿元，比上年的 4.2 亿元增长 19%。翻开非经常性损益明细：政府补助 0.6 亿元、出售一栋旧厂房的收益 0.5 亿元、理财和股票投资收益 0.4 亿元，合计 1.5 亿元，扣掉对应的所得税（$1.5 \times 25\% = 0.375$ 亿元），非经常性损益净额 1.125 亿元。扣非净利润是 $5.0 - 1.125 = 3.875$ 亿元。上年扣非净利润 4.08 亿元，所以**扣非净利润其实下降了 5%**。标题里的"增长 19%"，完全是一次性收益撑起来的。

扣非净利润是监管口径的起点，不是可持续盈利的终点：哪些"一次性"项目其实年年都有、哪些该剔除的经营外收益它没剔除，以及怎样从报告利润一步步得到可持续的"正常化盈利"，见 5.3.1.2.2 和 5.3.1.2.4.6。

### 5.3.1.1.4.4 利润率：毛利率·营业利润率·净利率

盈利能力有两种衡量方式：相对于**收入**（利润率），和相对于**投入的资本**（回报率）。先看利润率。

| 利润率 | 公式 | 青禾 2025 | 它告诉你什么 |
|---|---|---|---|
| 毛利率 | （收入 − 营业成本）÷ 收入 | $400 / 1000 = 40\%$ | 产品本身的定价能力和生产成本 |
| EBITDA 利润率 | EBITDA ÷ 收入 | $(170 + 50) / 1000 = 22\%$ | 扣掉所有现金性经营费用后的利润率，不受折旧政策影响 |
| 营业利润率（EBIT 口径） | EBIT ÷ 收入 | $170 / 1000 = 17\%$ | 主营业务扣除全部经营费用后的盈利能力 |
| 税后营业利润率 | EBIT ×（1 − t）÷ 收入 | $127.5 / 1000 = 12.75\%$ | 计算 ROIC 时用的利润率 |
| 净利率 | 归母净利润 ÷ 收入 | $120 / 1000 = 12\%$ | 扣完利息、税和少数股东之后，股东拿到的比例 |

每一层利润率的差，都对应一类成本：毛利率到营业利润率之间，是销售、管理、研发费用；营业利润率到净利率之间，是利息、税和少数股东。

**一定要自己算 EBIT（息税前利润）口径的营业利润率**，不要直接用"营业利润 ÷ 营业收入"。青禾的"营业利润率"是 16%，扣了利息；一家有大量理财或大额补贴的公司，"营业利润率"可能比真实的经营利润率高出好几个百分点。

利润率的高低本身不说明生意好坏，要和资本占用一起看。高端白酒毛利率可以在 90% 左右，而超市毛利率常常只有 20% 上下，可超市的资产周转很快、对供应商占款多，同样可以有不错的资本回报。所以 ROIC 可以拆成两部分的乘积：

$$
\text{ROIC} = \frac{\text{EBIT}(1-t)}{\text{收入}} \times \frac{\text{收入}}{\text{投入资本}} = \text{税后营业利润率} \times \text{资本周转率}
$$

青禾年初投入资本 520，资本周转率 $1000 / 520 = 1.923$，税后营业利润率 12.75%，乘起来就是下一小节要算的 24.5%。高利润率低周转、低利润率高周转，可以到达同样的回报。这棵分解树怎样一层层拆到具体的价格、成本和资本科目，见 5.3.2.5.3–5.3.2.5.5。

> **投资者怎么用**：利润率一定要看趋势和同行。单看一年的 17%，说明不了什么；五年从 12% 升到 17%，要问是涨价、降本、产品结构变化，还是折旧年限延长；同行都是 10%，青禾 17%，要问优势从哪里来、能维持多久（高利润率的来源见 5.2.2.2–5.2.2.5）。

### 5.3.1.1.4.5 ROA：资产创造利润的效率

ROA（总资产收益率）衡量公司用全部资产创造利润的效率，与公司怎么融资无关。为了不受融资影响，分子用的是**扣利息之前**的利润：

$$
\text{ROA} = \frac{\text{EBIT}(1-t)}{\text{总资产}} \quad \text{或} \quad \text{ROA} = \frac{\text{净利润} + \text{利息费用} \times (1-t)}{\text{总资产}}
$$

两个式子在没有非经营收益时相等：净利润加回税后利息，就回到了 EBIT（息税前利润）× (1 − t)。青禾：$120 + 10 \times 75\% = 127.5$，正是 $170 \times 75\%$。用年初总资产 700 计算，ROA = $127.5 / 700 = 18.2\%$；用年初年末平均总资产 $(700 + 780) / 2 = 740$，ROA = 17.2%。

还有一个**税前 ROA** = EBIT ÷ 总资产 = $170 / 700 = 24.3\%$。不同税率的公司比较（比如一家享受 15% 高新技术企业税率、一家 25%），或者站在一个税率不同的收购方角度看，税前口径更公平。

国内的财经数据库和不少研报里常见的 ROA 是"净利润 ÷ 总资产"（青禾是 $120 / 700 = 17.1\%$）。这个口径扣了利息，受资本结构影响，借钱多的公司被压低，和上面的定义不是一回事。用别人的 ROA 数字之前，先问分子是什么。

ROA 有两个毛病，所以估值分析里很少把它当主角：

- **分母包含了现金和非经营资产。** 账上躺着大量现金的公司，ROA 被拉低，经营本身的效率被掩盖。
- **分母没有扣掉经营负债。** 应付账款、合同负债是供应商和客户垫的钱，它们的"成本"已经藏在采购价、售价里扣过了，却还留在 ROA 的分母里，等于重复算了一次（详细的论证见 5.3.2.5 口径二）。

所以 ROA 适合两种场合：作为杜邦分解里的中间一步（5.3.1.1.4.7），以及分析银行这类"资产就是经营本身"的金融机构（5.6.1.1）。

### 5.3.1.1.4.6 ROC/ROIC：经营资本的回报

把 ROA 的两个毛病改掉，就得到 ROIC（投入资本回报率，有时也叫资本报酬率 ROC）：分子仍是税后经营利润，分母换成**投入资本**，即从经营中扣除现金、扣除经营负债之后，真正由出资人提供的资本。它的经济含义，以及为什么要和 WACC（加权平均资本成本）比，5.2.1.1 已经讲过。这里给出从报表上直接算的简便公式：

$$
\text{ROIC} = \frac{\text{EBIT}(1-t)}{\text{有息债务账面值} + \text{股东权益账面值} - \text{现金}}
$$

青禾年初有息债务 220、股东权益 400、现金 100，投入资本 520（和 5.3.1.1.1.1 从资产端算出来的一样）：

$$
\text{ROIC} = \frac{170 \times (1 - 25\%)}{220 + 400 - 100} = \frac{127.5}{520} = 24.5\%
$$

分母可以用期初值，也可以用期初期末的平均值。青禾期末投入资本 $200 + 480 - 40 = 640$，平均 580，平均口径 ROIC 是 22.0%。青禾这一年买了 150 的设备，资本增长了 23%，两个口径差了 2.5 个百分点。什么时候用哪个口径，见 5.3.2.5 口径一。

这个简便公式是从**资金来源端**算的，它的好处是快，从年报上抄四个数就能算。缺点是粗：它把全部现金都当作非经营资产，没有区分经营需要的现金；它把所有非现金资产都当作经营资产，联营企业投资、理财、闲置的投资性房地产都混在分母里，对应的收益却不一定在分子里；它也没处理租赁、递延税、商誉这些项目。用于第一遍筛选足够了，正式估值要按 5.3.2.2–5.3.2.3 的方法逐项重组。

ROIC 在不同公司之间差别很大，同一年里，一家公司 5%、另一家 20% 毫不稀奇。1998 年，美国的波音公司和家得宝公司就是这样一对：前者是飞机制造商，那一年经营不顺，ROIC 不到 6%；后者是建材零售商，ROIC 接近 20%，大约是波音的三倍。差距主要来自生意本身，这正是 5.2.2 要回答的问题：高 ROIC 从哪里来、能持续多久。

### 5.3.1.1.4.7 ROE：股东资本的回报及杠杆影响

ROE（净资产收益率）从股东的角度看盈利能力：

$$
\text{ROE} = \frac{\text{归属于普通股股东的净利润}}{\text{归属于普通股股东的权益账面值}}
$$

如果公司发行了优先股或永续债，分子要扣掉它们的股息或利息，分母要扣掉它们的金额，因为这部分权益不属于普通股股东（5.3.1.1.3.6）。青禾用年初权益：$120 / 400 = 30\%$；用平均权益 $(400 + 480) / 2 = 440$：27.3%。A股年报里披露的是"加权平均净资产收益率"，它的分母按增发、回购、分红发生的时间对期初期末权益做了加权，比简单平均更精确。

**ROE 高于 ROIC 的部分，来自财务杠杆。** 青禾的 ROE 30%，比 ROIC 24.5% 还高，因为它借了钱，而借款的税后成本远低于经营回报。这层关系可以写成一个等式：

$$
\text{ROE} = \text{ROIC} + \frac{D}{E} \times \left[\text{ROIC} - i(1-t)\right]
$$

其中 $D$ 是有息债务账面值，$E$ 是股东权益账面值，$i$ 是债务的账面利率（利息费用 ÷ 债务），$t$ 是税率。读法是：**股东的回报 = 经营的回报 + 借来的钱赚到的差价 × 借了多少**。只要经营回报高于税后借款成本，多借钱就能抬高 ROE；反之，借钱会压低 ROE。

注意 $i$ 是从报表倒推出的历史账面利率，不是 WACC（加权平均资本成本）里的债务成本 $k_d$：后者是公司今天借新钱要付的市场利率（5.5.2.3.5）。解释过去的 ROE 用 $i$；判断未来加杠杆是否划算，要用 $k_d$。

等式要严格成立，ROIC 和 ROE 的口径必须对应。有两种对应方式，用青禾年初数据各算一遍（$D = 220$，利息 10，$i(1-t) = 10 / 220 \times 75\% = 3.41\%$）：

| | 口径一：现金留在分母里 | 口径二：现金从两边都剔除 |
|---|---|---|
| ROIC | $127.5 / (220 + 400) = 20.56\%$ | $127.5 / (220 + 400 - 100) = 24.52\%$ |
| D/E | $220 / 400 = 0.55$ | $220 / (400 - 100) = 0.733$ |
| 按公式算的 ROE | $20.56\% + 0.55 \times 17.15\% = 30.0\%$ | $24.52\% + 0.733 \times 21.11\% = 40.0\%$ |
| 直接算的 ROE | $120 / 400 = 30\%$ | $120 / (400 - 100) = 40\%$（"不含现金的 ROE"） |

口径二的 40% 告诉你：青禾的股东权益里有 100 是闲置现金，几乎不赚钱，把报告 ROE 从 40% 稀释到了 30%。如果现金有利息收入，口径二的分子还要扣掉税后利息收入。

这个等式最重要的用法，是看**杠杆怎样同时放大收益和损失**。还用口径一（$i(1-t) = 3.41\%$），比较两种借款水平：

| 经营回报（ROIC） | D/E = 0.55（青禾现状） | D/E = 2 |
|---|---|---|
| 20.56%（今年） | $20.56\% + 0.55 \times 17.15\% = 30.0\%$ | $20.56\% + 2 \times 17.15\% = 54.9\%$ |
| 1%（设想生意大幅变差） | $1\% + 0.55 \times (1\% - 3.41\%) = -0.33\%$ | $1\% + 2 \times (1\% - 3.41\%) = -3.82\%$ |

好年景里，D/E 为 2 的股东多赚了将近 25 个百分点；一旦经营回报跌到税后借款成本以下，借得越多亏得越多。同样的 ROE 提升，靠 ROIC 得来是生意变好了，靠杠杆得来是风险变大了（为什么加杠杆不创造价值，见 5.2.1.7）。

A股投资者更熟悉的是**杜邦分解**，它把 ROE 拆成三个因子：

$$
\text{ROE} = \frac{\text{净利润}}{\text{收入}} \times \frac{\text{收入}}{\text{总资产}} \times \frac{\text{总资产}}{\text{股东权益}}
$$

青禾（年初资产和权益）：$12\% \times (1000 / 700) \times (700 / 400) = 12\% \times 1.429 \times 1.75 = 30\%$。三个因子分别是净利率、资产周转率、权益乘数，前两项相乘就是"净利润 / 总资产"口径的 ROA。杜邦分解直观好记，但它的杠杆因子（总资产 / 权益）把经营负债和有息债务混在一起，净利率也已经扣了利息，经营和融资的影响没有分干净；上面的 ROIC 加杠杆公式把两者分开了。杜邦分解在 PB（市净率）分析里的用法见 5.5.4.3.1.6；杠杆与 ROE 在信用分析中的用法见 5.3.2.7.2。

> **投资者怎么用**：拿到一个 ROE，按顺序问三件事。第一，分子分母干净吗：永续债、优先股扣了没有，分母是不是被大额回购、累计亏损压得很小，账上有没有大量闲置现金把它稀释（像青禾的 30% 与 40%）。第二，用上面的公式把它拆成"ROIC"和"杠杆贡献"两块，看后一块占多少。第三，假设 ROIC 回落几个百分点，用同一个公式重算一遍 ROE；结果掉得越狠，这个 ROE 越不可靠。

## 5.3.1.1.5 衡量风险

会计报表对风险的处理有两个特点，读表时要心里有数。

**第一，会计关心的风险主要是违约风险**，即公司能不能按时还本付息、履行固定的支付义务。股东关心的是更宽的风险：实际回报偏离预期回报的程度。一家完全没有负债、盈利为正但波动很大的公司，在会计看来风险很低，在股东看来未必（估值中的风险怎样衡量，见 5.5.2.3）。

**第二，会计对风险的看法是静态的**：几乎所有比率都用某一个时点的资产负债表和某一年的利润表来算，回答的是"今天的家底能不能应付今天的义务"，而不是"情况变坏时还撑不撑得住"。

会计对风险的处理分两类：附注里的**信息披露**，和用报表算出的**财务比率**。

### 5.3.1.1.5.1 或有负债与表外承诺

**或有负债**是只有某个不确定事件发生时才会变成真实义务的潜在负债。最常见的是：未决诉讼和仲裁、对外担保、已背书或贴现但尚未到期的票据（出票人到期不付款，公司要承担追索责任）、产品质量保证、环保责任。

中国准则把它分成两种处理：

| 可能性 | 能否可靠计量 | 处理 |
|---|---|---|
| 很可能发生（通常理解为超过 50%） | 能 | 确认为**预计负债**，同时计入费用 |
| 可能发生，但达不到"很可能" | — | 只在附注里披露 |
| 极小可能 | — | 可以不披露 |

问题在于，"很可能"由管理层判断。很多潜在义务因此只在附注里有一段文字，资产负债表上什么都没有。

A股里，对外担保是或有负债中最需要警惕的一项。上市公司为控股股东、关联方或其他企业提供担保，被担保方一旦违约，上市公司就要代为偿还。有些公司还存在未履行审议程序、未披露的**违规担保**，事后爆出时，往往伴随股价大跌和公司陷入困境。

粗略估算一项担保的风险，可以用"担保金额 × 违约概率 ×（1 − 回收率）"。设想一家公司为一家关联企业的 10 亿元贷款提供担保，你判断这家关联企业违约的可能性约 20%，违约后能追回 30%，这项担保的期望损失约为 $10 \times 20\% \times 70\% = 1.4$ 亿元。这个数字很粗，但比假装它不存在要好。

**表外承诺**还包括：已签订但未履行的大额资本支出合同、长期照付不议采购合同、对子公司或合营企业的出资承诺、对赌协议中可能的业绩补偿或回购义务、"明股实债"安排中对其他投资者的回购承诺、衍生工具合约。它们分散在附注的"承诺及或有事项""关联交易""金融工具"等部分，没有固定位置。

> **投资者怎么用**：读年报时，把"或有事项"和"承诺事项"两节当作必读，并用一张表记下：对外担保余额（尤其对关联方的）、未决诉讼的涉案金额、已背书未到期的商业承兑汇票、资本承诺。担保余额占净资产比例高、被担保方经营困难的公司，账面负债率再低也不安全。

### 5.3.1.1.5.2 短期流动性：流动比率·速动比率

**短期流动性风险**来自日常经营的资金需要：公司往往要先付钱给供应商，过一段时间才能从客户那里收回钱，中间的缺口通常靠短期借款填。衡量它的两个最常用指标是：

$$
\text{流动比率} = \frac{\text{流动资产}}{\text{流动负债}}
$$

$$
\text{速动比率} = \frac{\text{流动资产} - \text{存货}}{\text{流动负债}} \quad \text{（严格口径：} \frac{\text{货币资金} + \text{交易性金融资产}}{\text{流动负债}} \text{）}
$$

流动比率小于 1，意味着一年内到期的义务超过了一年内能变成现金的资产。速动比率把变现慢的存货去掉；更严格的口径只保留现金和可以马上卖掉的证券，因为应收账款也不一定能及时收回。反过来，如果应收账款能证明可以很快变现（比如是银行承兑汇票），也可以放进分子。国内教材和数据库多用"流动资产减存货"的口径。

青禾：

| | 年初 | 年末 |
|---|---|---|
| 流动资产 | $100 + 80 + 120 = 300$ | $40 + 100 + 140 = 280$ |
| 流动负债 | $60 + 20 + 100 = 180$ | $70 + 30 + 100 = 200$ |
| 流动比率 | 1.67 | 1.40 |
| 速动比率（扣存货） | $180 / 180 = 1.00$ | $140 / 200 = 0.70$ |
| 速动比率（严格口径） | $100 / 180 = 0.56$ | $40 / 200 = 0.20$ |

青禾的流动性一年里明显变紧：现金从 100 降到 40，主要是因为买设备、还长期借款都用了自有现金，而短期借款 100 一分没还。这正是"用短期资金支撑长期投资"的苗头。

这两个比率要谨慎使用：

- **"流动比率最好在 2 以上"是过时的经验法则。** 流动性和效率之间有取舍：流动比率越高，压在营运资本里的钱越多。流动比率过高，有时反而说明存货卖不动、应收收不回。
- **流动负债的成分很重要。** 合同负债用发货来偿还，不需要现金。一家合同负债占流动负债一大半的白酒公司或会员制零售商，流动比率低一些也没有问题。青禾的流动负债里如果去掉合同负债 30，年末流动比率就是 $280 / 170 = 1.65$。
- **商业模式决定合理水平。** 超市、餐饮这类现金收款、对供应商赊账的生意，流动比率长期低于 1 很正常；而工程、设备类公司应收和存货占用大，流动比率高也不一定安全。
- **期末时点容易被"粉饰"。** 年末突击还掉短期借款再在年初借回来，或者年末集中收回应收款，都能让比率在报表日好看一天。
- **比率的变化方向取决于原来的水平。** 流动资产和流动负债同时增加相同金额（比如借 50 短期借款放在账上），比率原来大于 1 时会下降，原来小于 1 时会上升。

估值分析中更有用的现金短债比、受限资金剔除、债务期限结构等指标，见 5.3.2.7.4。

### 5.3.1.1.5.3 营运效率：应收·存货·应付周转

周转率衡量营运资本的使用效率：应收账款多久收回来，存货多久卖出去，供应商的钱多久付出去。

$$
\text{应收账款周转率} = \frac{\text{营业收入}}{\text{平均应收账款}}, \qquad \text{应收账款周转天数} = \frac{365}{\text{应收账款周转率}}
$$

$$
\text{存货周转率} = \frac{\text{营业成本}}{\text{平均存货}}, \qquad \text{存货周转天数} = \frac{365}{\text{存货周转率}}
$$

$$
\text{应付账款周转率} = \frac{\text{采购额}}{\text{平均应付账款}}, \qquad \text{应付账款周转天数} = \frac{365}{\text{应付账款周转率}}
$$

存货和应付用营业成本或采购额做分母，因为它们按成本记账；如果用收入，售价一变，天数就跟着变，哪怕存货管理毫无变化。应付账款严格说应该用采购额，因为它是因采购而欠下的；采购额报表上不直接给，可以用"营业成本 + 存货增加"估算。拿不到可靠的采购额时，实务中常直接用营业成本近似（5.3.2.5.5 就是这样做的）。存货变化不大的公司，两者差别很小；比较不同公司或不同章节的现金转换周期时，先确认应付天数的分母是同一个。

三个天数合起来，就是**现金转换周期**（CCC）：

$$
\text{现金转换周期} = \text{应收天数} + \text{存货天数} - \text{应付天数}
$$

它的意思是：从付钱给供应商，到从客户那里收回钱，中间公司自己要垫多少天。这段时间越长，营运资本占用的钱越多，短期流动性风险也越大。

青禾 2025 年：

| 指标 | 计算 | 结果 |
|---|---|---|
| 应收账款周转率 | $1000 / [(80 + 100)/2] = 1000 / 90$ | 11.1 次，约 **32.9 天** |
| 存货周转率 | $600 / [(120 + 140)/2] = 600 / 130$ | 4.6 次，约 **79.1 天** |
| 应付账款周转率 | $620 / [(60 + 70)/2] = 620 / 65$ | 9.5 次，约 **38.3 天** |
| 现金转换周期 | $32.9 + 79.1 - 38.3$ | **约 73.7 天** |
| 合同负债相当于几天收入 | $365 \times [(20 + 30)/2] / 1000$ | 约 9.1 天 |

青禾平均要自己垫 73.7 天的钱；经销商的预付款又帮它抵掉了约 9 天，实际约 64.5 天。

几个使用上的要点：

- **用平均余额还是期末余额？** 平均余额更贴近全年的实际占用；期末余额更能反映最新的状况。季节性强的公司（比如年底旺季备货），期末余额会严重偏离全年水平，有季度数据时最好用季度平均。同一组比较只用一种口径。
- **天数要看趋势和同行。** 应收天数从 33 天升到 50 天，同时收入增长加速，常常说明增长是靠放宽信用换来的；存货天数大幅上升，可能是需求放缓、产品滞销，也可能是为涨价囤货，要结合行业判断。
- **应付天数长不一定全是好事。** 它可能是议价能力的体现，也可能是公司付不出钱在拖欠供应商，或者是 5.3.1.1.3.1 提到的供应链金融在起作用。

这些天数怎样嵌进 ROIC（投入资本回报率）的分解树、用来解释资本周转率的变化，见 5.3.2.5.5。

### 5.3.1.1.5.4 长期偿债能力：债务负担与利息保障

长期偿债能力看两件事：**利润能不能付得起利息**，和**债务相对于家底有多重**。

**利息保障倍数**：

$$
\text{利息保障倍数} = \frac{\text{EBIT}}{\text{利息费用}}
$$

倍数越高，利润付利息的能力越强。青禾：$170 / 10 = 17$ 倍。但它有一个盲点：EBIT（息税前利润）的波动可能很大，经济下行时会急剧下跌。两家倍数相同的公司，一家利润稳定（公用事业），一家利润大起大落（周期性化工），风险完全不同。所以最好用几年的平均 EBIT，或者用周期低点的 EBIT 来算。

**固定支出保障倍数**把其他固定的支付义务也算进来，最主要的是租金：

$$
\text{固定支出保障倍数} = \frac{\text{EBIT} + \text{租金}}{\text{利息} + \text{租金}}
$$

一个经典的对比是 1998 年的波音和家得宝（单位：百万美元）：

| | 波音 | 家得宝 |
|---|---|---|
| EBIT | 1720 | 2661 |
| 利息费用 | 453 | 37 |
| 利息保障倍数 | 3.80 | 71.92 |
| 经营租赁费用 | 215 | 290 |
| 固定支出保障倍数 | $(1720 + 215) / (453 + 215) = 2.90$ | $(2661 + 290) / (37 + 290) = 9.02$ |
| EBITDA | 3341 | 3034 |
| EBITDA / 固定现金支出（利息 + 租金） | $3341 / 668 = 5.00$ | $3034 / 327 = 9.28$ |

家得宝几乎不借钱，利息保障倍数高达 72 倍；但它的门店大量是租来的，把租金算进去，倍数降到 9 倍。只看利息保障倍数，你会大大低估一家租赁密集型公司的固定支付压力。

还可以从现金流的角度看：用 EBITDA（息税折旧摊销前利润）代替 EBIT，除以全部固定的现金支出，也就是表里最后一行。波音的折旧大，换成 EBITDA 后倍数从 2.90 升到 5.00，但仍低于家得宝的 9.28。这类覆盖率都有一个共同的批评：**它们没有考虑资本开支**。短期内公司可以推迟设备更新，把钱拿去付利息；长期来看，不维持投资就无法维持经营。所以可以再看一个比率：

$$
\text{经营现金流 / 资本开支} = \frac{\text{EBIT}(1-t) + \text{折旧} - \text{营运资本增加}}{\text{资本开支}}
$$

分子是付利息之前、交税和满足营运资本需要之后的经营现金流。青禾：$(127.5 + 50 - 20) / 150 = 157.5 / 150 = 1.05$，经营产生的现金刚好够这一年的资本开支。1998 年波音和家得宝的这个比率分别是 1.36 和 0.81：用利息覆盖看，波音风险更大；把资本开支算进去，正在大规模开店的家得宝反而更紧。不同的比率给出不同的结论，这正说明任何一个单一比率都不够。

**负债率**衡量债务相对于资本的轻重：

$$
\frac{\text{债务}}{\text{资本}} = \frac{D}{D + E}, \qquad \frac{\text{债务}}{\text{股东权益}} = \frac{D}{E} = \frac{D/(D+E)}{1 - D/(D+E)}
$$

青禾年初 $D/(D+E) = 220 / 620 = 35.5\%$，$D/E = 55\%$；年末 $200 / 680 = 29.4\%$，$D/E = 41.7\%$。两个比率可以互相换算：年末 $29.4\% / (1 - 29.4\%) = 41.7\%$。

这里的"债务"指**有息债务**，不是资产负债表上的全部负债。国内常说的"资产负债率"= 总负债 ÷ 总资产，把应付账款、合同负债也算进去了。合同负债很高的白酒公司、预收房款很多的房企，资产负债率看起来很高，有息债务却可能不多；地产行业"三道红线"监管中第一条用的就是"剔除预收款后的资产负债率"，道理相同。

负债率还有几种变形：

- **只用长期债务**：长期债务 ÷（长期债务 + 权益）。理由是短期借款是临时的。但很多公司长期滚动短期借款、用短债支撑长期投资，只看长期债务会误导。青禾年末长期债务比率只有 $100 / 580 = 17.2\%$，可它的 100 短期借款一直没还。
- **用市场价值**：债务市值 ÷（债务市值 + 股票市值）。理由是有些公司的借债能力远超账面价值所反映的。股票市值容易得到，债务市值难一些，但多数情况下用债务账面值代替影响不大（5.3.1.1.3.3）。WACC（加权平均资本成本）的权重用的就是市值口径（5.5.2.3.3）。
- **包含其他索取权**：优先股、永续债（5.3.1.1.3.6）、租赁负债、养老金缺口最好单独列出或计入债务，而不是混在股东权益里。

估值分析里对利息保障倍数口径的细化（EBITA（息税及摊销前利润）还是 EBITDA，新租赁准则下怎样对应，A股财务费用为净额、利息资本化的处理），以及债务 / EBITDA、杠杆与信用评级的关系，见 5.3.2.7.1–5.3.2.7.2 和 5.5.2.3.5。

## 5.3.1.1.6 会计标准和实践差异：同一经济活动可能有不同会计呈现

前面几个小节里已经出现了很多"同一件事、不同记法"的例子。它们来自两个层面：**准则不同**，以及**同一准则下的选择不同**。

**准则层面。** A股公司执行中国企业会计准则，2006 年起与国际准则基本趋同；港股公司多用香港准则（与国际准则全面趋同）或国际准则，在内地注册的 H股公司也可以用中国准则；美股上市的中概股多用美国准则。几套准则在大多数问题上的相似之处多于差异，但仍有一些会影响比较的差别：

| 问题 | 中国准则 | 国际 / 香港准则 | 美国准则 | 对比较的影响 |
|---|---|---|---|---|
| 存货计价 | 不允许后进先出 | 不允许后进先出 | 允许后进先出 | 美国公司在通胀期利润可能偏低 |
| 存货跌价准备转回 | 允许 | 允许 | 不允许 | |
| 长期资产减值转回 | **不允许** | 除商誉外允许 | 不允许 | 中国公司一次性大额减值后不能"找回" |
| 开发支出资本化 | 满足条件可以 | 满足条件可以 | 基本不允许（软件等例外） | 研发大的公司，中国 / 国际准则下利润和净资产可能更高 |
| 投资性房地产 | 成本模式或公允价值模式 | 成本模式或公允价值模式 | 只能成本模式 | 选公允价值模式的公司，房价涨跌直接进利润 |
| 承租人的经营租赁 | 上表，折旧加利息 | 上表，折旧加利息 | 上表，但利润表仍记直线租金费用 | EBITDA、EBIT 不可直接比 |
| 支付利息的现金流分类 | 筹资活动 | 可选经营或筹资（2027 年起 IFRS 18 生效，一般企业须列筹资活动，取消选择） | 经营活动 | "经营现金流"口径不同 |
| 合并范围 | 以控制为基础 | 以控制为基础 | 以控制为基础，具体判断模型不同 | 少数股东权益在中国 / 国际准则下列入权益 |

**实践层面。** 即使在同一套准则下，公司也有大量选择。本节已经出现过的有：折旧方法和年限（5.3.1.1.2.2）、坏账计提比例（5.3.1.1.2.3）、存货计价方法（5.3.1.1.2.4）、金融资产分类（5.3.1.1.2.5）、开发支出资本化比例（5.3.1.1.4.2）、收入的总额法和净额法（5.3.1.1.4.1）、短期和低价值租赁是否上表（5.3.1.1.3.4）。还有一个常见的：政府补助可以按**总额法**（单独列为其他收益）或**净额法**（直接冲减相关成本费用）处理，选净额法的公司，毛利率会更高。

这些差异的结论有两层。

**第一，差异是可以解释和调整的，而且没有很多人以为的那么大。** 两家公司估值差了一倍，几乎从来不是因为会计准则不同。会计差异不改变现金流（除了通过税），也就不改变价值；它改变的只是你看到的利润、资产和比率。

**第二，正因为它改变了你看到的数字，未经调整就直接比较是危险的。** 一家按美国准则编表的中概股和一家 A股公司比 PE（市盈率），一家研发全部费用化的药企和一家大量资本化的药企比利润率，一家执行新租赁准则的连锁餐饮和它自己 2020 年的数据比 EBITDA（息税折旧摊销前利润），都会得出错误的结论。动手比较之前，先读附注里的"重要会计政策和会计估计"，把关键口径对齐。

> **投资者怎么用**：给每家研究的公司建一张"会计政策卡片"：收入确认时点、折旧方法与主要资产年限、坏账计提比例、存货计价、研发资本化比例、政府补助处理、租赁处理、主要的会计政策和估计变更。比较同行时，先比卡片，再比数字。卡片上一旦出现变化，就是你需要重新检查利润质量的信号（5.3.1.2）。

## 本节小结

会计报表回答了四个问题，每个问题都有它的强项和盲区：

| 问题 | 会计的答法 | 强项 | 盲区 | 后面怎么补 |
|---|---|---|---|---|
| 有哪些资产、值多少 | 历史成本，保守计量 | 分类清楚，可核对 | 自创的无形资产不在表上；账面价值偏离经济价值；增长资产完全看不到 | 5.3.1.2.1、5.3.2.2、5.3.2.8 |
| 钱是谁出的 | 负债 / 权益，按历史成本 | 流动负债接近市值 | 表外义务、债务市值、永续债的性质 | 5.3.2.2.7、5.5.3.4.3 |
| 赚了多少 | 权责发生制，三类支出 | 有配比，能看趋势 | "营业利润"不是经营利润；研发等误分；一次性项目混入 | 5.3.1.2.3–5.3.1.2.4、5.3.2.3 |
| 风险多大 | 违约风险，静态比率 | 能提示流动性和偿债问题 | 不衡量股东承担的经营风险；只看一个时点 | 5.3.2.7、5.5.2.3 |

**三句话**：

1. 资产负债表上每一行的变化，要么来自利润表，要么来自现金流量表；对不上的地方，就是最该追问的地方。
2. 会计数字是"按规则记下来的过去"，估值需要的是"按经济实质看到的未来"；读表的功夫在于知道每条规则在哪里偏离了经济实质。
3. 任何比率，先问分子分母是什么口径、和谁比、看了几年；单一年份、单一比率、不对齐口径的比较，结论往往是错的。
