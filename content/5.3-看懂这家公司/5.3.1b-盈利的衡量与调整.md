# 5.3.1b 盈利的衡量与调整

> 本文件覆盖 5.3.1「读懂会计报表」的第二个四级节点：5.3.1.2 盈利的衡量与调整。三张表的基本读法、资产与负债的计量、基础财务比率见 5.3.1.1。

> **本节新教**：会计资产负债表与经济资产负债表、盈利更新（滚动十二个月）、费用误分类（研发、租赁、融资费用）为什么要纠正、盈余管理的常见手法与识别信号、扣非与正常化的差别（扣非的定义见 5.3.1.1.4.3）、正常化盈利

> **在估值流程中的位置**：5.1.1.5 的第 2 步（重组财务报表，得到可用于估值的经营数据）的前半段。这一节先决定"哪一个利润数字值得相信、哪些要改"，5.3.2 再把改过的数字装进投入资本、NOPLAT 和自由现金流。

估值几乎总是从一个利润数字出发：公司口径的现金流从税后经营利润起算，股权口径的现金流从净利润起算，市盈率直接拿净利润做分母。可是年报上的那个利润，是会计准则、公司选择和管理层动机共同生产出来的。它可能太旧（去年的年报，今天公司已经变了样）；可能分错了类（研发本来是投资，却被当成了当期费用）；也可能被有意无意地修饰过（年末压货、少提坏账、一次性卖资产）。

这一节回答一个朴素的问题：**拿到一份利润表，哪些数字可以直接用，哪些要先改，怎么改。** 它和 5.3.2 的分工是：这里讲"为什么要改、改的方向、怎么识别"；5.3.2 讲改完之后怎样一行一行地装进估值报表。

**术语速查**

| 缩写 / 术语 | 中文 | 一句话解释 |
|---|---|---|
| EBIT | 息税前利润 | 扣利息和所得税之前的利润，近似"经营利润" |
| NOPLAT | 税后经营利润 | 只算经营业务、扣掉经营相关的税之后的利润，不扣利息 |
| ROIC | 投入资本回报率 | NOPLAT ÷ 投入资本 |
| ROE | 净资产收益率 | 净利润 ÷ 股东权益 |
| TTM | 滚动十二个月 | 最近连续四个季度（或两个半年）加起来的数字 |
| PE | 市盈率 | 股价 ÷ 每股收益，或市值 ÷ 净利润 |
| DSO | 应收账款周转天数 | 应收账款 ÷ 营业收入 × 365，收回货款平均要多少天（本节用期末余额，平均余额口径见 5.3.1.1.5.3） |
| 扣非净利润 | 扣除非经常性损益后的净利润 | A股按监管口径剔除"非经常性损益"后的归母净利润（定义和名单见 5.3.1.1.4.3） |
| 正常化盈利 | — | 剔除一次性因素、把波动项目平均化之后，公司在正常年份能赚的利润 |

## 5.3.1.2.1 会计资产负债表与经济意义上的资产负债表

先看一个问题。两家设想的调味品公司，生意几乎一样：品牌知名度相当，每年税后经营利润都是 60 万元，厂房设备和营运资本都占用 300 万元。区别只在品牌的来路：

- **甲公司**自己做品牌，过去十年每年投 30 万元广告，全部当期计入销售费用；
- **乙公司**五年前花 400 万元买下了一个现成的品牌，记成无形资产（使用寿命不确定，不摊销，只做减值测试）。

| | 甲（自建品牌） | 乙（买来品牌） |
|---|---|---|
| 厂房设备和营运资本 | 300 | 300 |
| 品牌在报表上的金额 | 0 | 400 |
| 报表上的投入资本 | 300 | 700 |
| 税后经营利润 | 60 | 60 |
| **报表算出的 ROIC（投入资本回报率）** | **20%** | **8.6%** |

两个品牌在经济上的分量差不多，报表却一个记 0、一个记 400。甲看起来是一门 20% 回报的好生意，乙只有 8.6%，低于大多数公司的资本成本。**会计资产记录的是"怎么来的"，经济资产关心的是"能带来多少现金"。** 两者经常不一致。

### 5.3.1.2.1.1 会计资产不等于经济资产

会计资产负债表的左边，大体是"公司为取得资源实际花过的钱，减去已经摊掉的部分"（历史成本、折旧、账面价值的含义见 5.3.1.1.2）。估值者心里的那张资产负债表不一样，它把公司拆成两块：

| 经济资产负债表 | | |
|---|---|---|
| **现有资产**：已经投下去、正在产生现金的业务 | | **债务**：对公司现金流的固定索取权 |
| **增长型资产**：未来将要做、预计能赚超额回报的投资 | | **股权**：对剩余现金流的索取权 |

两张表有四处关键差别。

**第一，增长型资产在会计报表上不存在。** 一家公司未来十年开新店、出新品能创造的价值，会计上记为零，因为钱还没花。这就是为什么高成长公司的市值可以是账面净资产的十倍：多出来的部分主要是增长型资产。估值时，DCF（折现现金流）通过预测未来的再投资和回报，把这块价值算进来（增长什么时候值钱，见 5.2.1.3）。

**第二，自己"做"出来的无形资产不上表。** 研发、品牌广告、员工培训、客户获取，这些支出的效果往往持续多年，但会计上大多当期费用化（理由是未来收益不确定、难以计量）。结果就是开头的甲乙公司：同样的品牌，自建的不上表，买来的上表。商誉也是一样，只有并购时才会出现。研发密集、品牌驱动的公司，报表上的资产会系统性地偏小。

**第三，表上有的，经济上未必有。** 反方向的偏差也常见：

| 科目 | 什么时候"有账无实" |
|---|---|
| 应收账款 | 对关联方或资金紧张客户的长期挂账，坏账准备提得不足 |
| 存货 | 过时型号、临期产品仍按成本挂账，跌价准备提得不足 |
| 在建工程 | 项目早已停滞或实际已投产，却长期不转固定资产 |
| 开发支出 | 研发资本化后形成的资产，项目实际已经失败 |
| 商誉 | 当初并购付了过高的价格，被收购业务的盈利已经大不如前 |
| 预付款项、其他应收款 | 金额大、对象模糊，有时是资金被占用的痕迹 |

**第四，金额按历史成本记，不按今天的价值记。** 二十年前买的工业用地、早年间按成本记账的股权投资，账面值可能远低于市值；反过来，周期高点建的产能，账面值可能远高于它今天能带来的现金。

这四点合起来，结论很简单：**不要拿账面资产当成"公司值多少钱"，也不要不加调整地拿它做 ROIC 和 ROE（净资产收益率）的分母。** 账面数字是起点，要先问上面四个问题。

### 5.3.1.2.1.2 账面负债不一定覆盖全部经济义务

负债一侧也有同样的问题：有些义务在经济上和借钱没有区别，报表上却看不到，或者藏在不起眼的地方。判断一项承诺是不是"类债务"，可以用三条标准：

1. **不可撤销**：公司没有权利单方面退出；
2. **金额基本固定**：付多少不随公司的销量、利润变化；
3. **不付会有类似违约的后果**：被起诉、被追偿、丧失资产。

三条都满足，它就该被当作债务。举一个简化的例子：设想一家职业体育俱乐部，和一位球员签了 5 年合同，每年保证支付 1000 万元，不论他是否上场。按 5% 的利率折现，这份合同相当于一笔约 4330 万元的债务：

$$
1000 \times \frac{1 - 1.05^{-5}}{5\%} = 1000 \times 4.3295 \approx 4330 \text{ 万元}
$$

资产负债表上可能一分钱借款都没有，但这家俱乐部实际已经背上了固定的偿付义务，现金流不好的年份同样会陷入困境。

拿这三条去检验 A股、港股里几种常见的安排：

| 形式 | 为什么像债务 |
|---|---|
| 新租赁准则执行以前（A股 2021 年、港股 2019 年）的经营租赁 | 长期固定租金，不可撤销，和借钱买资产相似（5.3.1.2.3.3） |
| 永续债 | 可以计入权益、可以不断延期，但票息通常会跳升，实际上多数会赎回（5.2.1.7） |
| 商业承兑汇票、供应链金融 | 本质是延期付款融资，到期必须兑付，部分还有贴息 |
| 回购承诺、对赌条款（"明股实债"） | 到期按固定价格回购股权，金额固定、不能退出 |
| 设定受益养老义务、弃置费用 | 长期、金额可估计、无法回避的未来支付（5.3.2.8.4–5.3.2.8.5） |

对外担保、未决诉讼这类义务只满足一部分条件：要不要付、付多少取决于一个不确定事件，所以要先乘上发生的可能性再计入。这些项目在附注的哪里找、怎么粗算期望损失，见 5.3.1.1.5.1。

2021 年前后一些内地房企的经历就是现成的教训：表内有息负债看上去可控，商票、明股实债、合作项目的回购承诺等加在一起，真实的偿付压力要大得多。这些类债务项目在估值时怎样从经营价值里扣除，见 5.5.3.4。

### 5.3.1.2.1.3 估值要把会计分类重新翻译成经营、融资和非经营项目

会计报表按"流动 / 非流动""资产 / 负债 / 权益"分类，服务于债权人保护、审计、纳税等很多目的。估值只关心三个问题：经营业务占用了多少资本、赚了多少；公司欠了出资人什么；有哪些资产和主营业务无关、要单独估值。所以每一个科目都要重新翻译：

| 估值分类 | 资产负债表上的典型科目 | 利润表上的对应项目 |
|---|---|---|
| **经营** | 应收、存货、固定资产、使用权资产、应付账款、合同负债 | 收入、营业成本、期间费用、正常的坏账和存货跌价 |
| **融资** | 借款、债券、租赁负债，以及上一小节的各种类债务 | 利息费用 |
| **非经营** | 富余现金、理财、联营企业投资、闲置物业 | 利息收入、投资收益、公允价值变动 |

翻译的原则只有一条：**资产负债表上归到哪一类，利润表上对应的收益和费用就归到哪一类**，分子分母要对得上。这一节后面讲的各种调整，最终都落在这三类里。逐个科目怎么划、为什么这样划、划完怎样得到投入资本和 NOPLAT（税后经营利润），见 5.3.2.1。

## 5.3.1.2.2 盈利更新：旧财报、最新信息与正常化盈利

假设今天是 11 月初，你要给一家 A股公司估值。最新的年报是去年 12 月 31 日的数字，距今已经十个月；这期间公司又发布了一季报、半年报和三季报。如果公司变化得快，用十个月前的年报做起点，就等于在估值一家已经不存在的公司。

**滚动十二个月（TTM）** 是最常用的更新办法：用最近连续四个季度的数字，代替最近一个会计年度的数字。A股的季报、半年报给的是"年初至报告期末"的累计数，所以算法是：

$$
\text{TTM} = \text{最近一个年度} + \text{今年累计至最新报告期} - \text{去年同期累计}
$$

设想一家消费电子公司"云帆电子"，单位亿元：

| | 2024 年报 | 2024 年前三季度 | 2025 年前三季度 | TTM（2024Q4–2025Q3） |
|---|---|---|---|---|
| 营业收入 | 100 | 70 | 105 | $100 + 105 - 70 = 135$ |
| 归母净利润 | 8.0 | 5.5 | 9.0 | $8.0 + 9.0 - 5.5 = 11.5$ |

TTM 净利润比年报高出 44%（$11.5 / 8.0 - 1$）。如果公司市值 230 亿元，按年报算的静态 PE（市盈率）是 28.75 倍，按 TTM 算只有 20 倍。同一时刻、同一家公司，看哪个数字，结论就差很多。

TTM 的好处是它始终包含完整的四个季度，**季节性自动抵消**：零售公司的四季度旺季、空调公司的二季度旺季，都不会被多算或漏算。这比"最新一个季度 × 4"的年化方法稳妥得多，后者只在公司增长极快、季节性又很弱时才勉强可用。

更新也有代价，要心里有数：

- **季报信息少。** A股季报不经审计，附注很简略：研发投入中资本化多少、非经常性损益的明细、股权激励的进展，往往只有年报和半年报才说清楚。缺的项目只能沿用年报，或者按收入同比例推算，这会造成口径不完全一致。
- **港股多数只有半年报。** 主板公司强制披露的是年报和中期报告，TTM 只能用"年报 + 本期中期 − 上年中期"，信息天然比 A股晚一些。两次报告之间，可以参考公司公告、经营数据月报、管理层交流纪要等非正式信息，但要标明是估计。
- **资产负债表项目用最新一期。** 现金、债务、股本这些时点数，直接用最近一期报表的数字，不需要"滚动"。股本变动大的公司（刚增发、刚回购、大量股权激励行权），每股数字一定要用最新股本。
- **业绩预告和快报。** A股公司在满足一定条件（如亏损、扭亏、利润大幅变动）时，要在年报之前发布业绩预告或快报。它们未经审计、只有几个核心数字，但比等年报及时。

更新解决的是"新不新"的问题，没有解决"正不正常"的问题。TTM 正好包含了一笔 3 亿元的卖地收益，或者正好处在行业景气的顶点，它仍然是一个最新的、却不能外推的数字。估值需要的起点是**正常化盈利**：剔除一次性因素、把大起大落的项目平均化之后，公司在一个正常年份能赚到的利润。它的直觉很简单，后面的终值、倍数、增长率都要从一个"正常"的基数出发，基数错了，乘上再好的倍数也是错的。正常化的具体方法放在本节最后（5.3.1.2.4.6），因为要先把各种扭曲利润的因素认清楚；周期公司的正常化另有一套方法，见 5.6.2.1.2。

> **投资者怎么用**：对变化快的公司（新上市、高增长、业务转型、周期拐点），一律先做 TTM 更新，再谈正常化。对变化慢的公司，年报数字和 TTM 差别不大，可以直接用年报，把精力放在正常化上。

## 5.3.1.2.3 纠正盈利分类错误

公司花出去的每一笔钱，按经济性质分成经营性、资本性、融资性三类，定义和"收入 − 经营性支出 = 经营利润"的公式见 5.3.1.1.4.2。估值关心的是它们**应该怎样进利润表**：

| 类别 | 应该怎样进利润表 |
|---|---|
| 经营性支出 | 当期全部扣除，在 EBIT（息税前利润）之上 |
| 资本性支出 | 当期不扣，按使用年限分期折旧或摊销 |
| 融资性支出 | 不进经营利润，在 EBIT 之下扣除 |

会计报表大体也是这样做的，问题出在**分错了类**：有些资本性支出被当成了经营性支出，有些融资性支出被当成了经营性支出，还有些经营性支出被藏进了资本性支出。每一种分错，都会同时扭曲利润和资本两个数字，进而扭曲 ROIC（投入资本回报率）。下面三个四级小节逐一纠正。

### 5.3.1.2.3.1 经营费用与资本支出的误分

**会计上的保守，造成了经济上的错配。** 会计准则要求研发、广告、培训这类支出大多当期费用化，理由是它们的未来收益不确定、难以可靠计量。从防止虚增资产的角度看，这很合理；但从估值的角度看，它带来三个后果：

1. **资产被低估**：多年积累的研发成果、品牌、人才团队不在资产负债表上，投入资本偏小；
2. **当期利润被扭曲**：投入在增长时，当期费用大于"应该摊到本年的部分"，利润被压低；投入在收缩时，反过来，利润被抬高；
3. **再投资看不见**：这些支出本来是为未来增长做的投资，却没有出现在资本开支里，你会以为这家公司"增长不需要再投资"，从而高估增长的质量（增长需要再投资的道理见 5.2.1.2）。

**什么样的费用应该当作投资？** 判断标准是：**有没有足够的证据表明，这笔支出的效益会持续多个时期。**

| 支出 | 效益持续多年的证据 | 通常的判断 |
|---|---|---|
| 研发（医药、半导体、高端装备） | 专利、产品管线、多年的产品生命周期 | 有，倾向于当作投资 |
| 品牌广告（白酒、乳业、调味品） | 品牌认知多年不衰、产品能持续溢价 | 有一部分，但要和促销返利分开 |
| 渠道返利、进场费、促销折扣 | 本质是降价，停了销量就掉 | 没有，是经营费用 |
| 咨询、IT 服务公司的招聘和培训 | 员工平均在职多年，培训成果随人留下 | 视员工流失率而定 |
| 互联网平台的补贴获客 | 要看用户补贴停止后是否留存 | 争议最大，要有留存数据支撑 |

最后一行值得多说一句。外卖、网约车、社区团购这些行业都打过补贴大战，管理层通常会说"补贴是获客投资，用户会留下来"。如果真是这样，补贴确实该当作资本支出；但如果用户只认价格，补贴一停就转向对手，它就是不折不扣的经营成本。**另一种看法**认为，获客成本应当一律资本化，因为平台的价值就在用户规模上。本体系的取舍是：资本化要有证据，比如分批次的用户留存率、补贴退坡后的订单量变化；拿不出证据时，按经营费用处理，宁可低估利润，也不要把烧掉的钱记成资产。

**一个手算例子：研发资本化会把数字往哪个方向推？** 设想一家创新药公司，研发成果平均可用 3 年。过去四年的研发支出依次为 40、60、80、100（最后一年是今年），每笔研发从次年起每年摊销 1/3。报告的 EBIT 是 50（已扣今年研发 100），年初报表上的投入资本 500。为简化，本例用税前口径，不考虑税（研发费用实际已经在税前扣除过，资本化只是重新归类，不改变税负）。

| | 金额 | 计算 |
|---|---|---|
| 今年的研发摊销 | 60 | $(80 + 60 + 40) / 3$ |
| 年初的研发资产 | 133.3 | $80 + 60 \times \frac{2}{3} + 40 \times \frac{1}{3}$ |
| 年末的研发资产 | 173.3 | $100 + 80 \times \frac{2}{3} + 60 \times \frac{1}{3}$；核对：$133.3 + 100 - 60 = 173.3$ |
| 调整后 EBIT | 90 | $50 + 100 - 60$ |
| 调整后年初投入资本 | 633.3 | $500 + 133.3$ |
| 税前 ROIC：报告口径 | 10.0% | $50 / 500$ |
| 税前 ROIC：资本化后 | 14.2% | $90 / 633.3$ |

这个例子里，资本化之后 ROIC 反而**上升**了。原因是研发在快速增长，当期费用 100 远大于本该摊到今年的 60，报告利润被压得很低。反方向的情形同样常见：一家利润率很高、研发规模大而稳定的公司，资本化后分母增加的比例大于分子，ROIC 会**下降**。美国生物技术公司安进（Amgen）2008 年的数据就是这样：按 10 年摊销期把研发资本化之后，税前资本回报率（经营利润 ÷ 投入资本，和上面的例子一样不扣税）从约 25.4% 降到约 20.5%，ROE（净资产收益率）从约 23.5% 降到约 18.6%。仍然很高，但不再是"不可思议"的高。

所以研发资本化的意义不在于把数字做高或做低，而在于**让研发密集的公司和重资产公司能放在同一把尺子上比较**。A股还有一个特殊情况：准则允许开发阶段的支出在满足条件时资本化，同行之间资本化的比例可以从零到一半以上，比较前必须先统一口径。摊销期怎么选、历史数据怎么用、A股开发支出怎样还原，完整做法见 5.3.2.8.2。

> **投资者怎么用**：不是每家公司都要做研发资本化（节俭原则）。研发占收入超过 5%、研发支出增长很快或者同行资本化比例差别很大时，才值得动手；其他时候，在 ROIC 旁边注一句"未含研发资产"就够了。

### 5.3.1.2.3.2 研发费用资本化处理

上一小节讲的是"为什么"：研发的经济性质是投资。这里补充三个读报表时最容易误会的地方。

**第一，估值意义上的"资本化"和会计上的"资本化"是两回事。** 会计资本化是公司自己决定把一部分开发支出记成资产，它会直接抬高当期利润，管理层有动机多做（5.3.1.2.4.2）。估值资本化是分析者自己动手，把**全部**研发（无论公司怎么记）统一当作投资处理，目的是可比，不是美化。两者的方向甚至可能相反：你要先把公司已经会计资本化的部分还原回来，再按自己的摊销期统一资本化。

**第二，资本化不改变自由现金流，也就不改变价值。** 研发支出从"费用"挪到了"资本开支"，经营利润多了多少，再投资就多了多少，自由现金流不变。它改变的是你对两个驱动因素的判断：ROIC 到底是多少、增长需要多少再投资。如果你做完研发资本化，发现估值结果变了，多半是哪里做错了（5.3.2.8 有同样的检查）。

**第三，税不用调整。** 研发费用在计税时实际已经扣除过（A股还有研发费用加计扣除），这个税盾是真实的、和经营相关的。分析者把它重新归类为投资，并不会让公司补交税款，所以 NOPLAT（税后经营利润）里的税保持报告的实际水平即可。

### 5.3.1.2.3.3 租赁的经营与融资属性

租一间店铺 10 年，和借钱买下这间店铺，经济上非常接近：都长期占用店铺，都背上一串固定的付款义务。区别只在法律形式。可在旧的会计处理下，两者看起来完全不同：

| | 借钱买店 | 长期租店（旧准则下的经营租赁） |
|---|---|---|
| 资产负债表 | 店铺资产 + 借款 | 什么都没有 |
| 利润表 | 折旧在经营费用里，利息在财务费用里 | 全部租金都在经营费用里 |
| 结果 | — | 资产更轻，经营利润偏低（租金里含了利息），ROIC 偏高，杠杆看起来为零 |

租金里其实包含两部分：出租人收回资产成本的部分（相当于折旧）和出租人要的资金回报（相当于利息）。后者是**融资性支出**，却被当成了经营性支出。纠正的思路是：把未来租金按税前债务成本折现，得到一笔"租赁债务"；资产方加上同样金额的租赁资产；经营利润加回租金里隐含的利息。

这个问题在中国已经大体由新租赁准则解决了：绝大多数租赁要在表上确认使用权资产和租赁负债，租金拆成折旧和利息。准则的执行时间、短期和低价值租赁的豁免、可变租金不进租赁负债，以及新旧准则下报表怎样变化的例子，见 5.3.1.1.3.4。这里从"融资还是经营"的角度补两点：

1. **售后回租**：把自有设备卖给融资租赁公司再租回来，常被当作"盘活资产"，本质是一笔抵押借款，应该当作融资（5.2.1.7）。豁免上表的那部分租金（比如商场按销售额"扣点"的可变租金），经济上仍然是经营占用的场地成本，只是金额随销量变化、不满足"金额基本固定"那一条，所以留在经营费用里是合理的。
2. **EBITDA（息税折旧摊销前利润）口径会跳一下。** 新准则让餐饮、零售、航空这些租赁密集的公司 EBITDA 一下子变大，因为原来扣掉的租金现在变成了折旧和利息，都在 EBITDA 之下。经营没有任何变化。如果 EV（企业价值）里没有同时加上租赁负债，EV/EBITDA（企业价值倍数）会显得更便宜；把租赁负债加进 EV，分子分母一起变大，倍数未必下降。跨年份、跨准则比较时，要先把口径对齐。旧准则数据怎样手动资本化、新旧口径怎样换算，见 5.3.2.8.1。

### 5.3.1.2.3.4 融资费用与经营费用的区分

融资费用和经营费用的边界，在 A股报表上有几处特别容易混。

**一是财务费用是个"净额"。** 利润表上的财务费用 = 利息费用 − 利息收入 + 汇兑损益 + 手续费等。账上现金多的公司，利息收入超过利息费用，财务费用是负数，看起来"不但没有财务负担，还靠财务赚钱"。实际上这是两件不相干的事互相抵消了：利息费用是付给债权人的回报（融资），利息收入是富余现金的收益（非经营）。

设想一家公司营业利润 120，财务费用 −10，明细是利息费用 5、利息收入 18、经营性外币应收款产生的汇兑损失 3（$5 - 18 + 3 = -10$）。如果只想把融资和非经营的部分拿掉，得到经营利润（假设营业利润里没有其他非经营项目）：

$$
120 - 18 + 5 = 107
$$

利息收入要减掉，利息费用要加回，汇兑损失来自经营性的外币应收款，留在经营利润里。如果汇兑损益来自外币借款，就要和利息费用一起当作融资处理。

**二是利息可能藏在经营成本里。** 借钱建厂、借钱开发楼盘时，建设期的利息按准则可以资本化，计入在建工程或存货的成本。等资产完工或楼盘卖出，这些利息就以折旧或营业成本的形式进入经营费用。房地产公司最典型：设想一个项目营业收入 100，营业成本 75，其中资本化利息 8。报告的毛利率是 25%；把利息拿出来，开发业务本身的毛利率是 $(100 - 67) / 100 = 33\%$。比较两家房企时，一家杠杆高、资本化利息多，它的毛利率会被系统性压低，这不是经营差，而是融资费用跑到了经营成本里。

**三是经营往来里夹带的融资。** 几种常见情形：

| 情形 | 经济实质 | 怎么处理 |
|---|---|---|
| 应收票据贴现 | 拿未到期的票据向银行换现金，付出贴息，本质是短期借款 | 贴息属于融资费用；终止确认的贴现损失有时记在投资收益里，要留意 |
| 分期收款、长账期销售 | 收入里含着给客户的融资 | 新收入准则要求把重大融资成分拆出来，确认为利息收入 |
| 给客户的现金折扣 | 客户提前付款，公司让利，相当于付利息 | 金额小时可忽略 |
| 供应商给的长账期 | 供应商的融资成本藏在采购价里 | 已经体现在营业成本里，作为经营负债，不要再当成债务（5.3.2.1.2） |
| 带息的长期应付款（分期购买设备等） | 明确的借款 | 当作债务，利息作融资费用 |

判断规则就一句话：**一项负债的成本如果单独体现为利息，就是融资；如果已经包含在经营费用里，就留在经营一侧。** 不能两头都算，也不能两头都漏。

## 5.3.1.2.4 从会计盈利到真实盈利

前面讲的是"规则本身造成的偏差"：即使管理层完全诚实，研发也会被费用化，财务费用也是净额。这一节讲另一类偏差：会计准则给了管理层选择的空间，而管理层有动机去用这些空间。

**为什么要管理盈利？** 在美国市场，动机主要是"迎合分析师预期"。20 世纪 90 年代，微软在十年 40 个季度里有 39 个季度超过分析师的盈利预期；1996—2000 年，连续 18 个季度都是超预期的公司多于不及预期的公司。A股的动机更多样，而且常常和**硬性门槛**挂钩：

| 动机 | 门槛长什么样 | 容易诱发的操作 |
|---|---|---|
| 避免退市风险警示 | 利润总额、净利润、扣非净利润孰低者为负，且营业收入低于规定门槛 | 年末突击确认收入、做大贸易类收入、卖资产 |
| 再融资 | 增发、发可转债对盈利能力、ROE（净资产收益率）有要求 | 在申报前几年平滑利润 |
| 股权激励行权 | 行权条件通常是利润或收入增长率 | 把利润挪到考核年 |
| 并购业绩承诺 | 标的公司承诺三年左右的净利润 | 承诺期内"刚好达标"，期满后变脸 |
| 管理层更替 | 新管理层上任 | 第一年"大洗澡"，把损失集中计提，为以后几年留出增长空间 |

**市场好骗吗？** 没那么好骗。美国市场出现过"耳语预期"：一家公司连续多年超预期之后，市场私下的期望就会比公开的分析师预期再高一点。1997 年 4 月，英特尔公布的每股收益 2.10 美元高于分析师预期的 2.06 美元，股价反而下跌，因为耳语预期是 2.15 美元。市场能在多大程度上看穿会计数字，证据见 5.7.1.3。但"市场最终会看穿"不等于"你可以不看"：价格修正之前，相信漂亮数字的人已经付了高价。

下面六个四级小节，前五个各讲一类扭曲（收入、费用资本化、减值、准备金、非经营收益），最后一个把它们汇总成正常化盈利的方法。

### 5.3.1.2.4.1 收入确认是否激进或提前

收入是利润表的第一行，也是最常被做文章的一行，因为收入一动，利润、增速、市销率全都跟着动。

**常见形式：**

- **年末压货（渠道塞货）**：在报告期最后几周把货推给经销商，确认收入，同时给更长的账期或退货承诺。下一期销量就变差，或者出现大额退货。
- **提前确认**：按履约进度确认收入的业务（工程、定制软件、系统集成），进度本身是估计出来的，估得快一点，收入就早一点。
- **总额法和净额法**：贸易、平台类业务，如果公司只是代理（不承担存货风险、不能定价），应按净额（佣金）确认收入；按总额确认，收入能放大好几倍，利润却不变。它对利润没影响，但会让市销率和"营收门槛"失真。
- **循环交易和关联交易**：货物或资金在关联方之间转一圈，制造出收入和现金流。
- **反方向：藏起收入当蓄水池。** 好年份有意少确认，把收入留在预收款（合同负债）里，淡季再释放。这让利润平滑，同样会误导你对趋势的判断。

**识别信号与手算方法。** 设想一家家电公司，正常年份收入 1000，年末应收账款 150。第二年真实需求仍是 1000，但它在年底向经销商多压了 200 的货，并允许延期付款。毛利率 40%：

| | 第 1 年 | 第 2 年 | 第 3 年 |
|---|---|---|---|
| 营业收入 | 1000 | 1200 | 800 |
| 年末应收账款 | 150 | 350 | 150 |
| DSO（应收账款周转天数） | $150 / 1000 \times 365 = 54.8$ 天 | $350 / 1200 \times 365 = 106.5$ 天 | $150 / 800 \times 365 = 68.4$ 天 |
| 毛利 | 400 | 480 | 320 |

这里的 DSO 用年末应收账款计算，因为要看的正是年末那一下压货；用平均余额会把它摊薄（第 2 年按平均余额 $(150 + 350) / 2 = 250$ 算是 76.0 天，年末口径是 106.5 天；两种口径见 5.3.1.1.5.3，同一组比较只用一种）。

第二年毛利多出 80（$200 \times 40\%$），第三年还回去 80。只看收入和利润，第二年是一个"增长 20%"的好年份；看 DSO 就会发现收款天数翻了一倍，这 200 的收入并没有换成现金。

几个实用的检查指标：

| 指标 | 怎么算 | 警惕什么 |
|---|---|---|
| 应收增速 vs 收入增速 | 两者同比增长率对比 | 应收持续比收入增长快 |
| DSO | 年末应收账款 ÷ 营业收入 × 365 | 明显上升，或远高于同行 |
| 收现比 | 销售商品、提供劳务收到的现金 ÷ 营业收入 | 长期明显偏低。注意现金里含增值税，销售普通商品（税率 13%）的公司正常值在 1.1 左右，低于 1 就要问原因 |
| 第四季度收入占比 | 四季度单季收入 ÷ 全年收入 | 突然显著高于往年同期 |
| 合同负债的变动 | 收入 + 合同负债增加额 | 收入增长，但"收入 + 合同负债增加额"在下降 |

最后一项对先收款后发货的行业（白酒、部分家电和装修建材）特别有用。设想一家白酒公司 2023 年收入 90，合同负债从 25 增到 30；2024 年收入 100，合同负债从 30 降到 10。报告收入增长 11%，但"收入 + 合同负债增加额"从 $90 + 5 = 95$ 降到 $100 - 20 = 80$，经销商新打的款其实少了不少。2024 年的增长有一部分是在消耗以前的蓄水池。

### 5.3.1.2.4.2 费用资本化是否抬高当期利润

5.3.1.2.3.1 讲的是费用该资本化却没有资本化；这里是反方向：**本该当期扣除的费用，被放进了资产**，当期利润被抬高，代价推到了以后。

**常见形式和手算：**

**在建工程迟迟不转固。** 在建工程不计提折旧（规则见 5.3.1.1.2.2）。一条 10 亿元的产线已经投产，按 10 年直线折旧每年 1 亿元。如果它在账上继续挂着"在建工程"，就不用计提折旧；为它借的 6 亿元专门借款，利息（假设 5%，每年 0.3 亿元）还可以继续资本化。拖一年转固，当年税前利润多出 $1 + 0.3 = 1.3$ 亿元。识别信号：在建工程余额很大、多年不降，而公司已经在宣传产能投放。

**延长折旧年限、提高残值。** 年限变更怎样抬高利润的规则和例子见 5.3.1.1.2.2，这里看一项已经用了一半的资产。设想一批设备原值 1200 万元，原来按 8 年折旧，用了 4 年后账面净值 600 万元。如果把总年限改成 12 年，剩下的 600 万元要在 8 年里摊，每年折旧从 150 万元降到 75 万元，利润每年多出 75 万元。识别信号：年报"会计估计变更"一节，以及折旧额占固定资产原值的比例明显下降。

**开发支出资本化比例上升。** A股年报披露研发投入中资本化的比例。同一家公司这个比例突然从 10% 升到 40%，而研发项目没有明显进入后期，常常是在托当期利润。

**多生产、少销售：固定成本进了存货。** 制造业的固定制造费用（厂房折旧、管理人员工资）按产量分摊到每件产品上，卖不掉的那部分就留在存货里。设想单价 10、单位变动成本 4、每年固定制造费用 300：

| | 生产 100 件，卖 100 件 | 生产 150 件，卖 100 件 |
|---|---|---|
| 单位成本 | $4 + 300/100 = 7$ | $4 + 300/150 = 6$ |
| 营业成本（100 件） | 700 | 600 |
| 毛利 | 300 | **400** |
| 新增存货 | 0 | $50 \times 6 = 300$ |

销量一件没多，毛利多了 100，因为 100 的固定成本跟着 50 件存货留在了资产负债表上。识别信号：存货增速明显快于收入，毛利率却在上升。

**合同取得成本、长期待摊费用。** 新收入准则下，为取得合同发生的增量成本（如销售佣金）可以资本化后分期摊销；装修、某些营销支出也可能记入长期待摊费用。金额不大时无所谓，金额大且增长快时要看摊销期是否合理。

把这些合起来，一个通用的检查是：**利润增长是否长期明显快于经营现金流和收入的增长？** 如果是，就要逐项去找，费用是不是在资产负债表上找到了暂时的落脚点。

### 5.3.1.2.4.3 资产减值和一次性核销

**减值**是承认一项资产的可收回金额已经低于账面价值，差额一次性计入当期损失。A股常见的有两类：信用减值损失（应收款项）和资产减值损失（存货、固定资产、在建工程、无形资产、商誉、长期股权投资）。中国准则规定，固定资产、无形资产、商誉、长期股权投资等长期资产的减值一经确认，**以后不得转回**；存货跌价和应收坏账可以转回。

减值看起来是最"一次性"的项目，处理起来却要回答三个问题。

**第一，钱是什么时候花掉的？** 减值本身不花一分钱。钱在当初建厂、收购、备货的时候就花出去了，减值只是迟到的会计承认。所以在预测未来的经营利润时，减值通常应当剔除；但它告诉你一件更重要的事：**过去的投资没有赚到预期的钱**。A股 2018 年前后的商誉减值潮就是这样，超出协同效应的并购溢价在付款那一刻就毁灭了价值（5.2.1.7）。评估管理层的资本配置能力时，要把累计减值加回去看含商誉的 ROIC（投入资本回报率，5.3.2.5.1），不能因为减值冲掉了分母，就以为回报变好了。

**第二，它是不是在为以后"清仓"？** 一次性核销会降低以后的折旧和成本，让未来利润"自然"改善。设想一批设备账面净值 600，剩余使用寿命 6 年，每年折旧 100。今年减值 300 之后，以后每年折旧只剩 50，经营利润每年多出 50。这不是经营改善，是会计改善（立场第 6 条）。美国也有现成的例子：IBM 通过在关厂当年把老工厂核销，1996 年的折旧率降到 5%，而 1990—1994 年平均是 7%；按 1996 年的销售额，两种折旧率相差约 16.4 亿美元，占当年 90.2 亿美元税前利润的 18%。

这里有一个容易忽略的推论：**减值降低了折旧，但没有降低以后的设备更新开支。** 等这批设备用到头，换新仍要按市价花钱。所以做正常化时，维持性资本开支要按重置成本估，不能跟着减值后的低折旧走。

**第三，它是不是年年都"一次性"？** 一家公司如果今年计提存货跌价、明年计提重组费用、后年计提在建工程减值，名目年年不同，但每年都有，那它们合起来就是经常性的经营成本（5.3.1.2.4.6 的第二类）。

A股还有两个和减值相关的细节：

- **商誉减值不属于非经常性损益**（名单见 5.3.1.1.4.3），会直接减少扣非净利润。所以某一年扣非净利润大跌，要先看是不是商誉减值造成的。
- **业绩补偿收益**：并购标的没完成业绩承诺，原股东要向上市公司补偿股份或现金，这笔补偿按公允价值计入当期损益（列为非经常性损益）。常见的情形是同一年里商誉减值和业绩补偿收益同时出现，互相抵掉一部分，净利润看上去"损失不大"，但前者是经营的真实恶化，后者只是一次性的赔偿。

一次性重组费用在估值报表里怎样处理（不进 NOPLAT 即税后经营利润、准备金作为债务等价物），见 5.3.2.8.4.3；商誉和累计减值怎样进投入资本，见 5.3.2.2.3。

### 5.3.1.2.4.4 准备金的计提与转回

**准备金**是公司为未来可能发生的损失或支出提前计提的费用：坏账准备、存货跌价准备、产品质保、销售退回、预提返利。计提时减少当期利润，实际发生时直接冲减准备金，不再影响利润。准备金本身是对未来的估计，而估计就有弹性。

**利润对准备金的计提比例非常敏感。** 设想一家公司年末应收账款 2000 万元，过去按 5% 计提坏账准备，余额 100 万元。今年改为按 3% 计提，准备金余额降到 60 万元，差额 40 万元直接变成当年的利润。业务一点没变，利润多了 40 万元。预期信用损失模型和账龄组合的计提方法见 5.3.1.1.2.3，那里比较的是同行之间的差别；这里要盯的是**同一家公司自己调低比例**的那一年。

**转回和转销要分清。**

- **转回**：原来提多了，现在冲回来，直接增加当期利润。如果某一年利润里有大额的坏账准备转回，要问：是客户真的还钱了，还是估计变了？A股规定，单独进行减值测试的应收款项减值准备转回属于非经常性损益，但按组合计提的转回不属于，后者会直接留在扣非净利润里。
- **转销**：计提过跌价的存货卖出去时，跌价准备随之转销，相当于以减值后的低成本结转。它不增加利润，却会让当期毛利率"好看"。设想一批存货成本 100，2023 年原材料价格大跌，可变现净值只有 70，计提跌价 30；2024 年以 90 卖出。2024 年报告的毛利是 $90 - 70 = 20$，毛利率 22.2%；按原始成本算，这批货其实亏了 10。周期品价格大跌之后的那一年（比如锂电材料价格暴跌后的年份），这种"毛利率修复"很常见，不能当作经营好转外推。

**平滑。** 好年份多提，差年份少提或转回，报告利润就变得平稳，真实的波动被藏起来了。这种"收入平滑备抵"怎样识别和撤销，5.3.2.8.4.4 有完整的例子。读报表时，可以做三项检查：

| 检查 | 怎么做 | 警惕什么 |
|---|---|---|
| 准备金覆盖率 | 坏账准备 ÷ 应收账款，跌价准备 ÷ 存货 | 和自己的历史、同行相比明显偏低，或者突然下降 |
| 计提与利润的关系 | 逐年列出计提额（或转回额）和利润 | 利润好时多提、利润差时转回，时间上"恰好相反" |
| 会计估计变更 | 年报"会计政策和会计估计变更"一节 | 计提比例、账龄划分方法的调整 |

### 5.3.1.2.4.5 投资收益及其他非经营收益

A股利润表的"营业利润"里，除了主营业务，还混着好几类和经营无关的收益：

| 项目 | 常见来源 | 能不能外推 |
|---|---|---|
| 投资收益：理财、债券、交易性金融资产 | 闲置资金的收益 | 能持续，但对应的资产应单独估值 |
| 公允价值变动损益 | 持有的股票、基金、投资性房地产（公允价值模式）重估 | 不能，本质是市场价格的波动 |
| 投资收益：处置子公司、处置股权 | 卖掉一块业务；丧失控制权后剩余股权按公允价值重估的"纸面利得" | 不能，一次性 |
| 投资收益：联营 / 合营企业按权益法确认 | 持股 20%–50% 的公司的利润份额 | 能持续，但应按被投资公司的价值单独估 |
| 其他收益 / 营业外收入：政府补助 | 见下文 | 看性质 |
| 资产处置收益 | 卖旧设备、卖地、政府收储厂区给的补偿 | 通常不能 |
| 债务重组收益 | 债权人豁免部分债务 | 不能 |

**原则：把这些收益从经营利润里拿出去，把产生它们的资产单独估值，最后加回来。** 为什么不直接把它们留在利润里，一起乘个倍数？因为会犯两种方向相反的错误。

设想一家化工公司"恒远化工"，归母净利润 12 亿元，其中：经营业务赚 8 亿元；账上 50 亿元理财，税后收益率 2%，贡献 1 亿元；今年卖掉一家子公司，一次性收益 3 亿元（收到的现金已经在理财余额里）。可比公司的 PE（市盈率）是 15 倍。

| | 直接用 15 倍乘全部利润 | 分开估值 | 差异 |
|---|---|---|---|
| 经营业务 | $8 \times 15 = 120$ | $8 \times 15 = 120$ | 0 |
| 理财 | $1 \times 15 = 15$ | 50（按资产价值） | **低估 35** |
| 处置子公司收益 | $3 \times 15 = 45$ | 0（明年不会再有，现金已计入理财） | **高估 45** |
| 合计 | 180 | 170 | |

理财收益率只有 2%，乘 15 倍等于只按 30% 的价格给这笔现金估值；一次性收益乘 15 倍，等于假设明年、后年每年都能再卖一家子公司。两个错误碰巧部分抵消，但方向和大小都不受你控制。

**卖出证券的收益为什么不能预测？** 把它放进预测，等于相信公司未来每年都能以高于成本的价格卖出证券。除非这家公司的主业就是投资（券商自营、保险、投资控股公司），这个假设没有依据。金融机构的处理另见 5.6.1.1。

**经常性的资产处置。** 有些公司卖资产是商业模式的一部分，比如汽车租赁公司定期把旧车卖掉换新车。这时不能把处置收益简单剔除了事，而应该把处置收回的现金当作资本开支的减项。设想一家公司每年资本开支 10 亿元，折旧 6 亿元，处置旧资产收回 2 亿元，它的净资本开支是 $10 - 6 - 2 = 2$ 亿元，而不是 4 亿元。

上面这些收益，处理方向都比较明确：要么单独估值，要么剔除，要么转成资本开支的减项。政府补助难在同一个科目里混着几种性质完全不同的钱，有的跟着销量年年来，有的有明确的退坡期限，有的只此一次，还有的是早年收到的现金在今天做会计分摊。所以**政府补助要单独说**，先按性质分开，再决定怎么处理：

| 类型 | 例子 | 处理 |
|---|---|---|
| 和经营量挂钩、按固定标准持续享受 | 软件企业增值税实际税负超过 3% 的部分即征即退 | 可视为经营的一部分，但要盯住政策的期限和变化 |
| 行业扶持、但有明确退坡安排 | 新能源汽车购置补贴（2022 年底终止） | 预测期内按退坡路径递减，到期归零 |
| 一次性、和经营量无关 | 招商引资奖励、上市奖励、搬迁补偿、某个项目的专项资金 | 剔除 |
| 与资产相关的补助 | 建厂时拿到的设备补贴，先记递延收益，再随折旧分期转入损益 | 现金在拿到当年已经收到，以后每年转入的"收益"只是会计分摊，不是新的现金 |

新能源汽车的例子说明，"持续享受"的补助也会退出。补助占利润比重很高的公司，估值时最好分两种情形算：有补助和没有补助，差额就是政策风险的价格。

### 5.3.1.2.4.6 剔除不可持续、异常和一次性项目

现在把前面所有的扭曲汇总起来，得到估值要用的起点：**正常化盈利**。

**基本规则很简单：作为预测基础的利润，应该只反映持续的经营，不包含一次性或异常项目。** 难的是"一次性"在现实里有好几种样子。按出现的频率和规律，可以分成四类，各自的处理方法不同：

| 类型 | 例子 | 处理方法 |
|---|---|---|
| **① 真正的一次性** | 十年来唯一的一次大额重组、一次性搬迁补偿、卖掉一家子公司 | 剔除 |
| **② 不是每年有，但定期出现** | 每隔三年来一次的产品召回、每两三年一次的"一次性"重组 | 不能剔除，要按年平均摊入。每三年一次、每次 15 亿元，就每年扣 5 亿元 |
| **③ 每年都有，但金额波动大** | 每年都有、但大小不定的诉讼赔偿、存货跌价 | 取多年平均值代替当年值 |
| **④ 每年都有，但正负交替** | 汇兑损益：持有外币净资产的公司（如出口企业），本币升值年份为负，贬值年份为正；持有外币净负债的公司方向相反 | 长期平均接近零，预测时不计；如果波动很大，在风险里考虑 |

第②类最容易被忽略，也最危险。公司把它叫作"一次性"，分析者顺手剔除，未来每一年的利润就都被高估了。美国施乐公司 1997—1999 年的利润表里，存货费用、重组费用、"其他净支出"年年出现，名目和金额各不相同；这些反复出现的"一次性"费用本身就是经营出了问题的信号，施乐后来在 2000 年因为会计问题推迟提交年报。

**扣非净利润和正常化盈利差在哪里。** A股有一个现成的工具：扣非净利润。它是什么、非经常性损益的名单上有哪些项目，见 5.3.1.1.4.3。拿它和上面的四类规则对照，就能看出它为什么只能当起点：

1. **名单之外的一次性项目留在了扣非里。** 名单是事先列好的。商誉减值、大额存货跌价、按组合计提的坏账转回都不在名单上，哪怕它们完全是一次性的，也会留在扣非净利润里；第②类那种定期出现的召回费用，扣非既不剔除也不平均，哪一年发生就砸在哪一年。另一方面，年年都有的理财收益倒是被扣掉了，但理财资产仍然是股东的，只是要单独估值。
2. **公司有分类空间。** 政府补助算不算"与正常经营密切相关、按标准持续享受"，由公司自己判断并说明理由。同样性质的补助，有的公司列为经常性，有的列为非经常性，扣非数字因此并不完全可比。
3. **它仍然是股东口径**，扣了利息、含联营企业收益，适合算市盈率，不能直接拿来算 ROIC（投入资本回报率）。从扣非净利润走到 NOPLAT（税后经营利润）的调节见 5.3.2.3.2。

**另一种看法**：不少投资者把扣非净利润直接当作"真实利润"，理由是它由监管统一口径、经过审计、不同公司可比。这在快速筛选时确实好用。本体系的取舍是：筛选时用扣非，正式估值时以扣非为起点、按上面的四类规则再走一遍，因为监管名单解决的是"可比"，估值需要的是"可持续"。

**一个完整的例子。** 设想一家机械公司"华岳机械"，连续三年的利润构成如下（单位亿元，所得税率 25%，没有少数股东；商誉减值不能在税前扣除；该公司历史上在 2017、2020、2023 年各发生过一次约 0.9 亿元的产品召回）：

| | 2022 | 2023 | 2024 | 属于哪一类 |
|---|---|---|---|---|
| 核心经营利润（已扣利息） | 6.0 | 6.2 | 6.6 | 持续 |
| 理财收益 | 0.4 | 0.4 | 0.4 | 非经营，单独估值 |
| 汇兑损益 | 0.2 | −0.3 | 0.1 | ④ 正负交替 |
| 产品召回费用 | 0 | −0.9 | 0 | ② 每三年一次 |
| 商誉减值 | 0 | −1.6 | 0 | ① 一次性（但要记入资本配置的账） |
| 一次性政府补助（搬迁补偿） | 0 | 0 | 2.0 | ① 一次性 |
| **税前利润** | **6.6** | **3.8** | **9.1** | |
| 所得税 | 1.65 | 1.35 | 2.275 | 2023 年商誉减值不抵税：$(3.8 + 1.6) \times 25\%$ |
| **报告净利润** | **4.95** | **2.45** | **6.825** | |

三种口径的利润：

| | 2022 | 2023 | 2024 | 2024 年增速 |
|---|---|---|---|---|
| 报告净利润 | 4.95 | 2.45 | 6.825 | +178.6% |
| 扣非净利润 | 4.65 | 2.15 | 5.025 | +133.7% |
| 正常化盈利 | 4.275 | 4.425 | 4.725 | +6.8% |

算法说明：

- **扣非净利润**按监管名单只扣理财收益和政府补助（税后）：2022 年 $4.95 - 0.4 \times 75\% = 4.65$；2023 年 $2.45 - 0.3 = 2.15$；2024 年 $6.825 - (0.4 + 2.0) \times 75\% = 5.025$。商誉减值、召回费用、汇兑损益都不在名单上，留在了扣非里。
- **正常化盈利**用核心经营利润，扣掉召回费用的年均值 0.3 亿元（$0.9 / 3$），再按 25% 计税：2022 年 $(6.0 - 0.3) \times 75\% = 4.275$；2023 年 $(6.2 - 0.3) \times 75\% = 4.425$；2024 年 $(6.6 - 0.3) \times 75\% = 4.725$。

报告净利润说公司 2024 年利润增长了近两倍，扣非净利润说增长了 134%，正常化之后只增长了 6.8%。2023 年的低谷和 2024 年的高峰，几乎全部来自一次性项目的时间分布。如果你用 2024 年的增速去外推，或者拿 2024 年的高利润算出一个"便宜"的 PE（市盈率）、拿 2023 年的低利润算出一个"太贵"的 PE，结论都会错得很远。

再算一步估值上的含义。假设华岳机械市值 70 亿元，账上理财 20 亿元（收益率 2%，正好对应每年 0.4 亿元的理财收益）：

| 口径 | PE（市盈率） |
|---|---|
| 报告净利润 | $70 / 6.825 = 10.3$ 倍 |
| 扣非净利润 | $70 / 5.025 = 13.9$ 倍 |
| 正常化盈利 | $70 / 4.725 = 14.8$ 倍（分子含 20 亿元理财，分母已剔除理财收益，口径不一致，只作对照） |
| 正常化盈利，扣除理财后的经营业务 | $(70 - 20) / 4.725 = 10.6$ 倍 |

报告口径的 10.3 倍和最后一行的 10.6 倍看起来差不多，但含义完全不同：前者是用一个不可重复的利润算出来的"便宜"，后者是用可持续的经营利润、剔除了现金类资产之后的真实价格。数字接近只是巧合。

**正常化的操作步骤：**

1. **拉长时间。** 至少看五年，最好覆盖一个完整的行业周期。一年的数字分不清①②③类。
2. **列出全部非经营和非常规项目。** 从非经常性损益明细表开始，再补上不在名单里的：商誉减值、大额存货跌价、坏账准备的转回、召回和诉讼、会计估计变更的影响。
3. **逐项归类。** 按上面四类加"非经营、单独估值"一类，各自处理。
4. **检查税。** 剔除税前项目时，按适用税率算它的税后影响；不能抵税的项目（如商誉减值）不调税。
5. **对照现金。** 正常化之后的利润，和多年平均的经营现金流比一比。长期对不上，说明还有没找到的扭曲。
6. **记录假设。** 每一项调整写清理由。以后复盘时，你才能分清是"业务判断错了"还是"会计理解错了"（立场第 16 条）。

周期公司还要再加一步：把利润率放到周期的平均水平上，而不是只剔除一次性项目，方法见 5.6.2.1.2。正常化盈利会在后面多处用到：终值的起点 NOPLAT（5.5.2.4）、市盈率的分母（5.5.4.2.1.5）、增长率的计算基数（5.4.1.2）。

**盈利报告的预警信号。** 单独一个信号不能证明什么，几个同时出现，就值得花时间深挖：

| 信号 | A股报表上怎么看 | 可能的问题 |
|---|---|---|
| 利润增速连续几年远超收入增速 | 净利率持续抬升，却说不清靠什么 | 费用资本化、准备金释放、非经营收益 |
| "一次性"费用年年都有 | 非经常性损益明细、资产减值损失逐年对比 | 经常性成本被包装成一次性（第②类） |
| 费用率逐年大幅波动 | 销售、管理费用率忽高忽低 | 费用里混着非经营项目，或者在年度间腾挪 |
| 利润总是"刚好"达标 | 恰好达到股权激励、业绩承诺、再融资的门槛 | 盈余管理 |
| 利润很大一部分来自子公司或参股公司 | 投资收益占比高，关联交易多 | 通过定价在体系内转移利润 |
| 频繁变更会计政策和估计 | 折旧年限、坏账比例、收入确认方法的变更说明 | 用估计变更调节利润 |
| 并购之后利润跳升 | 并购当年和承诺期的增长 | 并购增厚的利润未必创造价值（5.2.1.7） |
| 营运资本随收入一起急剧膨胀 | 应收、存货增速远超收入，经营现金流和净利润背离 | 用赊销换收入，或者收入本身不实 |

> **投资者怎么用**：拿到一家公司，先把五年的报告净利润、扣非净利润、经营现金流并排放在一张表上。三条线大体同步，可以放心往下做；三条线分叉，先回到这一节，找到分叉的原因，再开始估值。

## 本节小结

1. 会计报表记录的是"怎么来的"，估值关心的是"能带来多少现金"。自建的无形资产和增长型资产不上表，表上的资产未必真值那么多，表外的承诺可能是真实的债务；所有科目最终都要翻译成经营、融资和非经营三类。
2. 先更新，再正常化。TTM 解决数字旧的问题，正常化解决数字不正常的问题。
3. 研发、品牌、培训等支出被当成费用，利息被藏进经营费用或净额里，都会同时扭曲利润和资本。纠正分类改变的是你对 ROIC 和再投资的判断，不改变自由现金流。
4. 盈余管理的手法集中在收入确认、费用资本化、减值、准备金和非经营收益五处，每一处都有对应的报表信号可查。
5. 扣非净利润是起点，不是终点。正常化盈利按"真一次性、定期出现、波动、正负交替"四类分别处理，非经营收益对应的资产单独估值。
