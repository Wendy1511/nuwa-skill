> **在估值流程中的位置**：5.1.1.5 的第 2 步（重组财务报表，得到可用于估值的经营数据）。它的产出是第 3 步（分析历史 ROIC、增长和现金流）的全部原料，也是第 4、5 步做预测的起点。

5.2.1 用小满茶饮算 ROIC 时，投入资本和税后经营利润都是现成的：哪项算、哪项不算，一张小表就列清楚了。真实的年报不会这样配合你。打开一家 A股公司的合并资产负债表，你看到的是四五十行科目：货币资金、交易性金融资产、应收款项融资、合同负债、使用权资产、一年内到期的非流动负债……利润表里的"营业利润"把理财收益、政府补助、利息支出都搅在了一起。这一节要做的，就是把这些科目一行一行地重新归类，得到估值真正需要的四个数：**投入资本、税后经营利润、投入资本回报率、自由现金流**。

这项工作枯燥，但几乎所有估值错误都能在这里找到源头：把理财算进了经营资产，ROIC 就被低估；把一次性补贴算进了经营利润，ROIC 又被高估；把应付票据当成经营负债还是借款，投入资本可以差出一大截。后面的预测和折现做得再精细，也救不回源头上的分类错误。

**术语速查**

| 缩写 | 中文 | 一句话解释 |
|---|---|---|
| IC | 投入资本 | 经营资产减去经营负债，经营业务实际占用的资本 |
| NOPLAT | 税后经营利润 | 只算经营业务、按"假设没有负债"计税之后的利润 |
| FCF | 自由现金流 | NOPLAT 扣掉净投资之后，能分给全部出资人的现金；严格说是 FCFF（公司自由现金流） |
| ROIC | 投入资本回报率 | NOPLAT ÷ IC |
| EBIT | 息税前利润 | 扣利息和所得税之前的利润 |
| EBITA | 息税及摊销前利润 | 在 EBIT 基础上再加回并购形成的无形资产摊销，本节用它作经营利润的起点 |
| EBITDA | 息税折旧摊销前利润 | 再加回折旧，常用来粗看现金生成能力 |
| CFO | 经营活动现金流 | 现金流量表第一部分的合计数 |
| OA / OL | 经营资产 / 经营负债 | 经营必需的资产 / 经营中自然形成、不付利息的负债 |
| NOA | 非经营资产 | 富余现金、理财、联营企业投资等，单独估值 |
| D / DE | 有息债务 / 债务等价物 | 借款、债券 / 租赁负债、养老金缺口等类似债务的义务 |
| E / EE | 股东权益 / 权益等价物 | 股本、留存收益 / 递延所得税、少数股东权益等 |
| IR | 再投资率 | 净投资 ÷ NOPLAT |

## 5.3.2.1 为什么要重组财务报表

### 5.3.2.1.1 会计报表服务于会计呈现，估值需要服务于经济分析

先看一个问题。两家设想的工厂，生产同样的产品，经营上完全一样：都占用 1000 万元经营资本，都有 200 万元经营利润，交 25% 的税后剩 150 万元。区别只在资产负债表的其他部分：

| | 甲厂 | 乙厂 |
|---|---|---|
| 经营占用的资本 | 1000 | 1000 |
| 账上另有闲置现金（年化 2%） | 500 | 0 |
| 借款（利率 5%） | 0 | 600 |
| 股东权益 | 1500 | 400 |
| 净利润 | $150 + 500 \times 2\% \times 75\% = 157.5$ | $150 - 600 \times 5\% \times 75\% = 127.5$ |
| ROE（净资产收益率） | $157.5 / 1500 = 10.5\%$ | $127.5 / 400 = 31.9\%$ |
| ROA（总资产收益率） | $157.5 / 1500 = 10.5\%$ | $127.5 / 1000 = 12.75\%$ |
| ROIC（投入资本回报率） | $150 / 1000 = 15\%$ | $150 / 1000 = 15\%$ |

ROE（净资产收益率）一个 10.5%，一个 31.9%，相差三倍；ROA（总资产收益率）也不一样。可这两家工厂的生意没有任何区别。差异全部来自两件和经营无关的事：甲厂囤了一笔闲钱，乙厂借了一笔钱。只有 ROIC（投入资本回报率）两家一样，因为它的分子分母都只算经营。

会计报表并没有做错什么。资产负债表的任务是**完整列出公司拥有什么、欠了谁什么**，利润表的任务是按会计准则**确认这一期的盈亏**，它们服务于债权人保护、纳税、监管、审计等很多目的。但估值要回答的问题是另一个：**经营业务占用了多少资本，每年赚回多少，能拿出多少现金**。会计报表按"流动 / 非流动"、按"资产 / 负债 / 权益"来分类，而估值需要按"经营 / 融资 / 非经营"来分类。这两种分类方式是交叉的，所以必须重组。

A股报表有几个特别容易误导的地方：

| 会计呈现 | 为什么会误导估值 |
|---|---|
| "营业利润"里包含投资收益、公允价值变动、其他收益（政府补助） | 一家公司理财做得好、补贴拿得多，营业利润就高，但经营本身未必更好 |
| 财务费用是利息费用减利息收入的净额 | 账上现金多的公司，财务费用甚至为负，看起来"没有财务负担"，其实只是两件事互相抵消 |
| 货币资金不区分经营必需和闲置 | 现金堆积的公司 ROA、ROE 被拉低，ROIC 如果不剔除现金也会被拉低 |
| 现金流量表里利息支付归在筹资活动，利息收入常归在经营活动 | 同样的公司，CFO（经营活动现金流）会因为现金多寡而高低不同；港股按国际准则编表，利息支付目前还可以选择放在经营活动或筹资活动，可比性更差（2027 年 IFRS 18（国际财务报告准则第 18 号）生效后，一般企业支付的利息基本统一归入筹资活动） |

表中第一行（投资收益、其他收益混入营业利润）的问题，5.3.1.2.4.5 讲过；第二行（财务费用是净额）的问题，5.3.1.2.3.4 讲过。这里把它们放在一起，是为了说明重组要一次性解决哪些问题。

### 5.3.2.1.2 把经营活动与融资活动分开

重组的第一刀，是把**经营**和**融资**分开。

经营活动是公司本身的生意：采购、生产、销售、收款，以及为此占用的厂房、设备、存货、应收款。融资活动是公司从哪里拿钱、给出资人什么回报：借款和还款、利息、分红、回购、发股。

为什么要分开？回到 5.2.1 的结论：ROIC 要和 WACC（加权平均资本成本）比，而 WACC 已经包含了债权人和股东两方的回报要求，包括利息的税盾。如果经营利润先扣了利息，再拿去和 WACC 比，就把债权人的回报算了两遍。所以 NOPLAT（税后经营利润）里不扣利息，投入资本也不区分是借来的还是股东的。资本结构对价值的影响，留到资本成本里去处理（5.5.2.3）。

落到资产负债表上，分界线在负债一侧：

- **经营负债**是做生意自然产生、不单独付利息的负债：欠供应商的货款、客户预付的货款、欠员工的工资、欠税务局的税。它们由经营带来，规模随经营变化。
- **融资负债**是公司主动去筹的钱，按合同付利息：银行借款、债券、租赁负债。

经营负债从经营资产中扣掉，融资负债和股东权益一起放在"资金来源"一侧。

> **另一种看法**：有人认为应付账款也是一种融资。供应商给你 60 天账期，其实收了隐含的利息，只是藏在了采购价里；那为什么不把它当成债务？
>
> 答案是口径一致。供应商隐含的利息既然已经算在采购价里，它就已经作为营业成本从 NOPLAT 里扣掉了。如果再把应付账款当成债务、让它的"利息"进入 WACC，同一笔融资成本就扣了两次。所以，**只要一项负债的成本已经体现在经营费用里，它就应该作为经营负债从投入资本中扣除**。反过来，如果一项负债的成本单独体现为利息（比如和供应商约定计息的延期付款，或者公司自己拿票据去贴现、自己承担贴息换来的资金），它就是融资负债。这条原则在后面判断应付票据、供应链金融时还会用到。

### 5.3.2.1.3 把经营资产与非经营资产分开

第二刀，是在资产一侧把**经营资产**和**非经营资产**分开。

非经营资产是公司拥有、但不参与主营业务的资产：超过经营需要的现金、银行理财、债券投资、对联营企业的股权、出租的房产等。它们有价值，但这份价值不由 ROIC 和增长决定，应该单独估值，最后加到经营价值上（5.5.3.4）。

分开的理由仍然是口径一致：如果把 500 万元理财放进投入资本，ROIC 的分母就变大，而理财 2% 的收益又没有进分子（或者进了分子，又把一项低风险、低回报的资产和高风险的生意混成一个平均数），算出来的 ROIC 既不反映生意，也不反映理财。

用启明精工算一下。2024 年它的 NOPLAT 是 231（怎么来的见 5.3.2.3），2023 年末的经营投入资本是 1341，ROIC 约 17.2%。如果把富余现金、理财、联营企业投资一起塞进分母，分母变成 1905，"ROIC"就只剩 12.1%。差出来的 5 个百分点，跟生意好坏没有关系。

### 5.3.2.1.4 把经营利润与非经营收益分开

第三刀在利润表上，对应前两刀：资产负债表上哪些资产被划出投入资本，它们带来的收益和损失也要划出经营利润；哪些负债被划为融资，它们的利息也要划出经营利润。

A股的利润表格式让这一刀特别重要，因为"营业利润"这个名字很容易让人以为它就是经营利润。下表是 A股利润表的常见项目和它们的归属：

| 利润表项目 | 归属 | 说明 |
|---|---|---|
| 营业收入、营业成本、税金及附加、销售 / 管理 / 研发费用 | 经营 | 主营业务的收入和费用 |
| 信用减值损失（应收坏账）、资产减值损失（存货跌价） | 通常经营 | 正常经营中反复发生；对应的应收和存货在投入资本里 |
| 资产减值损失中的商誉减值、大额固定资产减值 | 通常单独处理 | 不进 NOPLAT，见 5.3.2.2.3 |
| 财务费用中的利息费用 | 融资 | 付给债权人的回报 |
| 财务费用中的利息收入 | 非经营 | 来自富余现金 |
| 财务费用中的汇兑损益 | 看来源 | 经营性外币应收应付产生的，可以算经营；外币借款产生的，算融资 |
| 投资收益：理财、债券、处置股权 | 非经营 | 对应资产不在投入资本里 |
| 投资收益：联营 / 合营企业按权益法确认 | 非经营（单独估值） | 联营企业的资产不在投入资本里 |
| 公允价值变动收益 | 通常非经营 | 多来自交易性金融资产 |
| 其他收益（政府补助） | 看性质 | 与主营业务挂钩、按固定标准持续享受的（如软件企业增值税即征即退），可算经营；一次性补贴算非经营 |
| 资产处置收益、营业外收支 | 通常非经营 | 卖旧设备、罚款、捐赠等；如果年年都有且金额稳定，再单独判断 |

> A股投资者熟悉的"扣非净利润"（扣除非经常性损益后的净利润）也做了一部分这样的工作：它扣掉了理财收益、一次性补贴、资产处置损益等。但它**不是** NOPLAT：扣非净利润仍然扣了利息，仍然包含联营企业的收益，也仍然只属于股东。两者的差别在 5.3.2.3.2 用启明精工的数字算一遍。

### 5.3.2.1.5 最终得到 NOPLAT、投入资本、ROIC 和 FCF

三刀切完，报表就变成了一张"经济报表"。它的核心是两个恒等式。

资产负债表原来的恒等式是：

$$
\text{资产} = \text{负债} + \text{权益}
$$

把资产拆成经营资产（OA）和非经营资产（NOA），把负债拆成经营负债（OL）、有息债务和债务等价物（D + DE），把权益拆成股东权益和权益等价物（E + EE）：

$$
\text{OA} + \text{NOA} = \text{OL} + (\text{D} + \text{DE}) + (\text{E} + \text{EE})
$$

把经营负债挪到左边：

$$
\underbrace{\text{OA} - \text{OL}}_{\text{投入资本 IC}} + \text{NOA} = \underbrace{(\text{D} + \text{DE}) + (\text{E} + \text{EE})}_{\text{总投入资金}}
$$

左边是**钱用在了哪里**：经营占用了多少（投入资本），另外放了多少在非经营资产上。右边是**钱从哪里来**：债权人和股东一共提供了多少。两边相等，叫**总投入资金**。

这个恒等式给了你一个自查工具：投入资本可以从左边算（经营资产减经营负债，叫**经营法**），也可以从右边倒推（总资金来源减非经营资产，叫**融资法**）。两边对不上，说明某个科目被漏掉或者分重了。

利润表这边也对应一个关系：

$$
\text{NOPLAT} + \text{税后非经营收益} = \text{属于全部出资人的利润} = \text{净利润} + \text{税后利息} + \cdots
$$

有了 NOPLAT 和投入资本，ROIC 和 FCF（自由现金流）都只是代数：

$$
\text{ROIC} = \frac{\text{NOPLAT}}{\text{IC}}, \qquad \text{FCF} = \text{NOPLAT} - \Delta \text{IC} = \text{NOPLAT} + \text{折旧摊销} - \text{总投资}
$$

启明精工重组之后的结果如下，后面三个四级节点逐项推导：

| 指标 | 2023 年末 / 2024 年 | 2024 年末 |
|---|---|---|
| 投入资本 IC（含商誉） | 1341 | 1504 |
| 非经营资产 | 564 | 573 |
| 总投入资金 | 1905 | 2077 |
| 2024 年 NOPLAT | 231 | |
| 2024 年 FCF | 68 | |
| 2024 年 ROIC（期初投入资本） | $231 / 1341 \approx 17.2\%$ | |

ROIC 用期初、期末还是平均投入资本，含不含商誉，是 5.3.2.5 的内容。这里先用期初值，和 5.2.1 经济利润的口径一致。

## 5.3.2.2 投入资本：公司为经营到底占用了多少资本

投入资本（IC）回答的问题是：**为了让这门生意按现在的规模运转，出资人一共押进去了多少钱**。它不区分这些钱是借来的还是股东的，只看经营占用了多少。

通行的做法是把它拆成几块逐项计算，而不是笼统地写"经营资产减经营负债"：

$$
\text{IC} = \text{经营性营运资本} + \text{固定资产净值} + \text{商誉和购得的无形资产} + \text{其他长期经营净资产}
$$

### 5.3.2.2.1 经营性流动资本

**经营性营运资本**（也叫经营性流动资本，本体系统一称"营运资本"）= 经营性流动资产 − 经营性流动负债。它衡量的是公司在"买进—生产—卖出—收款"这个循环里垫了多少钱。

经营性流动资产包括经营必需的现金、应收票据和应收账款、预付款项、存货、合同资产，以及其他与经营相关的流动资产（如待抵扣的增值税进项税）。**不包括**富余现金、交易性金融资产、理财产品。

经营性流动负债包括欠供应商的（应付账款、经营性的应付票据）、欠客户的（合同负债、预收款项）、欠员工的（应付职工薪酬）、欠政府的（应交税费），以及其他与经营相关的应付款（如经销商保证金）。**不包括**短期借款、一年内到期的非流动负债、应付利息、应付股利，这些属于融资。

几个 A股报表里常见的判断：

**应付票据算经营还是融资？** 公司向供应商开出银行承兑汇票，相当于让银行担保"到期一定付款"，供应商因此愿意接受延期付款。它的本质是延长了对供应商的付款期，大多数情况下应当和应付账款一样算经营负债。但有两种情况要警惕。第一，票据实际上被用来从银行变相融资：没有真实的采购交易做背景（所谓融资性票据），或者开给关联方、供应商的票据贴现后，钱又流回了公司自己手里。这部分票据的成本是贴息，它其实是借款。至于公司为开票向银行存的保证金（体现为受限货币资金），它本身不会让票据变成借款，而是要和对应的应付票据配对来看（见 5.3.2.2.6.1）。第二，票据规模远远超过同行、增长远快于采购额，往往说明公司在用供应商和银行的钱撑现金流。判断方法仍然是 5.3.2.1.2 那条原则：它的成本藏在采购价里，就是经营负债；它的成本单独体现为利息或贴息，就是融资负债。

这个判断对数字影响不小。如果把启明精工的应付票据改为债务，2023 年末投入资本就从 1341 变成 1421，ROIC（投入资本回报率）从 17.2% 降到约 16.3%。

**供应链金融**是同一个问题的新形式。一些大型企业通过自建或合作的平台，向供应商开具可以拆分、转让、融资的电子债权凭证，供应商可以拿着凭证去贴现，贴现利息由供应商承担。账面上，这些凭证常常留在应付账款或应付票据里。对投资者来说，要看的是整体付款周期有没有被异常拉长：如果应付账款周转天数明显长于同行，"不花钱的经营负债"可能正在替代真正的借款，一旦信用收紧，这部分资金会很快收回。

**经营性营运资本可以是负数。** 先收客户的钱、后付供应商的钱，营运资本就会为负，等于客户和供应商在替公司出资。5.2.1 提到的贵州茅台就是例子。负营运资本让 ROIC 更高、增长所需的投资更少，是好事；但做预测时不能假设它会随规模无限扩大，供应商的耐心和客户的预付意愿都有边界，超过边界还会被评级机构当成违约风险的信号。

### 5.3.2.2.2 不动产、厂房和设备净值（PP&E）

PP&E（不动产、厂房和设备）净值，在 A股报表里对应固定资产、在建工程，以及性质相同的土地使用权（列在无形资产里，但在中国它就是厂房的地基）、预付设备款（列在其他非流动资产里，本质是还没到货的设备）。它们全部按账面净值进入投入资本。

**为什么用净值而不用原值？** 投入资本衡量的是"还被占用着的资本"。设备买了 10 年，折旧已经提了一大半，这部分折旧在过去每一年都从利润里扣过，相当于已经"收回"了。用原值会高估占用的资本；用净值，是和利润表的折旧口径保持一致。净值有一个副作用：老工厂的资产账面值很低，ROIC 会显得很高，新工厂刚投产 ROIC 却很低。比较两家公司时要留意资产的新旧（5.3.2.5.3），通胀很高的时期还要考虑按重置成本调整（5.3.2.8.7）。

**在建工程要不要算？** 主流做法是算：这些钱已经投进去了，出资人在为它承担资本成本。它的代价是，大规模扩产期间 ROIC 会被暂时压低，因为分母里有一块还没开始产生利润的资产。

> **另一种看法**：也可以把在建工程从投入资本里拿出来，单独看"已投产资产"的回报率。这样做更能看清现有产能赚多少钱，适合在建规模很大的公司（比如正在建新基地的制造企业）。本体系的处理：**算估值用的 ROIC 要包含在建工程**，因为价值只认全部投入；**分析经营质量时，可以另算一个剔除在建工程的 ROIC 作对照**，两个数差得越多，越要追问新产能投产后能不能达到老产能的回报。

| 项目 | 2023 | 2024 |
|---|---|---|
| 固定资产 | 800 | 870 |
| 在建工程 | 100 | 150 |
| 预付设备款 | 20 | 30 |
| 土地使用权 | 90 | 88 |
| **固定资产类合计** | **1010** | **1138** |

### 5.3.2.2.3 购得的无形资产和商誉

公司收购别的公司时，付出的价格高于对方可辨认净资产公允价值的部分，记为**商誉**；收购中识别出来的客户关系、技术、品牌等，记为**购得的无形资产**。

它们算不算投入资本，取决于你要回答什么问题：

- **含商誉的投入资本**回答"公司（包括为并购付出的溢价）给出资人赚了多少"。这是衡量价值创造的口径：股东真金白银付了这笔溢价，它也要赚回资本成本。
- **不含商誉的投入资本**回答"公司底层的生意本身赚多少"。这是衡量经营能力、和同行比较的口径。

两个口径都要算，比较方法见 5.3.2.5.1。这里要讲的是，算含商誉的投入资本之前，要做两项调整。

**第一项：把累计减值加回来。** 中国会计准则下商誉不摊销，每年做减值测试，减值了就一次性冲掉。2018、2019 年前后 A股出现过一轮集中的商誉减值，不少此前高溢价并购的公司一年就冲掉了大部分商誉。冲掉之后，商誉账面值变小，含商誉的 ROIC 一下子"变好"了。但股东当初付出的钱并没有回来，减值只是承认了这笔并购没赚到预期的钱。所以，衡量价值创造时，应该**把历史上累计的商誉减值加回到商誉里**，同时 NOPLAT（税后经营利润）也不扣商誉减值（它不是当年经营的成本，而是对过去投资的重新估计）。否则，并购越失败、减值越多，ROIC 看上去反而越好。

**第二项：补上没有记录的商誉。** 中国准则下，**同一控制下的企业合并**（比如集团把旗下资产注入上市公司）按被合并方的账面价值入账，不确认商誉，付出的溢价直接冲减资本公积。这样一来，同样是花大价钱买业务，一家公司账上有商誉，另一家没有。要比较两家公司含商誉的回报，可以把同一控制下合并支付的溢价补记为商誉，同时等额调增权益。

启明精工的商誉 60 是几年前收购一家小厂形成的，从未减值，不用调整。

购得的无形资产要不要按摊销前的原值计入投入资本，取决于它的摊销算不算经营成本，在 5.3.2.3.1 讲 EBITA（息税及摊销前利润）时一并讨论。

### 5.3.2.2.4 其他长期净经营资产

除了固定资产和商誉，资产负债表上还有一些零散的长期科目。处理原则是：**金额小、看不清内容的，默认当经营项目；金额大的，打开附注逐项判断**。

常见的长期经营资产有长期待摊费用（比如租入厂房的装修）、预付的长期设备款、长期合同资产。常见的长期经营负债有产品质保形成的预计负债、与资产相关的递延收益（政府补助）等。长期经营负债要从长期经营资产里减掉。

但长期科目里经常混着非经营项目，要挑出来：递延所得税资产和负债（见 5.3.2.2.8）、长期股权投资和各类金融资产（见 5.3.2.2.6）、长期应付款里的融资租赁款和售后回租款（见 5.3.2.2.7）、设定受益计划形成的长期应付职工薪酬（见 5.3.2.2.7.2）。

启明精工只有一项：产品质保的预计负债，2023 年 15、2024 年 17。客户买设备时，公司承诺免费维修两年，质保成本已经在销售当期作为费用扣了，钱要以后才花，等于客户替公司垫了一笔钱。它是经营负债，从投入资本里减掉。重组费用、弃置费用这类预计负债性质不同，见 5.3.2.8.4。

**与资产相关的递延收益**是 A股常见的科目。政府为支持某个项目给了一笔补助，公司先记为递延收益，再随资产折旧分期转入其他收益。中国准则允许两种方法：总额法（资产按全价入账，补助挂在递延收益）和净额法（补助直接冲减资产账面价值）。为了让两家公司可比，可以统一按净额法理解，把递延收益从固定资产里减掉，同时把它每年的摊销留在 NOPLAT 里。如果补助是一次性的、不可能再有，也可以反过来，把它当作权益等价物，摊销也不进 NOPLAT。哪种处理都行，关键是资产负债表和利润表的口径要一致。

### 5.3.2.2.5 隐藏资产及其对应融资

有两类资产，经济上是投资，会计上却没有完整地放在资产负债表上：租赁和费用化的投资（研发、广告）。它们为什么是"费用误分类"、会怎样扭曲 ROIC（投入资本回报率），5.3.1.2.3 已经讲过（租赁见 5.3.1.2.3.3，研发见 5.3.1.2.3.1–5.3.1.2.3.2）。这里只回答重组时的新问题：它们在投入资本表上落在哪里、有多大。

**第一类是租赁。** 新租赁准则执行之后（港股公司执行的是等效的 IFRS 16，即国际财务报告准则第 16 号），绝大多数租赁已经以**使用权资产**和**租赁负债**出现在表上（境内外同时上市和在境外上市的企业 2019 年起执行，其他 A股上市公司 2021 年起执行，见 5.3.1.2.3.3）。重组时把它们分别落位：

- 使用权资产是经营资产，计入投入资本；
- 租赁负债是债务等价物，放在融资一侧（5.3.2.2.7.2）；
- 租赁利息在财务费用里，和其他利息一样不进 NOPLAT（税后经营利润）。

准则之外仍要手动处理的情形，就是 5.3.1.2.3.3 列出的那几种：执行新准则以前的历史年份、仍直接费用化的短期租赁、低价值租赁和可变租金。租金费用很大的行业（零售、餐饮、连锁服务），这部分可能不小。

隐藏的租赁资产有多大？一个直觉例子：一家门店每年租金 100 万元，签 10 年，按 5% 折现。"每年 1 元、连续 10 年、按 5% 折现"的现值合计是年金现值系数 $\frac{1 - 1.05^{-10}}{5\%} \approx 7.72$（这个工具见 5.2.2.1.3），所以这份租约的现值约 $100 \times 7.72 = 772$ 万元。这差不多就是新准则下该门店使用权资产和租赁负债的初始金额；在旧准则下，这 772 万元的"资产"和"负债"都不在表上，而它是一年租金的近 8 倍。

**第二类是费用化的投资**，主要是研发和广告。会计上研究阶段的支出全部费用化、开发阶段只有满足严格条件才资本化，广告费全部费用化，所以它们形成的资产大部分不在投入资本里。

隐藏的研发资产有多大？举个直觉例子：一家公司每年稳定投入研发 100，研发成果大约能用 5 年。如果把研发当资本开支、按 5 年摊销，账上会累积一块大约 300 的"研发资产"（今年的 100 全部未摊销，去年的还剩 80，前年的还剩 60，依此类推：$100 + 80 + 60 + 40 + 20 = 300$）。也就是说，隐藏在报表外的投入资本是年研发费用的 3 倍。

启明精工每年 100 的研发费用，就属于这种情况。要不要资本化、怎么选摊销年限、调整后 NOPLAT 怎么变，完整方法见 5.3.2.8.1（租赁）和 5.3.2.8.2（研发与广告）。本节后面的计算暂不做研发资本化。

### 5.3.2.2.6 非经营资产

非经营资产是公司拥有、但主营业务用不到的资产。它们不进投入资本，相关收益不进 NOPLAT，在估值时单独计价，再加到经营价值上（5.5.3.4.2）。

#### 5.3.2.2.6.1 富余现金和可交易证券

公司做生意需要一定的现金：发工资、付货款、应付日常波动。超过这个需要的部分，就是**富余现金**。富余现金和交易性金融资产、银行理财、短期债券投资一样，流动性高、回报低，应该从投入资本中剔除。

难点在于，公司不会告诉你它经营需要多少现金，会计上也不区分。一个常用的经验估计是：**经营现金约为营业收入的 2%**。这个比例来自对美国非金融公司的研究：在一段较长的时期里，这些公司的最低现金余额略低于收入的 2%。它不是普适规则：现金流波动大的行业、季节性强的行业、需要大量押金和保证金的行业，经营现金会更高；可以参考同行中现金最少的那几家公司的现金 / 收入比。

启明精工 2023 年收入 18 亿元，经营现金估为 $1800 \times 2\% = 36$；2024 年收入 20 亿元，经营现金估为 40。货币资金 300 和 285，扣掉之后，富余现金分别是 264 和 245。银行理财 200 和 220 也是非经营资产。

A股报表里，"现金类"非经营资产散落在好几个科目里，找全要靠附注：

| 科目 | 常见内容 | 处理 |
|---|---|---|
| 货币资金 | 库存现金、银行存款、其他货币资金 | 扣掉经营现金后是富余现金；**受限资金**（票据保证金、保函保证金）要单列，它们不能自由动用，跟着对应的应付票据一起判断 |
| 交易性金融资产 | 银行理财、基金、股票 | 非经营 |
| 其他流动资产 | 常混有理财产品、结构性存款 | 打开附注，把理财挑出来 |
| 一年内到期的非流动资产、其他非流动资产、债权投资 | 常混有大额存单、定期存款 | 挑出来，作非经营资产 |

> **投资者怎么用**：账上现金很多、同时借款也很多（所谓"存贷双高"），是 A股的一个经典警示信号。一家真正有大量闲钱的公司，没有理由同时借高息的钱。康美药业事件中，账面上的巨额货币资金后来被证实严重虚增。看到这种组合，先查利息收入和现金余额是否匹配：几百亿现金每年只有零星利息收入，就要打个问号。

#### 5.3.2.2.6.2 非流动性投资、非并表子公司和权益投资

这一类包括：长期股权投资（对联营、合营企业的投资）、其他权益工具投资、其他非流动金融资产、出租给别人的投资性房地产，以及向客户提供融资形成的有息应收款（比如工程机械厂商为客户提供融资租赁或分期付款形成的长期应收款）。

它们的共同点是：**回报和风险跟主营业务不一样**。联营企业的利润按持股比例一行计入投资收益，你看不到它的收入、成本和资本，没法放进主业的 ROIC 里分析；客户融资业务本质上是放贷，回报应该和一家金融公司比，而不是和制造业比。所以能拆开的尽量拆开，各自单独估值。

但现实里不一定都能拆干净。如果联营企业就是主业链条上的一环（比如和上游供应商合资建的配套工厂），或者公司没有披露客户融资业务的收入，有时只能把它留在投入资本里，这时要在分析中注明。

启明精工的长期股权投资 100（2023）和 108（2024）是一家联营企业，作为非经营资产。它 2024 年确认了权益法收益 12，收到分红 4，所以账面值增加了 8。

#### 5.3.2.2.6.3 预付款和无形养老金资产

这里的"预付款"是一个容易误读的名词：它指的是公司向**设定受益养老金计划**多缴的钱，也就是养老金计划资产超过养老金义务的部分，在部分境外准则下可以确认为公司的资产。它属于非经营资产，单独估值。

中国企业的职工养老主要通过社保缴费，属于设定提存计划，一般不会出现这种资产。只有少数历史较长的国有企业、在境外有业务的公司，或者港股中采用设定受益计划的公司会涉及，处理方法见 5.3.2.8.5。

要提醒的是：A股资产负债表上的"预付款项"是预付给供应商的货款，**属于经营性营运资本**，不要和这里混为一谈。

### 5.3.2.2.7 债务与债务等价物

以下进入总投入资金的右边：钱从哪里来。

#### 5.3.2.2.7.1 有息债务

有息债务是所有按合同付利息的借款。A股报表里，它们分布在这些科目中：

| 科目 | 说明 |
|---|---|
| 短期借款 | 一年以内的银行借款 |
| 一年内到期的非流动负债 | 长期借款、应付债券、租赁负债中一年内到期的部分，**很容易漏掉** |
| 长期借款 | |
| 应付债券 | 包括可转债的负债部分 |
| 其他流动负债 | 有的公司把超短期融资券、短期融资券放在这里，要看附注 |
| 长期应付款 | 可能包含融资租赁款、售后回租款，本质是借款 |
| 其他应付款中的应付利息、应付股利 | 欠出资人的钱，属于融资 |

启明精工的有息债务是：短期借款 + 一年内到期的长期借款 + 长期借款 = $150 + 50 + 200 = 400$（2023），$170 + 60 + 190 = 420$（2024）。

还有一类东西在会计上被归为权益、经济上却更像债务，最典型的是**永续债**：A股不少公司发行的永续债被计入"其他权益工具"，让资产负债率好看了不少，但它有固定的票息、实际上大多会按期赎回。重组时，应把永续债当作债务等价物（为什么这类操作本身不创造价值，见 5.2.1.7）。

#### 5.3.2.2.7.2 退休债务、经营性租赁等债务等价物

**债务等价物**是那些不叫"借款"、却和借款一样代表对公司现金的固定索取权的义务。常见的有：

- **租赁负债**：前面说过，它是"借钱买使用权"的那笔借款。启明精工的租赁负债 30（2023）和 28（2024）放在这里。
- **养老金和退休福利缺口**：设定受益计划的义务大于计划资产的部分，相当于公司欠员工的钱，迟早要拿现金补上。中国企业较少，部分老国企的内退、离退休人员统筹外费用会以长期应付职工薪酬的形式出现，详见 5.3.2.8.5。
- **弃置费用等长期预计负债**：矿山、油气田、核电站在使用寿命结束时必须拆除复原，公司提前按现值计提预计负债，每年计提利息。它像一笔逐年累积的借款。详见 5.3.2.8.4。
- **未决诉讼、对外担保等或有负债**：如果很可能发生、金额可估，也可以作为债务等价物。

为什么要把这些放在融资一侧，而不是从经营资产中扣掉？因为它们的成本不是经营费用：养老金缺口每年产生的利息、弃置费用的利息、租赁的利息，经济上都是融资成本。如果把它们当成经营负债从投入资本中扣掉，投入资本被低估，ROIC 被高估。

这些项目在算股权价值时都要从企业价值里扣掉，扣的方法见 5.5.3.4.3。

### 5.3.2.2.8 权益与权益等价物：递延税等项目

**股东权益**就是资产负债表上的所有者权益：股本、资本公积、其他综合收益、盈余公积、未分配利润，扣掉库存股（回购的股票）。

**权益等价物**是那些挂在负债里、但没有任何人会来要钱的项目。它们出现的原因是会计上记了一笔费用，却没有对应的现金流出，于是在负债方挂了一个"影子"。重组时，把它们看作股东权益的一部分，而不是经营负债。常见的有三类：

**递延所得税。** 中国税法允许单位价值不超过一定标准的新购设备在买入当年一次性税前扣除，而会计上仍然按使用年限折旧。于是前几年报税时扣得多、交税少，利润表上的所得税费用却按会计利润算，两者的差额记为递延所得税负债。只要公司持续投资，这笔递延的税就会不断滚动、很难真正交出去。启明精工 2024 年的所得税费用是 74，其中当期实际应交 68，递延 6。

估值关心的是**实际交了多少税**，所以 NOPLAT 要用现金税（5.3.2.3.4）。既然 NOPLAT 已经用了少交的税，递延所得税负债就不能再从投入资本里扣掉，否则同一件事算了两次；它被挪到权益一侧，就像一笔"没交的税留在了公司、归股东所有"。实务中通常用递延所得税负债减去递延所得税资产的净额。启明精工：$30 - 10 = 20$（2023），$36 - 10 = 26$（2024）。

**收入平滑类准备。** 有些公司在好年景多提准备、坏年景转回，用来平滑利润。这类准备不对应任何真实义务，也是权益等价物，识别方法见 5.3.2.8.4.4。

**少数股东权益。** 启明精工有一家控股 70% 的子公司，另外 30% 属于其他股东。合并报表把子公司的资产负债全部并进来，于是投入资本里有一部分是少数股东出的钱。少数股东权益放在融资一侧，作为权益等价物（它是一类出资人的索取权，估值时要扣除，见 5.3.2.8.6 和 5.5.3.4）。启明精工：55（2023），63（2024）。

**小结：用两种方法核对投入资本**

把上面的结果汇总，从两边各算一遍：

## 5.3.2.3 NOPLAT：真正由经营业务产生的税后利润

NOPLAT（税后经营利润）是投入资本在一年里给全部出资人赚回的税后利润。它和投入资本是一对：投入资本里有什么资产，NOPLAT 里就有什么收益；投入资本里没有的，NOPLAT 里也不能有。

计算分四步：找到经营利润、剔除非经营项目、调整隐藏资产、计算经营税。最后和净利润对一遍账。

### 5.3.2.3.1 从 EBITA/经营利润出发

先认识三个常见的利润指标：

| 指标 | 含义 | 和净利润的关系 |
|---|---|---|
| EBIT（息税前利润） | 扣利息、扣所得税之前的利润 | 净利润 + 所得税 + 利息 |
| EBITA（息税及摊销前利润） | EBIT 再加回并购形成的无形资产摊销 | EBIT + 购得无形资产的摊销 |
| EBITDA（息税折旧摊销前利润） | EBITA 再加回折旧和其余摊销 | EBITA + 折旧 + 其他摊销 |

为什么经营利润的起点用 EBITA，而不是 EBIT？因为并购形成的无形资产摊销是一笔特殊的费用：它摊的是收购时付出的价格，而不一定是维持经营必须重复发生的成本。一台设备用旧了要换新，所以折旧是真实的经营成本；收购时识别出来的"客户关系"摊完了，公司通常不会再花一笔收购价把它买一次，维持客户关系靠的是每年的销售费用。如果这些维持性支出已经作为费用从利润里扣过，再扣一次摊销，同一件事就扣了两遍。所以，计算 NOPLAT 时不扣这部分摊销，相应地，投入资本里的购得无形资产也按未摊销的原值计（和 5.3.2.2.3 加回商誉减值是同一个道理）。

> **另一种看法**：购得的客户关系、技术也会衰减。客户会流失，技术会过时，收购来的那一份价值确实在一年年消耗掉。按这种看法，摊销就和折旧一样是经营成本，应该从 EBITA 里扣掉，投入资本里的购得无形资产按摊销后的净值计，每年的投资按"净值变化 + 摊销"估算，和固定资产完全同样处理。
>
> 两种做法的分歧，落在一个事实问题上：**维持这些无形资产的支出，是否已经在当期费用里了？** 本体系的取舍是：默认加回摊销、按原值计投入资本，前提是公司每年的销售费用和研发费用足以维持被收购业务的客户和技术（看被收购业务的收入是否稳定，研发和销售投入是否跟上）。如果被收购的技术或牌照到期就要重新付钱购买，或者被收购业务的收入在明显萎缩、并没有替代投入，那就按另一种看法处理，把摊销当经营成本。无论选哪种，NOPLAT 和投入资本必须配套：扣了摊销，投入资本就用净值；加回了摊销，投入资本就用原值。

EBITDA 则走得太远了：折旧是真实的成本，加回折旧的利润高估了经营能赚的钱。EBITDA 常用来做倍数估值和衡量偿债能力，但不能用来算 ROIC（投入资本回报率）。

在 A股利润表上，你找不到现成的 EBITA，"营业利润"也不是它。要自己从营业收入开始往下减，只减经营性的项目。启明精工没有并购形成的无形资产摊销（商誉不摊销，土地使用权摊销是经营成本），所以它的 EBITA 就等于经营口径的 EBIT：

| 项目 | 金额 |
|---|---|
| 营业收入 | 2000 |
| 减：营业成本 | (1400) |
| 税金及附加 | (16) |
| 销售费用 | (80) |
| 管理费用 | (90) |
| 研发费用 | (100) |
| 信用减值损失（应收坏账） | (6) |
| 资产减值损失（存货跌价） | (8) |
| **EBITA（经营利润）** | **300** |

注意营业利润是 308，EBITA 是 300，差了 8：营业利润扣了财务费用 24，又加了其他收益 10 和投资收益 22。这三项都不属于经营。

### 5.3.2.3.2 剔除非经营收入、回报和损失

第二步，确认上面的 300 里没有混入非经营项目，并把利润表上的非经营项目全部列出来，留到最后对账用：

| 非经营项目 | 税前金额 | 剔除理由 |
|---|---|---|
| 利息收入 | 6 | 来自富余现金，富余现金不在投入资本里 |
| 理财收益 | 10 | 理财不在投入资本里 |
| 联营企业权益法收益 | 12 | 联营企业投资不在投入资本里 |
| 其他收益（一次性技改补贴） | 10 | 一次性，不可持续 |
| 利息费用（含租赁利息 2） | (30) | 融资成本，已在 WACC 里体现 |

剔除的原则就一条：**分子分母对应**。如果你决定把某项资产放进投入资本，它的收益就要留在 NOPLAT 里；反过来也一样。最常见的错误是把理财收益留在了经营利润里，而理财资产已经从投入资本里剔除了，ROIC 就被高估。

现在可以回答 5.3.2.1.4 留下的问题：扣非净利润和 NOPLAT 差在哪里？启明精工的非经常性损益是理财收益 10 和一次性补贴 10，税后合计 15（假设都归属母公司），扣非归母净利润 = $220 - 15 = 205$。从 205 走到 NOPLAT 231：

| 项目 | 金额 | 原因 |
|---|---|---|
| 扣非归母净利润 | 205 | |
| 加：税后利息费用 | 22.5 | NOPLAT 不扣利息（$30 \times 75\%$） |
| 加：少数股东损益 | 14 | NOPLAT 属于全部出资人，包括少数股东 |
| 减：联营企业收益 | (12) | 扣非不剔除它，NOPLAT 剔除 |
| 减：税后利息收入 | (4.5) | 扣非不剔除它，NOPLAT 剔除（$6 \times 75\%$） |
| 加：递延所得税 | 6 | NOPLAT 用现金税（见 5.3.2.3.4） |
| **NOPLAT** | **231** | |

扣非净利润是一个"更干净的股东利润"，NOPLAT 是"经营业务给全部出资人赚的税后利润"。前者适合算市盈率，后者适合算 ROIC 和现金流。

### 5.3.2.3.3 调整隐藏资产相关收益和费用

如果在 5.3.2.2.5 把隐藏资产放进了投入资本，NOPLAT 也要做对应的调整，否则分子分母又不一致了：

- **租赁**：如果租赁已经按新准则在表上（启明精工就是），租赁利息在财务费用里，不在 EBITA 里，不需要再调。如果分析的是旧准则下的数据，或者有大额短期租赁仍在费用化，就要把租金里隐含的利息部分加回 EBITA，因为它是付给"出租人这个债权人"的融资成本。
- **研发**：如果把研发资本化了，EBITA 里就不再扣当年的研发费用，改扣过去研发的摊销。研发增长快的公司，当年研发费用大于摊销，调整后 EBITA 会变高；同时投入资本也变大，ROIC 通常是下降的。

具体算法见 5.3.2.8.1 和 5.3.2.8.2。养老金费用里的利息部分、各类准备的处理也会影响 EBITA，见 5.3.2.8.4 和 5.3.2.8.5。

### 5.3.2.3.4 计算经营现金税

最后一步是扣税。这里的问题是：利润表上的所得税费用 74，是按利润总额 308 算的，它被利息抵税、非经营收益、递延税都影响过。NOPLAT 需要的是**假设公司只有经营业务、全部用股东的钱、按实际现金交的税**。

**第一步：从报告的税收出发，算出经营业务应负担的税。**

| 项目 | 金额 | 说明 |
|---|---|---|
| 报告的所得税费用 | 74 | |
| 加：利息费用的税盾 | 7.5 | $30 \times 25\%$；如果没有借款，就不能扣这 30，要多交这么多税 |
| 减：利息收入对应的税 | (1.5) | $6 \times 25\%$ |
| 减：理财收益对应的税 | (2.5) | $10 \times 25\%$ |
| 减：一次性补贴对应的税 | (2.5) | $10 \times 25\%$ |
| 减：联营企业收益对应的税 | 0 | 免税，所以不用调 |
| **EBITA 的经营税** | **75** | 等于 $300 \times 25\%$，核对通过 |

为什么要把利息的税盾加回去？因为 NOPLAT 要和资本结构无关。利息能抵税，这个好处是真实的，但它属于融资决策的结果，已经在 WACC（加权平均资本成本）里通过"税后债务成本"体现了（5.2.1.1）。如果在 NOPLAT 里也算上它，税盾就被算了两次。

每一项调整乘的税率，应该是**边际税率**：多 1 元应税收入要多交多少税。它通常是法定税率，在中国一般是 25%；高新技术企业、享受西部大开发政策的企业是 15%。有效税率（报告税费 ÷ 利润总额）则会被各种一次性因素、免税收入、亏损子公司扭曲。启明精工的有效税率是 $74 / 308 \approx 24.0\%$，低于 25%，原因正是联营企业收益免税，这是非经营的因素。两种税率的完整区别以及预测时用哪个，见 5.5.2.1.2。

一个实用技巧：A股年报附注里有一张"会计利润与所得税费用调整过程"表，列出了法定税率下的税额与实际税费之间的每一项差异。逐项判断它们属于经营还是非经营：研发费用加计扣除、子公司适用不同税率、不可抵扣的业务招待费，属于经营，应留在经营税里；权益法投资收益免税、以前年度汇算清缴差异、未确认递延税的亏损，通常不属于当期经营。

**第二步：从经营税调整到经营现金税。**

$$
\text{经营现金税} = \text{EBITA 的经营税} - \text{递延所得税净负债的增加}
$$

启明精工的递延所得税净负债从 20 增加到 26，增加 6，说明今年有 6 的税被递延了，没有真正交出去。

$$
\text{经营现金税} = 75 - 6 = 69, \qquad \text{现金经营税率} = 69 / 300 = 23\%
$$

$$
\text{NOPLAT} = \text{EBITA} - \text{经营现金税} = 300 - 69 = 231
$$

> **另一种看法**：也可以不调递延税，直接用 EBITA × 法定税率得到 NOPLAT = 225，同时把递延所得税负债当作经营负债从投入资本中扣掉。这种做法更简单，也被很多分析师采用。它的结果在自由现金流上和现金税法完全一样（两种做法下 FCF（自由现金流）都是 68，因为差额 6 会在投资一侧抵消），差别只在 NOPLAT 和 ROIC（投入资本回报率）的数值：简化做法下期初投入资本是 $1341 - 20 = 1321$（扣掉递延所得税净负债 20），ROIC 为 $225 / 1321 \approx 17.0\%$，比现金税法的 17.2% 低 0.2 个百分点。
>
> 本体系的取舍是：**递延税金额小、方向不稳定时，用简单做法，符合节俭原则；递延税持续、大额地增长时（比如长期大量享受设备加速扣除的重资产公司），用现金税法**，因为这时报告的税负会系统性地高估公司实际交的税，按报告税负算出的 ROIC 会偏低。不管选哪种，NOPLAT 和投入资本里的递延税处理必须配套。

### 5.3.2.3.5 与净利润进行调节和核对

重组完之后，一定要从净利润出发，再走一遍到 NOPLAT 的路。两条路的终点一致，才说明没有漏项、没有重复。

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润（含少数股东损益） | 234 | |
| 加：递延所得税净负债的增加 | 6 | 换成现金税口径 |
| 加：税后利息费用 | 22.5 | $30 \times (1 - 25\%)$，含租赁利息 |
| **属于全部出资人的税后利润** | **262.5** | |
| 减：税后利息收入 | (4.5) | $6 \times 75\%$ |
| 减：税后理财收益 | (7.5) | $10 \times 75\%$ |
| 减：税后一次性补贴 | (7.5) | $10 \times 75\%$ |
| 减：联营企业收益 | (12) | 免税 |
| **NOPLAT** | **231** | 与 5.3.2.3.4 一致 |

如果公司有商誉减值、并购无形资产摊销，它们在净利润里扣过、在 NOPLAT 里没扣，调节时也要加回。

"属于全部出资人的税后利润" 262.5 这个数字也有用：它等于 NOPLAT 加上全部非经营收益，是"公司的全部资产（经营加非经营）给全部出资人赚的钱"，和总投入资金 1905 对应。

## 5.3.2.4 自由现金流：经营利润怎样变成可分配现金

5.2.1.2 给出了自由现金流（FCF）最简洁的定义：

$$
\text{FCF} = \text{NOPLAT} - \text{净投资}, \qquad \text{净投资} = \Delta \text{IC}
$$

启明精工的投入资本从 1341 增加到 1504，净投资 163，所以 FCF = $231 - 163 = 68$。

这一个减法就够了，为什么还要展开？因为只看投入资本的净增加，你不知道钱花在了哪里：是扩产，是存货积压，还是给客户放了更长的账期。下面把它拆开，从"总现金流"减"总投资"重新算一遍。这就是历史口径的完整推导；做预测时的写法见 5.5.2.1.4。

### 5.3.2.4.1 总现金流：NOPLAT + 非现金费用

NOPLAT（税后经营利润）是利润，不是现金。从利润到现金，第一步是加回那些扣了利润、却没有花现金的费用，最主要的是折旧和摊销：

$$
\text{总现金流} = \text{NOPLAT} + \text{折旧和摊销}
$$

启明精工：$231 + 88 = 319$。

**总现金流**的含义是：经营业务在不卖任何非经营资产、不借新钱、不让股东掏钱的情况下，自己产生的现金，可以用来再投资和回报出资人。

加回时要注意三点：

- **只加回已经在 EBITA（息税及摊销前利润）里扣过的非现金费用。** 商誉减值、并购无形资产摊销在算 NOPLAT 时本来就没扣，就不能再加回，否则就重复了。
- **应收坏账、存货跌价这类准备不要单独加回**，如果你在计算营运资本时用的是扣除准备后的净额（大多数情况如此）。它们的影响已经体现在营运资本的变动里了；单独再加一次就重复了。
- **股权激励费用**也是非现金费用。是否加回，取决于你在算每股价值时怎么处理员工持有的期权和限制性股票：加回它，就必须把这些股权当作对公司的索取权、在最后扣掉；不加回，相当于把它当作现金薪酬。两种做法都要前后一致，详见 5.3.2.8.3 和 5.5.3.4.4。

### 5.3.2.4.2 总投资：营运资本·资本支出·其他经营投资

公司要维持和扩大经营，必须把总现金流的一部分投回去。总投资由以下几项组成，每一项都对应投入资本里的一个组成部分：

| 投资项 | 怎么算 | 启明精工 |
|---|---|---|
| 营运资本投资 | 经营性营运资本的增加 | $295 - 256 = 39$ |
| 净资本支出 | 固定资产类净值的增加 + 当年折旧摊销 | $(1138 - 1010) + 80 + 2 = 210$ |
| 使用权资产投资 | 使用权资产的增加 + 当年折旧（即新签租约） | $(28 - 30) + 6 = 4$ |
| 商誉和购得无形资产投资 | 并购支付的溢价 | 0 |
| 其他长期经营净资产的增加 | 本例是预计负债增加，属于资金来源 | $-(17 - 15) = -2$ |
| **总投资** | | **251** |

$$
\text{FCF} = \text{总现金流} - \text{总投资} = 319 - 251 = 68
$$

和净投资法算出的 68 一致。两种算法的关系是：$\text{总投资} = \text{净投资} + \text{折旧摊销}$，也就是 $251 = 163 + 88$。

几个最容易出错的地方：

**净资本支出要用"净值变化 + 折旧"倒推，而不是用原值的变化。** 设备报废时，原值和累计折旧同时减少，不涉及现金；如果用原值变化估资本支出，会把报废当成"负投资"，低估实际花的钱。启明精工倒推出的 210，正好等于现金流量表上"购建固定资产、无形资产和其他长期资产支付的现金"210，这是一个很好的核对。真实公司里两者通常不会完全相等（处置旧资产、应付工程款的变化都会造成差异），差距大时要查原因。

**营运资本投资要用经营性营运资本**，不能直接用"流动资产 − 流动负债"的变化。后者把富余现金、理财、短期借款都混了进去：公司借了一笔短期借款放在账上，流动资产和流动负债同时增加，看起来营运资本没变，其实是无关的融资。

**并购也是投资。** 一家主要靠收购增长的公司，资本开支可能很低，FCF 看起来很漂亮，但它每年花在收购上的钱和自建工厂没有本质区别。按经营法计算投入资本时，商誉和购得无形资产的增加会自动进入总投资；如果你只看现金流量表上的资本开支，就会漏掉它。

**汇率换算会制造假投资。** 有大量境外子公司的公司，资产负债表上的外币资产换算成人民币时，汇率变化会让账面值升降，但这不是真实的现金投资。一个粗略的修正方法是参考其他综合收益里的"外币财务报表折算差额"的变动，把它从投资中扣掉。

> **补充一个角度**：再投资有两个部分，**资本净支出**（资本开支减折旧）和**非现金营运资本的增加**。这和上面的拆法本质相同，只是另一种表述。它提醒了两件事：第一，资本开支常常是一块一块发生的，今年建新厂、后几年投得很少，用单一年份的资本开支做判断会严重失真，应该看几年的平均；第二，研发和并购在会计上不算资本开支，但经济上就是再投资，应该算进去。这两点在下面的再投资率里会用到。

### 5.3.2.4.3 再投资率：为了增长留下了多少经营利润

5.2.1.5 用 IR（再投资率）把增长、回报率和现金流连在了一起：

$$
\text{IR} = \frac{\text{净投资}}{\text{NOPLAT}}, \qquad g = \text{RONIC} \times \text{IR}, \qquad \text{FCF} = \text{NOPLAT} \times (1 - \text{IR})
$$

现在可以用重组后的数字把它算出来。启明精工 2024 年：

$$
\text{IR} = \frac{163}{231} \approx 70.6\%
$$

也就是说，它把七成的税后经营利润重新投回了生意里，只有三成变成了自由现金流（$231 \times 29.4\% \approx 68$）。

**用 IR 做一次粗检验。** 如果新投资的回报率和现有的 ROIC（投入资本回报率）差不多（约 17.2%），那么这样的再投资率能支撑的增长大约是 $17.2\% \times 70.6\% \approx 12.1\%$。这个数其实就是投入资本的增长率：$\Delta \text{IC} / \text{IC}_{期初} = 163 / 1341 \approx 12.2\%$（两者只差在四舍五入），因为 $\text{ROIC} \times \text{IR} = \frac{\text{NOPLAT}}{\text{IC}} \times \frac{\Delta \text{IC}}{\text{NOPLAT}}$。启明精工 2024 年的收入增长是 $2000 / 1800 - 1 \approx 11.1\%$，两者大体吻合。如果一家公司的再投资率很高，增长却很低，就说明新投资的回报率远低于历史平均，或者投资还没开始见效，这是需要追问的信号。反过来，再投资率很低、增长却很高，要么是公司真的有极高的新增资本回报率，要么是增长来自提价、提效这类不需要资本的一次性来源（5.2.1.6），要么是会计上有东西没算进投资（研发、并购、租赁）。

**另一种算法。** 也可以用总投资除以总现金流：

$$
\frac{\text{总投资}}{\text{总现金流}} = \frac{251}{319} \approx 78.7\%
$$

这个比例同样衡量"经营产生的现金有多少被投了回去"，但分子分母都包含了折旧（维持性投资）。分子分母同时加上同一笔折旧，会把比例往 100% 的方向拉。所以 IR 低于 100% 时（绝大多数公司在绝大多数年份都是这样），它高于净额口径的 IR，资产越重、折旧越大，两者差得越多；IR 超过 100% 时（投资多于利润，比如集中扩产的年份），结论反过来，它低于净额口径的 IR。下面三年例子的第 1 年就是这种情况。这个比例的用途是看趋势：它持续上升、增长却没有跟上，说明投资见效越来越慢，或者公司在低效地堆资本。

> 本体系统一用**净投资 ÷ NOPLAT** 作为再投资率，因为只有这个口径能直接代入 $g = \text{RONIC} \times \text{IR}$。用总额口径的比例去乘 RONIC（新增资本回报率），对 IR 低于 100% 的大多数公司，会系统性地高估增长；对集中扩产、IR 超过 100% 的年份则会低估。无论哪种情况，都是口径错配。

**单一年份的再投资率不可靠，要看多年平均。** 设想一家公司连续三年的 NOPLAT 是 100、110、121，第一年建了一座新工厂，三年的净投资分别是 150、20、30：

| | 第 1 年 | 第 2 年 | 第 3 年 | 三年合计 |
|---|---|---|---|---|
| NOPLAT | 100 | 110 | 121 | 331 |
| 净投资 | 150 | 20 | 30 | 200 |
| 再投资率 | 150% | 18% | 25% | **60.4%** |

单看第 1 年，你会以为它是一个吞噬现金的公司；单看第 2 年，又会以为它几乎不用投资就能增长 10%。三年合起来的 60.4% 才接近它的真实再投资需求。重资产、产能扩张呈阶梯状的行业（化工、半导体、电池、水泥），尤其要用多年平均。

再投资率在增长估算中怎么用、和 $g = b \times \text{ROE}$ 的关系，见 5.4.1.4–5.4.1.5。

### 5.3.2.4.4 自由现金流 = NOPLAT − 净投资

把前面的计算合成一张表，这就是历史口径的自由现金流表：

| 项目 | 2024 | 来源 |
|---|---|---|
| NOPLAT | 231 | 5.3.2.3 |
| 加：折旧和摊销 | 88 | 附注 |
| **总现金流** | **319** | |
| 营运资本投资 | (39) | 投入资本表 |
| 净资本支出 | (210) | 投入资本表 + 折旧 |
| 使用权资产投资（新签租约） | (4) | 投入资本表 + 折旧 |
| 其他长期经营净资产 | 2 | 投入资本表 |
| **总投资** | **(251)** | |
| **自由现金流 FCF** | **68** | 核对：$231 - (1504 - 1341) = 68$ |

**FCF 和"经营活动现金流 − 资本开支"有什么不同？** 很多人用 CFO（经营活动现金流）减去资本开支作为自由现金流的捷径。启明精工的这个数字是 $303 - 210 = 93$，比 68 高出 25。差在哪里？

| 差异来源 | 金额 | 原因 |
|---|---|---|
| 利息收入 | 6 | CFO 里包含利息收入，FCF 不含（属于非经营） |
| 一次性补贴 | 10 | CFO 里包含政府补助，FCF 不含 |
| 税的差异 | 1 | CFO 里的税享受了利息抵税（再扣掉非经营收益的税），FCF 用的是"假设没有负债"的经营税 |
| 经营现金的增加 | 4 | FCF 把经营必需现金算作营运资本，CFO 不算 |
| 新签租约 | 4 | 新准则下新签租约不走现金流量表，但经济上是一笔投资 |
| **合计** | **25** | $93 - 68$ |

捷径并非没用，但它有三个系统性的偏差：它把非经营的收入算了进来；它把利息抵税的好处算了进来（于是和 WACC（加权平均资本成本）重复）；它漏掉了不经过现金流量表的投资（新租约、换股收购）。对一家现金多、补贴多、租赁多、靠换股并购的公司，这个捷径会明显高估自由现金流。而且这个捷径的结果还取决于公司把利息支付放在哪一类现金流里：在目前还可以选择分类的港股公司中，同一笔利息放在经营活动还是筹资活动，"CFO − 资本开支"就会差出一整笔利息（2027 年 IFRS 18（国际财务报告准则第 18 号）生效后，一般企业支付的利息基本统一归入筹资活动，但分析此前的历史年份仍要留意）。

**FCF 和 EBITDA（息税折旧摊销前利润）的关系**也值得记住：$\text{FCF} = \text{EBITDA} - \text{经营现金税} - \text{营运资本投资} - \text{资本支出（含新租约）} \pm \text{其他}$。启明精工：$388 - 69 - 39 - 214 + 2 = 68$（EBITDA = EBITA 300 + 折旧摊销 88 = 388；资本支出 214 = 210 + 4）。EBITDA 是 FCF 的五倍多，差距全部来自税和再投资。用 EBITDA 当作"现金流"去看一家正在扩产的制造业公司，会严重高估它能拿出来的钱。

> **投资者怎么用**：看一家公司的历史 FCF，至少要连续看五年，同时把 NOPLAT 和净投资并排列出来。FCF 低，可能是因为利润差，也可能是因为投资多；前者是坏消息，后者要看投资的回报。真正要警惕的组合是：NOPLAT 增长平平，净投资却年年很大，而且越来越多投在应收账款和存货上，这通常说明增长是靠放宽信用和压货买来的。

### 5.3.2.4.5 投资者可获得的现金流

FCF 只来自经营业务。公司还有非经营资产，它们也产生现金流，比如理财收益、联营企业分红；处置或增持这些资产，也会带来现金流入或流出。FCF 加上这些非经营现金流，就是**投资者可获得的现金流**，也就是全部出资人这一年实际能从公司拿走（或者需要再投进去）的现金。

$$
\text{投资者可获得的现金流} = \text{FCF} + \text{税后非经营收益} - \text{非经营资产的增加}
$$

启明精工：

| 项目 | 金额 | 说明 |
|---|---|---|
| 自由现金流 | 68 | |
| 税后利息收入 | 4.5 | $6 \times 75\%$ |
| 税后理财收益 | 7.5 | $10 \times 75\%$ |
| 减：理财增加 | (20) | 净买入理财 |
| 税后一次性补贴 | 7.5 | $10 \times 75\%$ |
| 联营企业收益 | 12 | 免税 |
| 减：联营企业账面值增加 | (8) | 收益 12 中只有 4 以分红形式收到现金 |
| 加：富余现金减少 | 19 | $264 - 245$ |
| **投资者可获得的现金流** | **90.5** | |

两点要注意。第一，非经营收益要用**税后**的口径，税率仍然用边际税率，因为 NOPLAT 里只算了经营业务的税，非经营收益的税要在这里扣。第二，非经营资产的收益和它的账面变化要放在一起看。联营企业账面增加 8，单独看像是"投资了 8"，但它其实是收益 12 中没分配的部分；把收益 12 和账面增加 8 放在一起，净现金流就是收到的分红 4，这才是真实的。同理，如果某项股权投资发生了 1 亿元的减值，单看资产减少像是"卖掉了 1 亿元资产"，单看利润表又像"亏了 1 亿元"，两者合起来才是真相：现金变化为零。

这也解释了估值时为什么要把非经营资产单独计价：

$$
\text{公司价值} = \text{FCF 的现值（经营价值）} + \text{非经营资产的价值}
$$

完整步骤见 5.5.3.4。

### 5.3.2.4.6 总融资现金流与经营现金流的勾稽

投资者可获得的现金流，必须正好等于流向（或来自）全部出资人的现金。前者从"钱怎么挣出来"的角度算，后者从"钱给了谁"的角度算，两者对上，才说明前面所有的分类都没有出错。这和 5.3.2.2 用经营法、融资法核对投入资本是同一个思路，只是从存量换成了流量。

| 项目 | 金额 | 说明 |
|---|---|---|
| 税后利息费用 | 22.5 | $30 \times 75\%$，含租赁利息；用和 NOPLAT 相同的边际税率 |
| 减：有息债务增加 | (20) | 借款从 400 增加到 420，债权人给了公司 20 |
| 加：租赁负债减少 | 2 | 从 30 降到 28；新签租约 4 已在投资里，这里是净偿还 |
| **流向债权人** | **4.5** | |
| 分红给母公司股东 | 80 | |
| 分红给少数股东 | 6 | 等于少数股东损益 14 减去少数股东权益的增加 8 |
| 股份发行（回购） | 0 | |
| **流向股东** | **86** | |
| **总融资现金流** | **90.5** | 与投资者可获得的现金流一致 |

两边都是 90.5，核对通过。

几个处理细节：

- **利息要用税后口径。** 因为 NOPLAT 是按"没有利息"计的税，利息的税盾没有在经营一侧出现，所以要在融资一侧把它体现为"公司付给债权人的利息里，有一部分由政府通过少收税承担了"。
- **送股、转增没有现金影响，不计入。** 高送转只是把一块蛋糕切成更多块（5.2.1.7）。
- **股东一侧看的是净额。** 发股、回购、分红都算，三者合起来是股东从公司净拿走的钱。
- **递延所得税的变化不进融资现金流。** 它虽然被当作权益等价物，但它已经通过现金税体现在 NOPLAT 里了。养老金缺口等债务等价物的变化则要进融资现金流，因为它们代表公司对债权人性质的义务的增减。

最后，回头看一眼启明精工这一年的现金故事：经营业务赚了 231 的税后利润，其中 163 投回了生意（扩产、垫营运资本），剩下 68 的自由现金流；加上理财和联营企业的现金收益、动用了一部分富余现金，一共 90.5 可以分给出资人；实际上，它借了 20 的新钱，付了 22.5 的税后利息和 2 的租赁本金，给股东分了 86。会计上的现金流量表告诉你货币资金少了 15；重组后的报表告诉你这 15 是怎么来的、该归到哪一类人的账上。

> **投资者怎么用**：拿到一家公司的年报，按本节的顺序走一遍：先给资产负债表每一行贴上"经营 / 非经营 / 债务 / 权益"的标签，用经营法和融资法核对投入资本；再从营业收入往下算 EBITA，用报告税费调出经营现金税，从净利润倒推核对 NOPLAT；最后算 FCF，用投资者现金流和融资现金流核对。三个核对都通过，你手里的 ROIC、增长和再投资率才是可信的。核对不通过的地方，往往正是这家公司报表里最值得追问的地方。

## 本节小结

```
会计资产负债表 ──┬── 经营资产 − 经营负债 ─────────→ 投入资本 IC ──┐
                 ├── 非经营资产（富余现金、理财、联营）──→ 单独估值     │
                 └── 债务 + 债务等价物 + 权益 + 权益等价物 ← 核对 ────┘

会计利润表 ──→ EBITA（只减经营项目）
              − 经营现金税（报告税 + 利息税盾 − 非经营收益的税 − 递延税增加）
              = NOPLAT ←── 核对：净利润 + 递延税 + 税后利息 − 税后非经营收益

NOPLAT + 折旧摊销 = 总现金流
总现金流 − 总投资 = FCF = NOPLAT − ΔIC
FCF + 非经营现金流 = 投资者可获得的现金流 = 总融资现金流 ←── 核对
```

**三句话**：

1. 重组只做一件事：按"经营 / 融资 / 非经营"重新分类，并保证每一类资产和它的收益放在同一边。
2. 每一个分类判断，最后都要过两道核对：投入资本经营法等于融资法，投资者现金流等于融资现金流。
3. A股报表上的"营业利润""经营活动现金流""扣非净利润"都不是估值要的数，它们各自混进了不同的非经营或融资项目。
