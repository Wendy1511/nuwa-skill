先看一个问题。两家设想的公司，主业一模一样：每年净利润 100，主业每年只需要留下 20 再投资，就能保持 2.5% 的增长。甲公司每年把剩下的 80 全部分掉；乙公司只分利润的四成（第一年是 40），剩下的留在公司里，拿去做一些只赚 2% 的投资。股东要求 8% 的回报。

如果你只看股息，乙公司每年只给你一半的钱，价值大约只有甲公司的一半多一点。如果你看的是"公司能分多少"，两家完全一样。哪个答案对？

两个都对，只是回答的问题不同。前者问的是"作为小股东，我实际能拿到什么"，后者问的是"这门生意本来能给股东什么"。两者之间的差距，恰好就是乙公司管理层"不分钱、乱花钱"毁掉的价值。本节的两个模型，股息贴现模型和股权自由现金流模型，就分别对应这两个问题。

它们都属于**股权估值**：直接估股东那一份，折现率用股权成本。和 5.5.3.3 的企业 DCF 相比，它们跳过了"先估整个企业，再减去债务"这一步，代价是要把借钱、还钱、留存现金这些融资决策一起放进现金流里预测。

**术语速查**

## 5.5.3.1 股息贴现模型（DDM）

### 5.5.3.1.1 一般模型：股权价值 = 未来股息现值

**为什么只算股息。** 你买入一只股票，打算持有三年。这三年里你能拿到的现金只有两样：每年的股息，和三年后卖出时的价格。卖出价格由谁决定？由下一个买家决定。他愿意出多少钱，取决于他之后能拿到的股息和他再卖出时的价格；而那个价格又取决于再下一个买家……这条链一直往后推，最后剩下的只有一样东西：**公司未来付出的全部股息**。所以，对一个不打算控制公司的小股东来说：

$$
P_0 = \sum_{t=1}^{\infty} \frac{E(\text{DPS}_t)}{(1+k_e)^t}
$$

$P_0$ 是今天的每股价值，$E(\text{DPS}_t)$ 是第 $t$ 年每股股息的期望值，$k_e$ 是股权成本。这就是 DDM（股息贴现模型）的一般形式。它只是"任何资产的价值 = 预期现金流按风险折现的现值"在股票上的直接应用（5.1.2.1）。

"持有期多长"不影响结果，可以用一个例子验证。设想一家水电公司"澜江电力"，下一年每股股息 0.76875 元，以后每年增长 2.5%，股东要求 6.9% 的回报（这些数字的来历见 5.5.3.1.2.1）。

- **永远持有**：按下一小节的戈登公式，价值 = $0.76875 / (6.9\% - 2.5\%) = 17.47$ 元。
- **只持有一年**：一年后拿到股息 0.76875 元，再按当时的价值卖出。一年后的价值 = 第 2 年股息 ÷（6.9% − 2.5%）= $0.78797 / 0.044 = 17.908$ 元。今天的价值 = $(0.76875 + 17.908) / 1.069 = 17.47$ 元。

两个答案相同。短线投资者拿到的卖出价格，本身就是后来者对未来股息的折现。

**两个输入。** 模型只需要两类数字：

1. **预期股息**。通常不直接预测股息，而是预测每股收益和支付率：$\text{DPS}_t = \text{EPS}_t \times \text{支付率}_t$。增长率和支付率之间有一条约束：$g = \text{留存率} \times \text{ROE}$，其中 ROE（净资产收益率）= 净利润 ÷ 期初股东权益（5.4.1.4）。下面每一种形式都会用到这条约束。
2. **股权成本 $k_e$**。用 CAPM（资本资产定价模型）估：$k_e = r_f + \beta \times \text{ERP}$，即无风险利率加上 β（贝塔系数）乘以股权风险溢价。澜江电力的 6.9% 来自 $2.5\% + 0.8 \times 5.5\%$。三个参数怎么选，是 5.5.2.3.4 的内容。

股权成本可以随时间变化。比如一家公司现在处在高增长期，β 偏高；进入成熟期后 β 向 1 靠拢，股权成本下降。这时折现就不能用 $(1+k_e)^t$，而要把每年的 $(1+k_{e,t})$ 连乘起来，叫**累计折现因子**。三阶段模型（5.5.3.1.2.4）会用到。

**两个口径提醒。**

- 股息是**股东**的现金流，所以只能用股权成本折现，不能用 WACC（加权平均资本成本），后者是给 FCFF（公司自由现金流）用的（5.5.2.3.7）。
- 可以按每股算（每股股息、每股价值），也可以按总额算（股息总额、股权总价值，最后除以股数）。公司大量回购或增发时，股数在变，按每股算要小心：回购会让未来每股股息增长得比股息总额快。比较稳妥的做法是按总额算，把回购当作股息的一部分（5.5.3.1.4.3）。

> **一个常见疑问**：一家公司永远不分红、也永远不被清算或收购，它对小股东值多少？按这个模型，值零。这听上去荒谬，其实道理是对的：股东总得在某个时候以某种形式拿到现金，分红、回购、被收购、清算都算。今天不分红的公司，价值来自将来某一天开始的分配。DDM 能处理这类公司，前提是你要合理预测"什么时候开始分、分多少"（5.5.3.1.4.1）。

### 5.5.3.1.2 模型的各种形式

没有人能逐年预测无穷多年的股息。实际使用时，要先对增长路径做一个假设，再选对应的形式：

| 形式 | 增长路径 | 适合 |
|---|---|---|
| 戈登增长模型 | 从明年起永远按固定速度增长 | 已经成熟、增长不超过整体经济的公司 |
| 两阶段模型 | 先高速增长 $n$ 年，然后突然降到稳定增长 | 高增长期有明确终点、高增长不算太高的公司 |
| H 模型 | 增长率从高位**线性**下滑到稳定水平，支付率不变 | 增长正在逐步放缓、已经有较高分红的公司 |
| 三阶段模型 | 高增长 → 过渡期逐步下滑 → 稳定增长，支付率和风险都可以变 | 当前高增长、竞争优势会逐步消退的公司 |

四种形式背后是同一个公式，区别只在于对未来的假设有多细。高增长期多长、过渡路径用突变还是线性，属于增长输入的一致性问题，原则见 5.5.2.2.2–5.5.2.2.3；这里只讲每种形式怎么算、各自的坑。

#### 5.5.3.1.2.1 戈登（Gordon）增长模型：稳定增长公司

**公式。** 如果股息从明年起按固定速度 $g_n$ 永远增长：

$$
P_0 = \frac{\text{DPS}_1}{k_e - g_n}
$$

这就是 5.2.1.5 讲过的增长型永续年金公式，只是现金流换成了股息，折现率换成了股权成本。分子是**下一年**的股息，不是刚付过的那一笔：$\text{DPS}_1 = \text{DPS}_0 \times (1+g_n)$。把今年的股息直接放进分子，是初学者最常见的错误，会让价值低估约 $g_n$ 那么大的比例（准确地说是 $g_n/(1+g_n)$，下面澜江电力的例子里约 2.4%）。

**例子：澜江电力（设想）。** 一家成熟的水电公司，电站已经建成，来水和电价都相对稳定。假设：

| 输入 | 数值 | 说明 |
|---|---|---|
| 今年每股收益 $\text{EPS}_0$ | 1.00 元 | |
| 长期 ROE | 10% | 不是今年的 ROE，而是对长期水平的判断 |
| 永续增长率 $g_n$ | 2.5% | 不超过无风险利率，理由见下 |
| 支付率 | 75% | 由 $1 - g_n / \text{ROE} = 1 - 2.5\% / 10\%$ 算出 |
| 股权成本 $k_e$ | 6.9% | $2.5\% + 0.8 \times 5.5\%$，水电公司 β低于市场平均 |

$\text{DPS}_0 = 1.00 \times 75\% = 0.75$ 元，$\text{DPS}_1 = 0.75 \times 1.025 = 0.76875$ 元。

$$
P_0 = \frac{0.76875}{6.9\% - 2.5\%} = \frac{0.76875}{0.044} = 17.47 \text{ 元}
$$

对应今年每股收益的 PE（市盈率）约 17.5 倍。

**稳定增长率要满足的四个条件。** 戈登公式简单，但它把"永远"压缩进了一个 $g_n$ 里，所以对 $g_n$ 和与它相关的参数要求很严：

1. **$g_n$ 不能超过整体经济的长期名义增长率。** 一家公司如果永远比经济增长得快，最终会比整个经济还大。实务上常用无风险利率作为长期名义增长率的替代上限，因为长期来看，名义利率大致等于实际增长加通胀。完整讨论见 5.5.2.2.4 和 5.5.2.4.3。
2. **股息和利润必须同速增长。** 假设利润永续增长 2%，股息永续增长 3%，起点支付率 70%。每过一年，支付率乘以 $1.03 / 1.02$，大约 37 年后支付率就超过 100%，股息比利润还多，这不可能是稳定状态。所以稳定期里，你可以直接用利润增长率代替股息增长率。
3. **支付率必须和增长率、ROE 一致：$\text{支付率} = 1 - g_n / \text{ROE}$。** 要增长，就得留存利润去投资；留多少，取决于留下来的钱能赚多少。这里的 ROE 应该是长期可持续的水平，不是最近一年的数字。
4. **股权成本必须是成熟公司的股权成本。** 进入稳定期的公司，β 通常向 1 靠拢；经验上，稳定期 β 取 0.8–1.2 比较合理。公用事业等低风险行业可以略低于 1。

**对增长率极其敏感。** 澜江电力其他条件不变，只改 $g_n$，看两种算法：

| $g_n$ | 支付率固定 75%（不一致的做法） | 支付率 = $1 - g_n / 10\%$（一致的做法） |
|---|---|---|
| 1.0% | 12.84 | 15.41 |
| 2.0% | 15.61 | 16.65 |
| **2.5%** | **17.47** | **17.47** |
| 3.0% | 19.81 | 18.49 |
| 4.0% | 26.90 | 21.52 |
| 5.0% | 41.45 | 27.63 |
| 6.0% | 88.33 | 47.11 |

*计算：左列 = $0.75 \times (1+g_n) / (6.9\% - g_n)$；右列 = $(1 - g_n/10\%) \times (1+g_n) / (6.9\% - g_n)$。*

读这张表要看三点。第一，$g_n$ 越接近 $k_e$，价值越接近无穷大；$g_n$ 超过 $k_e$，公式给出负数，没有意义。第二，左列在 $g_n$ 提高时没有同步降低支付率，等于假设公司**不多投钱也能多增长**：$g_n = 6\%$、支付率 75% 隐含的 ROE 是 24%，而公司实际只有 10%。这种不一致把价值高估了将近一倍。第三，即使右列做到了一致，$g_n$ 从 2.5% 提到 4% 价值也会涨 23%。高于 2.5% 的几行在本例里都超过了无风险利率，违反条件 1，本来就不该出现。

为什么右列也随 $g_n$ 上升？因为这家公司的 ROE（10%）高于股权成本（6.9%），多留存、多增长是创造价值的。如果 ROE 恰好等于股权成本，右列会是一条水平线；如果低于，右列会随 $g_n$ 下降。这是 5.2.1.3 的结论在股权口径下的翻版（5.5.3.1.3 展开）。

**不要求每年增长都一样。** "永续固定增长"听上去很苛刻，尤其对盈利起伏大的公司。但只要长期平均增长率接近 $g_n$，用戈登模型的误差并不大。一是股息本身比利润平滑，公司不愿意随利润大起大落地调整分红；二是用逐年不同的增长率代替一个平均值，对现值的影响通常不大。所以一家盈利有周期、但长期平均增长 2% 的成熟公司，仍然可以用戈登模型，前提是起点的利润要正常化，不能用周期顶部或底部的利润（5.3.1.2.4）。

**反过来用：隐含增长率。** 估出来的价值和市场价格几乎总有差距。先别急着下结论说市场错了，可以反过来问：**要让价值等于价格，增长率得是多少？** 由 $P = \text{DPS}_0 (1+g) / (k_e - g)$ 解出：

$$
g_{\text{隐含}} = \frac{P \times k_e - \text{DPS}_0}{P + \text{DPS}_0}
$$

假设澜江电力的股价是 20 元，隐含增长率 = $(20 \times 6.9\% - 0.75) / (20 + 0.75) = 0.63 / 20.75 = 3.04\%$。再用 $g = \text{留存率} \times \text{ROE}$ 反推：留存率 25% 时，隐含 ROE = $3.04\% / 25\% = 12.1\%$。

于是问题从"市场是不是高估了"变成了一个可以讨论的经营问题：**这家水电公司能长期维持 12% 的 ROE 吗？** 如果电价受管制、新电站的回报率被压低，答案多半是否定的。这就是 5.7.4.2 逆向 DCF（现金流折现）的最简版本。

**最适合的公司。** 增长率不超过名义经济增长、分红政策合理且可持续、β 接近 1 的公司。有一种情况要特别警惕：公司长期分得比能分的少、账上不断积累现金，戈登模型只看到股息，会低估它（5.5.3.1.4.2）。

#### 5.5.3.1.2.2 两阶段模型：高增长 → 稳定增长

**公式。** 公司先以 $g$ 增长 $n$ 年，之后永远按 $g_n$ 增长：

$$
P_0 = \sum_{t=1}^{n} \frac{\text{DPS}_t}{(1+k_{e,hg})^t} + \frac{P_n}{(1+k_{e,hg})^n}, \qquad P_n = \frac{\text{DPS}_{n+1}}{k_{e,st} - g_n}
$$

第一项是高增长期每年股息的现值，第二项是第 $n$ 年末股票价值（终值）的现值。注意两个细节：

- **终值用稳定期的参数算，但用高增长期的折现率折回来。** $P_n$ 站在第 $n$ 年末看，是稳定公司的价值，所以分母用 $k_{e,st}$；从第 $n$ 年末折回今天，要经过高增长期的 $n$ 年，所以用 $(1+k_{e,hg})^n$。
- **$\text{DPS}_{n+1}$ 要用稳定期的支付率重新算**，不能用第 $n$ 年的股息乘以 $(1+g_n)$。高增长期支付率低，进入稳定期后支付率应该上升。

如果高增长期的增长率和支付率都不变，第一项可以合成一个公式（增长型年金的现值）：

$$
\sum_{t=1}^{n} \frac{\text{DPS}_t}{(1+k_{e,hg})^t} = \frac{\text{DPS}_0 \times (1+g) \times \left[1 - \dfrac{(1+g)^n}{(1+k_{e,hg})^n}\right]}{k_{e,hg} - g}
$$

不必背，逐年算一张表完全等价，而且更不容易出错。

**例子：鲜川食品（设想）。** 一家调味品龙头，品牌和渠道带来较高的回报率，未来五年仍能较快增长，之后进入成熟期。假设：

| 输入 | 高增长期（第 1–5 年） | 稳定期（第 6 年起） |
|---|---|---|
| ROE | 24% | 12.5%（向行业正常水平回落） |
| 支付率 | 50% | 80%（$= 1 - 2.5\% / 12.5\%$） |
| 增长率 | 12%（$= 50\% \times 24\%$） | 2.5% |
| β | 1.2 | 1.0 |
| 股权成本 | 9.1%（$2.5\% + 1.2 \times 5.5\%$） | 8.0%（$2.5\% + 1.0 \times 5.5\%$） |

今年每股收益 $\text{EPS}_0 = 2.00$ 元。

| 年份 | EPS（元） | DPS = 50% × EPS | 折现因子 $1.091^t$ | 现值 |
|---|---|---|---|---|
| 1 | 2.2400 | 1.1200 | 1.0910 | 1.0266 |
| 2 | 2.5088 | 1.2544 | 1.1903 | 1.0539 |
| 3 | 2.8099 | 1.4049 | 1.2986 | 1.0819 |
| 4 | 3.1470 | 1.5735 | 1.4168 | 1.1106 |
| 5 | 3.5247 | 1.7623 | 1.5457 | 1.1402 |
| **合计** | | | | **5.4131** |

第 6 年 EPS = $3.5247 \times 1.025 = 3.6128$ 元，按稳定期支付率 80%，$\text{DPS}_6 = 2.8902$ 元。

- 第 5 年末价值 $P_5 = 2.8902 / (8.0\% - 2.5\%) = 52.55$ 元
- 折回今天：$52.55 / 1.5457 = 34.00$ 元
- 每股价值 = $5.41 + 34.00 = 39.41$ 元，相当于今年 EPS 的 19.7 倍

注意价值的 86% 来自终值。这在两阶段模型里很普遍，说明稳定期参数的选择比高增长期的细节更要紧。

**稳定期参数要"换挡"。** 进入稳定期时，三个参数都应该变：支付率上升（增长慢了，不需要留那么多钱）、β 向 1 回落、ROE向行业平均或股权成本靠拢。只把增长率降下来、其他参数原样延续，是最常见的错误。看看鲜川食品如果没换挡会怎样：

| 稳定期的错误设定 | 每股价值 | 相对 39.41 元 |
|---|---|---|
| 支付率仍用 50%（没有随增长放缓而上升） | 26.66 | −32% |
| β 仍用 1.2（股权成本仍为 9.1%） | 33.74 | −14% |
| 高增长期延长到 10 年 | 50.35 | +28% |

*计算：只改表中一项，其他输入不变。*

前两行会让价值偏低，第三行偏高。所以排查时可以按这个思路：**算出来的价值极低，先看稳定期的支付率是不是太低（低于 40% 就该怀疑）、β 是不是太高；价值极高，先看稳定期增长率是不是超过了无风险利率、高增长期是不是太长。**

**三个局限。**

1. **高增长期多长，很难定。** 高增长期越长，价值越高，但定性判断（竞争优势还能维持多久，5.2.2.1）很难精确换算成"5 年"还是"8 年"。
2. **增长是断崖式下降的。** 第 5 年还在 12%，第 6 年突然变成 2.5%，现实中很少这样。所以两阶段模型更适合高增长期增速**不太高**的公司：假设一家增长 7% 的公司 5 年后降到 2.5%，比假设一家增长 40% 的公司 5 年后降到 2.5%，合理得多。后者应该用三阶段模型。
3. **只看股息。** 分得比能分的少、账上积累大量现金的公司，会被低估。

**最适合的公司。** 正处在高增长期、高增长的原因有明确的终点：比如一项专利还有若干年到期，或者行业有法律、牌照造成的进入壁垒，预计若干年后放开。以及那些习惯把"偿债和再投资之后剩下的钱"都分掉的公司。

#### 5.5.3.1.2.3 H 模型：增长率逐步衰减

**为什么需要它。** 两阶段模型的断崖式下降不现实。H 模型假设增长率从初始的 $g_a$ 开始，在 $2H$ 年里**线性**下降到 $g_n$，之后永远保持 $g_n$；支付率和股权成本全程不变。在这个假设下，价值有一个近似公式：

$$
P_0 = \underbrace{\frac{\text{DPS}_0 \times (1+g_n)}{k_e - g_n}}_{\text{稳定增长部分}} + \underbrace{\frac{\text{DPS}_0 \times H \times (g_a - g_n)}{k_e - g_n}}_{\text{超常增长部分}}
$$

$H$ 是过渡期长度的**一半**。第一项是"假如从现在起就只按 $g_n$ 增长"的价值，就是戈登公式；第二项是超常增长额外贡献的价值。直觉是：$2H$ 年里，增长率从 $g_a$ 线性降到 $g_n$，平均多出 $(g_a - g_n)/2$，累计多出大约 $2H \times (g_a - g_n)/2 = H \times (g_a - g_n)$ 的增长，再按永续的方式资本化。

**例子（设想）。** 一家公司今年每股股息 0.50 元，今年的增长率是 10%，预计 10 年内（$H = 5$）线性降到 3%，之后永续 3%；股权成本 8%，支付率不变。

- 稳定增长部分 = $0.50 \times 1.03 / (8\% - 3\%) = 10.30$ 元
- 超常增长部分 = $0.50 \times 5 \times (10\% - 3\%) / (8\% - 3\%) = 3.50$ 元
- 合计 13.80 元

拿逐年计算核对一下：第 1 年增长 10%，之后每年下降约 0.78 个百分点，第 10 年降到 3%，逐年算股息并折现，再加第 10 年末的终值，得到 13.86 元。近似公式只差 0.4%。

**局限。** 第一，增长路径被锁死成一条直线，实际路径偏离不大时影响很小，偏离大就会出问题。第二，**支付率不变的假设和增长放缓是矛盾的**：增长率降下来，公司应该分得更多。也正因为支付率要从头到尾保持不变，它很难用在今天分红很少甚至为零的公司上。能同时满足"增长较高"和"已经分得较多"的公司不多，所以 H 模型的用途有限，主要价值是提供一个快速的心算工具：**超常增长的价值 ≈ 稳定增长部分 × $H \times (g_a - g_n) / (1+g_n)$**。上例：$10.30 \times 5 \times 7\% / 1.03 = 3.50$。

#### 5.5.3.1.2.4 三阶段模型：高增长 → 转型 → 稳定

**结构。** 第一段高增长、增速不变；第二段过渡期，增长率逐步下降；第三段稳定增长。和 H 模型不同，它**不对支付率和风险做任何限制**：过渡期里，支付率可以逐年上升，β 可以逐年向 1 回落。

$$
P_0 = \sum_{t=1}^{n_1} \frac{\text{DPS}_t}{(1+k_{e,hg})^t} + \sum_{t=n_1+1}^{n_2} \frac{\text{DPS}_t}{\prod_{j=1}^{t}(1+k_{e,j})} + \frac{\text{EPS}_{n_2} \times (1+g_n) \times \text{支付率}_{st}}{(k_{e,st} - g_n) \times \prod_{j=1}^{n_2}(1+k_{e,j})}
$$

公式看起来复杂，其实就是"逐年算股息、逐年折现、最后加终值"。过渡期的股权成本每年不同，所以分母是**累计折现因子**：比如第 7 年的折现因子 = $1.091^5 \times 1.0888 \times 1.0866$，而不是某个利率的 7 次方。

**例子：鲜川食品的三阶段版本。** 高增长期参数不变（5 年，增长 12%，支付率 50%，股权成本 9.1%）。第 6–10 年为过渡期，增长率、支付率、股权成本都按直线从高增长期水平走到稳定期水平；第 11 年起稳定增长（2.5%，支付率 80%，股权成本 8.0%）。

| 年份 | 增长率 | EPS | 支付率 | DPS | 股权成本 | 累计折现因子 | 现值 |
|---|---|---|---|---|---|---|---|
| 1–5 | 12% | | 50% | | 9.10% | | 合计 5.4131 |
| 6 | 10.1% | 3.8807 | 56% | 2.1732 | 8.88% | 1.6830 | 1.2913 |
| 7 | 8.2% | 4.1989 | 62% | 2.6033 | 8.66% | 1.8287 | 1.4236 |
| 8 | 6.3% | 4.4634 | 68% | 3.0351 | 8.44% | 1.9830 | 1.5305 |
| 9 | 4.4% | 4.6598 | 74% | 3.4483 | 8.22% | 2.1460 | 1.6068 |
| 10 | 2.5% | 4.7763 | 80% | 3.8210 | 8.00% | 2.3177 | 1.6486 |
| **1–10 合计** | | | | | | | **12.9140** |

- 第 10 年末价值 = $4.7763 \times 1.025 \times 80\% / (8\% - 2.5\%) = 71.21$ 元
- 折回今天：$71.21 / 2.3177 = 30.72$ 元
- 每股价值 = $12.91 + 30.72 = 43.64$ 元，约为今年 EPS的 21.8 倍

比两阶段模型的 39.41 元多了约 11%，原因是过渡期里增长率不是一下子掉到 2.5%，而是逐步下降，多出来的这几年增长是有价值的（ROE 高于股权成本）。

**代价。** 三阶段模型最灵活，几乎能套用到任何公司，但需要的输入也最多：每一年的增长率、支付率、β 都要设定。对本来就噪声很大的公司，输入的误差可能抵消掉灵活性带来的好处。排查思路和两阶段一样：价值极高，先看高增长期加过渡期是不是太长、稳定增长率是不是太高；价值极低，先看稳定期的支付率和 β。

**最适合的公司。** 目前以很高的速度增长，预计还能保持一段时间，随着规模变大、竞争优势被侵蚀而逐步放缓。这是大多数"值得研究"的成长公司的典型路径。

### 5.5.3.1.3 增长率的价值：增长只有在留存资本回报足够高时才增值

市场为增长付溢价：高增长公司的 PE、PB（市净率）都更高。增长有价值，这没有争议；问题是你**付了多少**。长期的实证研究发现，低市盈率股票的回报总体上好于高市盈率股票，一个常见的解释就是投资者在增长上付得太多。DDM提供了一把尺子：把一只股票的价值拆开，看其中多少是在为增长付钱。

**三段分解。** 任何一只股票的价值都可以拆成三块：

| 部分 | 怎么算 | 含义 |
|---|---|---|
| 现有资产的价值 | $\text{EPS}_0 / k_{e,st}$ | 假设公司从此不增长，利润全部分掉 |
| 稳定增长的价值 | $\text{EPS}_0 \times \text{支付率}_{st} \times (1+g_n) / (k_{e,st} - g_n) - \text{现有资产价值}$ | 假设公司从现在起就进入稳定增长，比不增长多出来的部分 |
| 超常增长的价值 | 总价值 − 前两项 | 高增长期带来的额外价值 |

拆分时要保持一致：算现有资产时，因为不增长，利润应该全部分掉（支付率 100%）；算稳定增长时，支付率要用稳定期的支付率。

用鲜川食品的两阶段估值（39.41 元）拆一下：

- 现有资产：$2.00 / 8\% = 25.00$ 元
- 稳定增长：$2.00 \times 80\% \times 1.025 / (8\% - 2.5\%) - 25.00 = 29.82 - 25.00 = 4.82$ 元
- 超常增长：$39.41 - 29.82 = 9.59$ 元

39.41 元里，有 25 元是"即使从此不再增长也值"的部分；为五年高增长付的钱是 9.59 元，约占四分之一。

**决定增长价值的三个因素。**

**1. 高增长期的增长率。** 增长率越高，超常增长的价值越大。反过来，一旦公司发布令人失望的消息、预期增长率下调，高增长公司的价值会掉得非常快，因为这部分价值对增长率很敏感。

**2. 高增长期的长度。** 鲜川食品的高增长期从 5 年延长到 10 年，价值从 39.41 元升到 50.35 元，超常增长的价值从 9.59 元翻到 20.53 元。"还能高增长几年"这个判断，本质上就是竞争优势期的判断（5.2.2.1）。

**3. 留存资本的回报率。** 这是最容易被忽视的一个。保持增长率 12% 不变，只把高增长期的 ROE从 24% 降到 12%：要维持 12% 的增长，公司得把利润 100% 留下来（$12\% \div 12\% = 100\%$），前五年一分钱股息都没有。价值从 39.41 元降到 34.00 元。**增长率一样，回报率不同，价值差了 14%。**

极端情况是 ROE 等于股权成本。把 $\text{支付率} = 1 - g/\text{ROE}$ 代入戈登公式：

$$
P_0 = \frac{\text{EPS}_1 \times (1 - g/\text{ROE})}{k_e - g}
$$

当 $\text{ROE} = k_e$ 时，分子变成 $\text{EPS}_1 \times (k_e - g)/k_e$，和分母约掉，$P_0 = \text{EPS}_1 / k_e$，**与增长率完全无关**。增长多少都不增加价值。5.2.1.3 比较的是 RONIC（新增资本回报率）和 WACC，这里是同一个结论在股东口径下的表述：把 RONIC 换成 ROE，把 WACC 换成股权成本。用这个公式算出的"ROE × 增长"PE 对照表见 5.5.4.2.1.3.3。

> **投资者怎么用**：拿市场价格减去"现有资产的价值"，就是市场为增长付的价格。比如鲜川食品股价 45 元，市场为增长付了 $45 - 25 = 20$ 元，而按你的假设，增长只值 14.41 元（4.82 + 9.59）。接下来要问的不是"市场是不是疯了"，而是：要值 20 元，高增长要持续多久、ROE 要维持在多高？这些条件站不站得住？

### 5.5.3.1.4 使用 DDM 时的问题

很多人认为 DDM"过时"，除了少数高分红股票之外没什么用。这个批评有一半是对的。下面三个问题里，有的能在模型内解决，有的要换模型。

#### 5.5.3.1.4.1 无股息或低股息公司

"不分红的公司不能用 DDM"，这个说法并不准确。DDM 能估这类公司，条件是**让支付率随增长放缓而上升**。

鲜川食品的 ROE12% 版本就是一个例子：前五年不分红（支付率 0），全部利润用于增长；第 6 年起进入稳定期，支付率升到 80%。模型算出 34.00 元，这个价值全部来自终值，但完全合理。真正的错误是把今天的低支付率一直延续下去：如果假设一家今天不分红的公司**永远**不分红，DDM 给出的价值就是零；如果把今天 10% 的支付率一直用到稳定期，价值也会被严重低估。

所以问题不在模型，而在你能不能合理预测"将来什么时候开始分、能分多少"。对稳定期，答案由 $1 - g_n / \text{ROE}$ 给出；对过渡期，要按增长放缓的节奏逐步提高。

但在两种情况下，这条路确实走不通，应该改用 FCFE（股权自由现金流）模型：

- **公司还在亏损或利润极不稳定**，"支付率 × 利润"这个结构本身就失去意义。
- **公司有能力分、却长期不分**，分红政策和赚钱能力脱节，你无从判断它将来会按能力分配。这就是下一个问题。

#### 5.5.3.1.4.2 实际股息显著低于可支付股息

很多公司分得比能分的少，钱留在账上，变成现金、理财，或者变成收购。这时 DDM只看到实际股息，会出两种偏差：

- **如果留下来的钱将来会以某种方式回到股东手里，并且在留存期间赚到了与风险相称的回报**，理论上 DDM 的价值不受影响，但实务中很容易算错：分析师往往用很低的实际支付率配上一个按 ROE 算出的增长率，而留存现金的回报远低于主业 ROE，增长被高估、现金流被低估，两头都是错的。
- **如果留下来的钱被投到了回报低于股东要求的地方**（低息理财、高价收购、多元化），这部分价值就真的被毁掉了。DDM 算出的低价值，反映的恰恰是小股东实际面对的处境。

一个常见的批评是"DDM 太保守，漏掉了公司持有的闲置资产"。这个问题容易解决：账上**已有的**闲置资产，比如多余的现金、长期不用的土地，可以单独估值后加上去（方法见 5.5.3.4.2）。

真正的难题在于**未来还会继续积累**的现金。这时应当同时算 FCFE模型，看两个价值差多少，差距就是"分红政策"本身的价值。这一点放到 5.5.3.2.2.2 用一个完整的例子展开。

#### 5.5.3.1.4.3 分红政策变化会让模型失真

**股息是"粘"的。** 公司普遍不愿意削减股息，因为削减会被市场解读成坏消息；也因此不太愿意轻易提高股息，怕将来维持不住。结果是股息的变化远比利润平滑，而且常常滞后于赚钱能力的变化。用过去几年的股息推断未来，可能低估了公司的分配能力。

**支付率突然改变时，模型要一起改。** 近几年 A股监管层持续引导上市公司提高现金分红，一些长期低分红、现金充裕的公司明显提高了分红比例，有的还公布了多年分红规划。比如贵州茅台，过去账上长期积累大量现金，近年公布了多年的股东回报规划，提高了现金分红比例。业务没有任何变化，用 DDM估出的价值会不会跳一下？

如果模型是一致的，就不会乱跳。提高支付率意味着留存减少，增长也要相应下调：$g = (1 - \text{支付率}) \times \text{ROE}$。用澜江电力算一下：支付率从 75% 提到 90%，增长率就从 2.5% 降到 1%，价值从 17.47 元变成 $0.90 \times 1.01 / (6.9\% - 1\%) = 15.41$ 元。价值反而下降了，因为这家公司留存资金的 ROE（10%）高于股权成本（6.9%），少留存就是放弃了创造价值的机会。

反过来，如果原来留存的钱本来就只能存在银行里赚低息，提高分红就是在止损，价值上升。**支付率变化对价值的影响，取决于少留的那部分钱原本能赚多少。** 模型失真的根源，是改了支付率却没改增长率，或者改了增长率却没改支付率。

**回购：把它算进股息。** 越来越多的公司用回购代替分红把现金还给股东。港股的腾讯派息不多，但近几年持续大额回购并注销。如果只看股息，就会漏掉大量的现金返还。最简单的修正是用**增广支付率**：

$$
\text{增广支付率} = \frac{\text{股息} + \text{回购}}{\text{净利润}}
$$

有三个注意事项：

1. **用多年平均。** 回购不像股息那样每年平稳发生，可能一年回购 60 亿，接下来三年一分不回购。所以要看 4–5 年的累计。
2. **扣掉借钱回购的部分。** 有的公司借钱回购是为了提高负债率，这部分不是经营产生的可分配现金：$\text{增广支付率} = (\text{股息} + \text{回购} - \text{长期借款净增加}) / \text{净利润}$。
3. **ROE 和增长率要跟着改。** 增广支付率提高，留存就少了，增长率要用 $(1 - \text{增广支付率}) \times \text{ROE}$ 重算。另外，回购会直接减少账面股东权益，把 ROE 抬高。用这个被抬高的 ROE 作为新投资的回报率，会高估价值。比较稳妥的做法是把近年的回购金额加回账面权益，再算 ROE。

一个设想的例子：

| 年份 | 1 | 2 | 3 | 4 | 5 | 合计 |
|---|---|---|---|---|---|---|
| 净利润 | 100 | 110 | 120 | 130 | 140 | 600 |
| 股息 | 40 | 44 | 48 | 52 | 56 | 240 |
| 回购 | 60 | 0 | 0 | 30 | 10 | 100 |
| 股息支付率 | 40% | 40% | 40% | 40% | 40% | **40.0%** |
| 增广支付率 | 100% | 40% | 40% | 63% | 47% | **56.7%** |

单看第 1 年，增广支付率是 100%；单看第 2 年，是 40%。五年合计是 56.7%。如果 ROE 是 20%，按股息支付率算的增长是 $20\% \times 60\% = 12\%$，按增广支付率算是 $20\% \times 43.3\% = 8.7\%$。用增广支付率，每年分给股东的更多，但增长更慢，两者对价值的影响方向相反，净效应因公司而异。这和 5.2.1.7 的结论一致：回购本身不创造价值，它只是现金返还的另一种形式。

**用 DDM 估整个市场。** 同样的方法可以用在一个指数上：价格换成指数点位，股息换成成分股的股息总额（最好加上回购），增长率用指数整体的盈利增长，β 等于 1，股权成本就是无风险利率加股权风险溢价。要注意两点：整个市场的盈利不可能长期比整体经济增长得快；而且在回购盛行的市场，只算股息会严重低估。曾有人用这个方法测算美国标普 500 指数：只算股息，得出的价值远低于实际点位；把回购加进去，结果和实际点位就相差不大了。把这个方法反过来用，让模型价值等于当前点位、解出股权风险溢价，就是 5.5.2.3.4.3.2 的隐含股权风险溢价。

**DDM 是"逆向"的吗？** 有人认为 DDM 天然偏保守：牛市里能找到的"低估股"越来越少。这要看牛市是怎么来的。如果市场上涨是因为经济前景改善、利率下降，DDM 的价值也会同步上升；如果上涨和基本面无关，DDM 不跟，它会告诉你相对股息和现金流来说市场贵了。这应该看作模型的长处。

---

### 5.5.3.1.5 DDM 更适合的情形

一个判断原则：**DDM适合"股息基本就是可分配现金"的公司。** 股息和可分配现金差得越远，越该换成 FCFE模型。具体有三类。

#### 5.5.3.1.5.1 分红稳定且与盈利能力相匹配

检验办法很直接：看过去 5–10 年，"股息 + 回购"占 FCFE 的比例是不是长期接近 1（这个比率见 5.5.2.1.6.4）。接近 1，说明公司基本把能分的都分了，DDM 和 FCFE 模型会给出相近的结果，用哪个都行，DDM 更简单。

A股里的长江电力是常被提到的例子：大型水电站建成后资本开支有限，现金流稳定，公司公开承诺了多年期的最低分红比例。这类"承诺式分红"让未来的支付率比较好预测，降低了模型最难的那部分不确定性。不过承诺有期限，到期后会不会延续，仍然需要判断。

#### 5.5.3.1.5.2 资本结构受监管、股息可反映可分配现金的金融企业

银行、保险公司是 DDM 用得最多的地方，原因不是它们分红多，而是**别的现金流很难定义**：

- 对一家银行，借来的钱（存款）是"原材料"而不是融资，FCFF和 WACC都失去了清晰的含义。
- 银行的"再投资"不是厂房设备，而是为了支撑贷款增长必须补充的资本。资本开支、营运资本这些概念套不上去，FCFE 也不好算。
- 监管对资本充足率有硬性要求，这直接约束了能分多少：贷款要增长，就得留存利润补充资本，剩下的才能分。所以股息本身就比较接近"可分配现金"。

A股的国有大型银行多年来维持三成左右的现金分红比例，是一个监管资本、增长需要和股东回报之间的平衡结果。用 DDM 估银行时，关键仍然是一致性：支付率要和 ROE、贷款增长、资本充足率要求同时成立。金融机构估值的完整方法（包括股权现金流法、超额回报模型）见 5.6.1.1。

#### 5.5.3.1.5.3 成熟、高分红、增长路径相对清晰的公司

公用事业、高速公路、港口、成熟的能源公司，以及房地产投资信托基金（REIT）。香港的 REIT 按规定每年要把不少于 90% 的可分配收入派给持有人，股息几乎就是全部可分配现金，戈登模型或两阶段模型都很自然。

但要警惕"高分红"本身的陷阱。分红高有两种原因：一种是确实没有好的投资机会，把钱还给股东是正确的选择；另一种是公司**超出能力**在分，靠借钱或增发维持股息。后一种情况，DDM 会高估价值。所以对高股息股，也要用 FCFE 核对一下：股息是不是长期高于 FCFE？

**关于 DDM 有效性的证据。** 有不少研究检验过"按 DDM 买入低估股、卖出高估股"的效果。一项研究用 DDM 给 1980 年底的 150 只美国股票估值，按低估程度分成五组：随后几年（1981—1983）里，最低估的一组每年超额回报约 16%，最高估的一组每年约 −15%。另一项基金实践覆盖 1979—1991 年的 13 年，低估组合整体大幅跑赢，但其中有 6 年跑输市场。

这些证据说明三点。第一，DDM 的优势要在较长的持有期里才能体现，任何一年都可能失灵。第二，DDM 挑出来的低估股往往就是低市盈率、高股息率的股票，它的超额回报有多少是模型本身的贡献、有多少只是这两类已知现象，很难分开；有研究发现，控制住这些因素之后，模型自己的贡献很小。第三，这些研究大多没考虑税。高股息组合要多交股息税，对需要纳税的投资者，超额回报会被吃掉一部分。

> **投资者怎么用**：用 DDM 之前先问一句，"这家公司的股息，是它能分的钱吗？"银行、公用事业、REIT、有分红承诺的成熟公司，答案通常是肯定的，DDM 简单可靠。成长公司、长期囤积现金的公司、靠借钱维持分红的公司，答案是否定的，转向下一节的 FCFE 模型。

## 5.5.3.2 股权自由现金流贴现模型（FCFE）

### 5.5.3.2.1 FCFE 的经济含义：股东在不损害未来经营的前提下可取得的现金

**要回答的问题。** 一家公司今年分红加回购一共给了股东 30 亿元。这是多了还是少了？要回答这个问题，需要一把尺子：**付完所有该付的、投完所有该投的之后，公司本来能给股东多少？** 这把尺子就是 FCFE（股权自由现金流）。

**一行回顾。** FCFE 的定义、逐项口径，以及从 FCFF（公司自由现金流）往下推的换算，5.5.2.1.6.1 已经完整讲过。本节只用到结果：

$$
\text{FCFE} = \text{净利润} - (\text{资本开支} - \text{折旧}) - \text{非现金营运资本的增加} + (\text{新增借款} - \text{偿还借款})
$$

换成一句话：股东的利润，扣掉再投资里**股东自己出钱**的那部分；借来的那部分不用股东出。

**例子：和安大药房（设想）。** 一家连锁药房，今年的数据如下（单位：亿元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 10 | |
| 资本开支 | 8 | 开新店、装修、物流中心 |
| 折旧 | 4 | |
| 资本净支出 | 4 | $8 - 4$ |
| 非现金营运资本增加 | 2 | 新店要铺存货 |
| 新增借款 | 3 | |
| 偿还借款 | 1 | |
| **FCFE** | **6** | $10 - 4 - 2 + (3 - 1)$ |

把再投资和净借款合在一起，叫**股权再投资**：$4 + 2 - 2 = 4$ 亿元，即股东自己掏的再投资。它占净利润的 40%，叫**股权再投资率**（这个概念在增长估算里的用法见 5.4.1.4，本节 5.5.3.2.3 还会用到）。

**预测时按目标负债比例借款。** 历史上的净借款是一块一块发生的，直接外推会让 FCFE 大起大落。预测时改为假设：公司按一个目标比例 δ 用借款为再投资融资，剩下的由股东出（为什么这样简化、怎样从历史数据估出 δ，见 5.5.2.1.6.2）：

$$
\text{FCFE} = \text{净利润} - (1 - \delta) \times (\text{资本开支} - \text{折旧}) - (1 - \delta) \times \text{营运资本增加}
$$

和安大药房如果按 30% 的目标比例借款：FCFE = $10 - 4 \times 0.7 - 2 \times 0.7 = 5.8$ 亿元。本节后面的康衡医疗例子就用这种写法。

**加杠杆是免费午餐吗？** 从公式看，δ 越大，股东要出的钱越少，FCFE 越高。5.5.2.1.6.2 已经用"借钱发特别股息"演示过：如果股权成本不跟着调，估值会凭空上升。这里补上另一半：**股权成本应该升多少。** 借得越多，股东承担的风险越大，β（贝塔系数）越高。比如一家公司业务的无杠杆 β 是 0.8，不借钱时股权成本 = $2.5\% + 0.8 \times 5.5\% = 6.9\%$；把债务/股权比提到 50%（税率 25%），有杠杆 β = $0.8 \times (1 + 0.75 \times 0.5) = 1.1$，股权成本升到 $2.5\% + 1.1 \times 5.5\% = 8.55\%$（β 怎么加杠杆见 5.5.2.3.4.4.3）。FCFE 升了，折现率也升了，净效果取决于哪边更大，归根结底取决于税盾和财务困境成本的权衡（5.5.2.3.6）。借钱本身只是把风险和回报在股东和债权人之间重新分配（5.2.1.7）。

**优先股和永续债。** 如果公司有优先股，优先股股息要从 FCFE 中扣掉，优先股的净发行也要像借款一样处理，因为普通股股东排在优先股后面。在 A股和港股，更常见的是**永续债**：会计上计入权益，经济上是债（5.2.1.7）。算 FCFE 时，永续债的利息要扣掉，永续债的发行和赎回要像借款一样加减；估出的价值只属于普通股股东，不能再把永续债当成股东的钱（5.5.3.4.3）。

**和 FCFF 的关系。** FCFF 是付给债权人**之前**的现金，FCFE 是付给债权人**之后**的现金，两者的换算式见 5.5.2.1.6.1。两条路算出的股权价值什么时候能对上，是 5.5.3.2.7 要检验的。

---

### 5.5.3.2.2 FCFE 与股息的差别

#### 5.5.3.2.2.1 股息是管理层实际支付的金额

股息由董事会决定，它反映的不只是公司能分多少，还反映了管理层的意愿、顾虑和利益。全球范围看，大多数公司分的都少于 FCFE。原因主要有五类：求稳（股息有"粘性"，宁可定在坏年份也付得起的水平）、为将来的投资留钱、税、信号、管理层自身的利益。每一类的机制，以及在 A股、港股的表现，见 5.5.2.1.6.4 的表格。

对估值要紧的一点是：这五类原因大多是长期存在的，所以"股息低于 FCFE"往往不是一两年的现象，而会一直持续下去。这正是下一小节里两个模型会给出不同价值的根源。

**也有分得比能分的多的。** 有的公司股东偏好股息，或者面临监管和舆论的分红压力，于是靠借钱或增发来维持股息。A股里"一边大额股权融资、一边现金分红"的现象并不少见。这会从三个方向损害价值：

1. **发行费用。** 为了分红去增发，等于先从股东手里收钱、扣掉承销等费用，再以股息的形式还回去。绕这一圈，股东白白付了一笔发行成本，而股票发行的费用并不低。
2. **负债过高。** 借钱分红，会把负债推到超过合理水平，增加陷入困境甚至违约的风险（5.5.2.3.6）。
3. **好项目被放弃。** 钱都拿去分红了，有好的投资机会时反而没钱投，只能放弃，失去的是本来能创造的价值。

这三种损害都不会出现在股息里：DDM（股息贴现模型）看到的是一串又高又稳的股息，估出的价值偏高。FCFE 模型则直接显示"能分的没这么多"，所以这时应当相信 FCFE 模型（5.5.3.2.2.2）。

#### 5.5.3.2.2.2 FCFE 是潜在可支付金额

FCFE 是股东**能**拿到多少，股息加回购是股东**实际**拿到多少。两者之比（返还现金 / FCFE）可以用来判断公司是不是把能分的都分了，它的三种读法见 5.5.2.1.6.4：长期接近 1，基本分足；长期远低于 1，在囤积现金；长期远高于 1，在消耗存量现金或靠融资分红。本节要回答的是下一步的问题：比率偏离 1 时，两个模型估出的价值会差多少，差距又意味着什么。

**两个模型什么时候给出相同的价值。** 用开头的甲、乙两家公司来算。设想一家公司"守成实业"：

- 主业下一年净利润 100，以后每年增长 2.5%
- 主业每年需要再投资净利润的 20%，相当于新投资的 ROE（净资产收益率）为 $2.5\% / 20\% = 12.5\%$，所以主业每年的 FCFE = 80
- 股权成本 8%

**FCFE 模型**假设 80 全部分给股东：价值 = $80 / (8\% - 2.5\%) = 1454.5$。

DDM则只数实际股息。现在假设公司实际只把**全部净利润**（主业利润加上留存资金的收益）的 40% 作为股息分掉。主业 FCFE 中没分掉的部分留在公司，投到风险和主业相同、回报率为 $r_c$ 的项目上，这些项目的收益也计入净利润、按 40% 分配。逐年算出股息，按 8% 折现（用电子表格算 4000 年，足以收敛）：

| 留存资金的回报率 $r_c$ | DDM 价值 | 与 FCFE 价值（1454.5）比较 |
|---|---|---|
| 8%（等于股东要求的回报） | 1454.5 | 相同 |
| 2%（低于股东要求的回报） | 812.8 | 少 44% |

第一行是关键：**只要留下来的钱赚到了股东要求的回报，少分红不损失任何价值**，DDM 和 FCFE 给出完全一样的结果。少分的钱只是晚一点、以更大的金额回到股东手里。用一年来看最清楚：今年少分 40，投到 8% 的项目，明年回来 43.2，折回今年正好是 40；投到 2% 的项目，明年回来 40.8，折回今年只有 37.8，每次囤积都损失 2.2。日积月累，损失了 44%。

所以，两个模型给出相同价值的情形有两种：**股息等于 FCFE；或者股息低于 FCFE，但多出来的钱投到了净现值为零的地方**（比如按公允价格买入的金融资产）。

**两个模型给出不同价值的情形：**

- **FCFE 价值 > DDM 价值**：公司分得少，多出来的钱赚得少，或者被用来做了高价收购。这在现实中相当常见。另一个原因是：分得少的公司账上现金多，往往也就很少借钱，少用了债务的税盾，资本成本可能因此偏高（5.5.2.3.6）。
- **DDM 价值 > FCFE 价值**：公司分得比能分的多，靠发新股或借钱补缺口。这时应该相信 FCFE 模型，因为这样的股息不可持续。

两个模型在假设上的差别：

| | DDM | FCFE 模型 |
|---|---|---|
| 隐含假设 | 只分股息；没分的利润一部分投到经营资产，一部分变成现金和金融资产 | FCFE 全部分掉；没分的利润只投到经营资产 |
| 增长率 | 经营资产和现金资产合在一起的利润增长：留存率 × 整体 ROE | 只算经营资产的利润增长：股权再投资率 × 非现金 ROE（5.5.3.2.3） |
| 现金和金融资产 | 其收益计入利润、最终进入股息，不另加 | 要么把其收益计入利润一起估，要么剔除其收益、最后单独加回现金价值 |

**差距是什么：控制分红政策的价值。** 两个模型的价值之差，衡量的是"谁来决定分多少"的价值。一个有能力改变分红政策的买家，比如敌意收购方，买下公司后可以把 FCFE 全部分掉，拿到 FCFE 模型的价值；一个小股东只能接受管理层给多少拿多少，拿到的更接近 DDM 的价值。

所以拿哪个价值和股价比较，取决于**控制权有多大可能易手**。如果公司有可能被收购、管理层有可能被替换，市场价格会反映这种可能性，FCFE 模型的价值是更恰当的参照。如果控制权几乎不可能改变，比如 A股、港股常见的有稳定控股股东的国企和家族企业，小股东真正能拿到的就是股息，DDM 的价值可能更贴近现实。控制权的定价见 5.7.2.4。

> **投资者怎么用**：一家公司 FCFE 估值很高、DDM 估值很低，不要直接得出"低估"的结论。先问：这个差距要靠什么才能兑现？大股东会不会提高分红？监管会不会推动？有没有被收购的可能？如果都没有，你买到的可能只是一个永远兑现不了的"潜在价值"。

### 5.5.3.2.3 FCFE 的增长

FCFE和股息一样是股东的现金流，所以增长率的基本公式也一样：$g = \text{留存率} \times \text{ROE}$（完整推导见 5.4.1.4）。但直接套用会出问题。

**问题一：留存率和 FCFE 的假设矛盾。** 留存率 = 1 − 股息 / 净利润，它假设所有没分掉的利润都投回了公司。而 FCFE 模型假设 FCFE 全部分掉，真正留在公司里的只有股权再投资。所以应该用**股权再投资率**代替留存率：

$$
\text{股权再投资率} = \frac{\text{资本开支} - \text{折旧} + \text{营运资本增加} - \text{净借款}}{\text{净利润}}
$$

和安大药房的股权再投资率是 40%。如果它把股息定在利润的 20%，留存率就是 80%。用 80% 算增长，等于把那 40% 没分掉也没投出去、只是躺在账上的现金也当成了在赚主业回报。

**问题二：ROE 被现金拉低了。** 普通的 ROE分子里包括现金和理财的利息收入，分母里包括现金和理财本身。现金的回报率通常远低于主业，这会把 ROE 拉低。FCFE 模型假设公司没有多余现金，所以应该用**非现金 ROE**：

$$
\text{非现金 ROE} = \frac{\text{净利润} - \text{现金和金融资产的税后收益}}{\text{股东权益账面值} - \text{现金和金融资产}}
$$

设想一家公司净利润 100，其中 10 是现金的税后利息；股东权益 1000，其中现金 200。普通 ROE 是 10%；非现金 ROE = $(100 - 10) / (1000 - 200) = 11.25\%$。主业实际比报表看起来更赚钱。

于是 FCFE 的增长率是：

$$
g_{\text{FCFE}} = \text{股权再投资率} \times \text{非现金 ROE}
$$

估值时最稳妥的做法是**把现金拆出来**：用剔除了现金收益的净利润预测 FCFE，用非现金 ROE 算增长，估出经营资产对应的股权价值，再把现金和金融资产的价值单独加上去（5.5.3.4.2.1）。

**问题三：杠杆会让股东的增长快于经营的增长。** 净利润的增长来自 ROE，而 ROE 受杠杆影响：

$$
\text{ROE} = \text{ROIC} + \frac{D}{E} \times \left[\text{ROIC} - k_d(1-t)\right]
$$

借来的钱如果投到了 ROIC（投入资本回报率）高于税后借款成本的项目，多出来的回报归股东。比如 ROIC 10%、税后借款成本 3.75%、债务/股权 0.5，ROE = $10\% + 0.5 \times 6.25\% = 13.1\%$。所以高增长期里，净利润的增长率可以高于经营利润的增长率。

但**进入稳定期后，两者必须相同**。假设经营利润永远增长 5%，净利润永远增长 6%，那么总有一天净利润会超过经营利润，再往后甚至超过收入，这不可能。所以稳定期里，所有利润口径的增长率都要统一。杠杆如何同时改变 ROE 和增长，见 5.4.1.4.4。

### 5.5.3.2.4 固定增长模型

**公式。** 处在稳定增长状态的公司：

$$
\text{股权价值} = \frac{\text{FCFE}_1}{k_e - g_n}
$$

$\text{FCFE}_1$ 是下一年的 FCFE，$k_e$ 是股权成本，$g_n$ 是永续增长率。结构和戈登模型完全一样，约束也一样：$g_n$ 不能超过经济的长期名义增长率；β 接近 1。如果公司本来就把 FCFE 全部分掉，这个模型和戈登模型给出相同的价值。

**最关键的约束：稳定期的再投资。** 稳定增长的公司仍然需要再投资，只是比高增长期少。实务里最常见的两种错误，一种是让资本开支远超折旧（照搬高增长期的再投资水平），另一种是让资本开支**等于**折旧、营运资本不变，也就是再投资为零，同时却假设利润永续增长。估算稳定期再投资有两种方法：

1. **用行业里稳定公司的平均再投资水平**，比如"资本开支 / 折旧"的行业平均。风险是行业本身可能不稳定，平均数偏高或偏低。
2. **用基本面关系**：$\text{股权再投资率} = g_n / \text{ROE}$。比如稳定增长 4%、ROE12%，股权再投资率就是 1/3，FCFE 是净利润的 2/3。本体系优先用这种方法，因为它直接把增长和再投资绑在一起（5.5.2.2.1）。

**例子：恒岳汽配（设想）。** 一家成熟的汽车零部件公司，假设：

- 剔除现金利息之后的净利润 50 亿元（已检查过，不是周期高点或低点）
- 永续增长 2.5%，长期非现金 ROE 10%，所以股权再投资率 = $2.5\% / 10\% = 25\%$
- β 1.2（汽车产业链周期性较强），股权成本 = $2.5\% + 1.2 \times 5.5\% = 9.1\%$
- 账上现金 120 亿元
- 今年实际的股权再投资率只有 15%

| 设定 | 股权再投资率 | 增长率 | 经营部分的股权价值（亿元） |
|---|---|---|---|
| **一致：再投资 = $g/\text{ROE}$** | 25% | 2.5% | **582.4** |
| 照搬今年的再投资，增长仍用 2.5% | 15% | 2.5% | 660.0 |
| 照搬今年的再投资，增长相应下调 | 15% | $15\% \times 10\% = 1.5\%$ | 567.6 |
| 再投资为零（资本开支 = 折旧） | 0% | 2.5% | 776.5 |

*计算：$50 \times (1+g) \times (1 - \text{股权再投资率}) / (9.1\% - g)$。第一行：$50 \times 1.025 \times 0.75 / 0.066 = 582.4$。*

第一行加上现金 120 亿元，股权价值约 702 亿元。

第二行和第四行的错误一样：**增长没花钱**。第二行高估 13%，第四行高估 33%。第三行是另一种一致的做法：既然只投 15%，增长就只能有 1.5%。至于用哪一种，取决于你相信今年的低再投资是常态，还是暂时的。

**排查表。**

| 现象 | 可能的原因 | 处理办法 |
|---|---|---|
| 价值极低 | 资本开支相对折旧太高 | 用 $g_n / \text{ROE}$ 重算再投资，或改用两阶段模型 |
| | 营运资本占收入比例过高 | 用历史平均水平正常化 |
| | β 对稳定公司来说太高 | 用接近 1 的 β |
| 价值极高 | 资本开支低于折旧 | 至少让资本开支不低于折旧，并按 $g_n / \text{ROE}$ 设定再投资 |
| | 营运资本占收入比例为负且还在变大 | 长期不应假设负营运资本持续扩大 |
| | 增长率对稳定公司来说太高 | 用不超过无风险利率的增长率 |

**最适合的公司。** 增长不超过名义经济增长的成熟公司，尤其是分红和 FCFE 不一致的那些：分得远少于 FCFE 的（DDM 会低估），或者分得远多于 FCFE、靠融资维持的（DDM 会高估）。

### 5.5.3.2.5 两阶段模型

**公式。** 和两阶段 DDM结构相同，只是把股息换成 FCFE：

$$
\text{股权价值} = \sum_{t=1}^{n} \frac{\text{FCFE}_t}{(1+k_{e,hg})^t} + \frac{P_n}{(1+k_{e,hg})^n}, \qquad P_n = \frac{\text{FCFE}_{n+1}}{k_{e,st} - g_n}
$$

**终值是最容易出错的地方。** 高增长期里资本开支远超折旧是正常的；进入稳定期，两者的差距必须缩小。如果简单地让资本开支、折旧都按利润的增长率一路增长到终值，第 $n+1$ 年的再投资就会停留在高增长期的水平，严重低估终值。

**例子：康衡医疗（设想）。** 一家医疗器械公司，按每股计算，假设：

- 今年 EPS（每股收益）3.00 元，每股资本开支 2.40 元，每股折旧 1.20 元，每股营运资本增加 0.30 元
- 未来 5 年，利润、资本开支、折旧、营运资本增加都按 15% 增长
- 再投资的 20% 用借款（δ = 20%）
- 高增长期 β 1.2，股权成本 9.1%
- 第 6 年起永续增长 2.5%，稳定期 ROE15%，股权再投资率 = $2.5\% / 15\% = 16.7\%$；β 降到 1.0，股权成本 8.0%

高增长期每年的每股股权再投资 = （资本开支 − 折旧 + 营运资本增加）×（1 − 20%）：

| 年份 | EPS | 资本开支 | 折旧 | 营运资本增加 | 股权再投资 | FCFE | 现值（9.1%） |
|---|---|---|---|---|---|---|---|
| 1 | 3.4500 | 2.7600 | 1.3800 | 0.3450 | 1.3800 | 2.0700 | 1.8973 |
| 2 | 3.9675 | 3.1740 | 1.5870 | 0.3967 | 1.5870 | 2.3805 | 1.9999 |
| 3 | 4.5626 | 3.6501 | 1.8250 | 0.4563 | 1.8250 | 2.7376 | 2.1081 |
| 4 | 5.2470 | 4.1976 | 2.0988 | 0.5247 | 2.0988 | 3.1482 | 2.2221 |
| 5 | 6.0341 | 4.8273 | 2.4136 | 0.6034 | 2.4136 | 3.6204 | 2.3423 |
| **合计** | | | | | | | **10.5698** |

高增长期的股权再投资率始终是 40%（比如第 1 年 $1.38 / 3.45$），对应的 ROE 是 $15\% / 40\% = 37.5\%$。医疗器械龙头有这样的回报率并不离谱，但这个数字本身就是一个需要追问的假设。

第 6 年 EPS = $6.0341 \times 1.025 = 6.1849$ 元。终值有三种算法：

| 第 6 年的股权再投资怎么定 | 第 6 年 FCFE | 第 5 年末价值 | 每股价值 |
|---|---|---|---|
| **按 $g_n / \text{ROE} = 16.7\%$** | 5.1541 | 93.71 | **71.20** |
| 延续高增长期的 40% | 3.7110 | 67.47 | 54.22 |
| 再投资为零（资本开支 = 折旧，营运资本不变） | 6.1849 | 112.45 | 83.32 |

*计算：第 5 年末价值 = 第 6 年 FCFE ÷（8% − 2.5%）；每股价值 = 10.57 + 第 5 年末价值 ÷ $1.091^5$（1.5457）。*

延续高增长期的再投资，价值低估 24%；完全不再投资，高估 17%。**稳定期的再投资必须由稳定期的增长和回报率倒推出来。** 稳定期的 β 和负债率也要同步调整：成熟公司的 β 接近 1，而且通常比高增长时能承受更多负债。

**排查表。** 两阶段 FCFE 模型算出的价值极低，常见原因是：利润被周期压低（用正常化利润，5.3.1.2.4）；稳定期资本开支远超折旧；稳定期 β 太高；营运资本占收入的比例高得不可持续；该用三阶段时用了两阶段。价值极高，常见原因是：利润在周期高点；高增长期的资本开支还低于折旧；稳定期增长率太高。

**最适合的公司。** 增长路径和两阶段 DDM 相同（先高增长，然后突然降到稳定），但股息和 FCFE 不一致的公司。

### 5.5.3.2.6 三阶段模型

**公式。** 高增长期、过渡期各年的 FCFE现值，加上过渡期末终值的现值：

$$
\text{股权价值} = \sum_{t=1}^{n_1} \frac{\text{FCFE}_t}{(1+k_e)^t} + \sum_{t=n_1+1}^{n_2} \frac{\text{FCFE}_t}{(1+k_e)^t} + \frac{P_{n_2}}{(1+k_e)^{n_2}}, \qquad P_{n_2} = \frac{\text{FCFE}_{n_2+1}}{k_{e,st} - g_n}
$$

股权成本逐年变化时，分母换成累计折现因子。

**三个变量要同步转换。** 从高增长走向稳定，不只是增长率在变：

- **再投资**：高增长期资本开支远超折旧，过渡期差距缩小，稳定期只保留支撑 $g_n$ 所需的部分（$g_n / \text{ROE}$）。
- **风险**：公司变大、业务变多元之后，β 会向 1 收敛。高 β 组合的 β 长期向 1 回归，有实证支持。
- **回报率**：竞争把超额回报逐步压低，新投资的 ROE 向行业水平靠拢。

**例子：新曜储能（设想）。** 一家储能设备公司，正处在快速扩产期。假设（单位：百万元）：

- 今年净利润 100
- 第 1–5 年：利润增长 30%，股权再投资率 120%，即新投资的 ROE为 $30\% / 120\% = 25\%$；β 1.5，股权成本 = $2.5\% + 1.5 \times 5.5\% = 10.75\%$
- 第 6–10 年：增长率、股权再投资率、股权成本都按直线过渡
- 第 11 年起：增长 2.5%，ROE 12.5%，股权再投资率 = $2.5\% / 12.5\% = 20\%$；β 1.0，股权成本 8.0%

| 年份 | 增长率 | 净利润 | 股权再投资率 | FCFE | 股权成本 | 累计折现因子 | 现值 |
|---|---|---|---|---|---|---|---|
| 1 | 30.0% | 130.00 | 120% | −26.00 | 10.75% | 1.1075 | −23.48 |
| 2 | 30.0% | 169.00 | 120% | −33.80 | 10.75% | 1.2266 | −27.56 |
| 3 | 30.0% | 219.70 | 120% | −43.94 | 10.75% | 1.3584 | −32.35 |
| 4 | 30.0% | 285.61 | 120% | −57.12 | 10.75% | 1.5044 | −37.97 |
| 5 | 30.0% | 371.29 | 120% | −74.26 | 10.75% | 1.6662 | −44.57 |
| 6 | 24.5% | 462.26 | 100% | 0.00 | 10.20% | 1.8361 | 0.00 |
| 7 | 19.0% | 550.09 | 80% | 110.02 | 9.65% | 2.0133 | 54.65 |
| 8 | 13.5% | 624.35 | 60% | 249.74 | 9.10% | 2.1965 | 113.70 |
| 9 | 8.0% | 674.30 | 40% | 404.58 | 8.55% | 2.3843 | 169.68 |
| 10 | 2.5% | 691.16 | 20% | 552.93 | 8.00% | 2.5751 | 214.72 |
| **合计** | | | | | | | **386.83** |

*FCFE = 净利润 ×（1 − 股权再投资率）。过渡期隐含的新投资 ROE（增长率 ÷ 股权再投资率）从 24.5% 逐步降到 12.5%，和竞争侵蚀超额回报的叙事一致。*

- 第 11 年 FCFE = $691.16 \times 1.025 \times (1 - 20\%) = 566.75$
- 第 10 年末价值 = $566.75 / (8\% - 2.5\%) = 10305$
- 折回今天：$10305 / 2.5751 = 4002$
- 股权价值 = $386.83 + 4002 = 4388$ 百万元。如果总股本 2 亿股，每股约 21.94 元

价值的 91% 来自终值，前五年的 FCFE 全是负数。这在高增长公司里很典型。

**负的 FCFE 意味着什么。** 和股息不同，FCFE 可以是负数：利润是负的，或者再投资大到利润和新增借款都填不满。新曜储能前五年就是后一种情况。从直觉上说，负的 FCFE 意味着**公司必须向股东要钱**，也就是增发新股。A股里高速扩产的成长公司频繁定增，背后就是这个逻辑。

这对每股价值意味着什么？**未来增发造成的稀释，已经体现在今天的估值里了**。负的 FCFE 在折现时直接减少了股权价值，相当于股东今天就承担了将来要掏的钱。所以用今天的股数去除就可以，**不要再另外扣一次未来增发的稀释**，否则就算重了。需要单独处理的稀释，只是已经发出去的期权、限制性股票和可转债（5.5.3.4.4）。

**排查表。** 价值极低：稳定期资本开支远超折旧；稳定期 β 太高；营运资本比例高得不可持续。价值极高：高增长期和过渡期的资本开支不够支撑增长（甚至低于折旧）；增长期太长；稳定增长率太高。

**最适合的公司。** 目前增长很快、预计增长率逐步下滑、股息和 FCFE 差别很大的公司。

### 5.5.3.2.7 FCFE 与 FCFF 何时会得到相同或不同的股权价值

股权价值有两条路可以算：

- **股权法**：用 FCFE按股权成本折现，直接得到股权价值。
- **企业法**：用 FCFF按 WACC（加权平均资本成本）折现，得到企业价值，再减去债务（5.5.3.3、5.5.3.4）。

理论上两条路的终点应该一样。实际上，要让它们一样，比想象中难得多。

**一个能对上的例子。** 设想一家不增长、不再投资、永续经营的公司（单位：百万元）：

| 项目 | 数值 |
|---|---|
| 息税前利润 EBIT | 120 |
| 税率 | 25% |
| 债务（市值） | 400，税前利率 5% |
| 股权成本 | 10% |

**股权法**：净利润 = $(120 - 400 \times 5\%) \times (1 - 25\%) = 100 \times 0.75 = 75$。不增长也不再投资，FCFE 就等于净利润，股权价值 = $75 / 10\% = 750$。

**企业法**：税后经营利润 = $120 \times 0.75 = 90$，也就是 FCFF。WACC 用市值权重：股权 750、债务 400，合计 1150：

$$
\text{WACC} = \frac{750}{1150} \times 10\% + \frac{400}{1150} \times 5\% \times (1 - 25\%) = 6.52\% + 1.30\% = 7.83\%
$$

企业价值 = $90 / 7.83\% = 1150$，减去债务 400，股权价值 = **750**。两条路对上了。

**能对上，靠的是三个暗含的假设：**

1. **WACC 里的权重，等于估值算出来的价值。** 例子里 WACC 用的股权权重是 750，恰好是最后算出的股权价值。这里有个循环：要算价值，先得有 WACC；要算 WACC，先得知道价值。如果用当前市值做权重，而股价本身偏离了你估的价值，两条路就对不上。
2. **从经营利润到净利润，中间只有利息和税。** 如果有非经营收益（投资收益、资产处置损益）或一次性项目，影响净利润却不影响经营利润，两条路的现金流就不对应。
3. **利息等于"债务市值 × 当前借款利率"。** 如果公司账上还挂着几年前发的高息旧债，实际利息和这个乘积不一样，两条路也会出现偏差。

**加上增长，难度更大。** 企业法的 WACC 假设负债率保持不变；股权法要做到一致，就必须假设公司每年借入足够的新债，让负债率保持在同一水平，而且股权成本要按这个负债率对应的 β 计算。只要两边对借款的假设不同（比如企业法用目标负债率 30%，股权法却假设公司不再借新债），结果就会分开。

**常见的不一致来源，以及怎么查：**

| 不一致的来源 | 检查办法 |
|---|---|
| 负债率假设不同 | FCFE 预测中的 δ 和净借款，要和 WACC 里的 D/V 一致 |
| 股权成本没有按负债率调整 | 用无杠杆 β 按同一负债率重新加杠杆（5.5.2.3.4.4.3） |
| 债务用账面值，利率用历史票面利率 | 都改用市值和当前利率 |
| 现金处理不同 | 两边都剔除现金收益，最后统一加回现金 |
| 稳定期增长率不同 | 稳定期里净利润和经营利润必须同速增长 |

**实际中怎么选。** 两条路理论上等价，实践中各有所长：

- **企业法更适合负债率很高、很低或正在大幅变化的公司。** 负债率变化时，股权法要逐年预测借款和还款，算起来繁琐，而且高杠杆公司的股权只占企业价值的一小部分，对假设极其敏感。企业法只要在 WACC 里反映负债率的变化即可（资本结构变化剧烈时，5.5.3.3.4 的 APV（调整现值法）更自然）。
- **股权法更直观。** 大多数人习惯像老板一样思考：利息、还本都是实实在在的现金流出。FCFF 回答的是一个假设性问题：如果公司没有债务，它能产生多少现金？
- **股权法能暴露生存问题。** 一家公司 FCFF 每年 1 亿元，但债务负担沉重，FCFE 是 −5000 万元。它必须每年融到 5000 万元新股才能维持下去，否则一切都不牢靠。只看 FCFF，你看不到这个问题。
- **金融机构只能用股权法**（5.5.3.1.5.2、5.6.1.1）。

> **另一种看法**：另一派主张，非金融企业应当以企业 DCF（现金流折现）或经济利润模型为主，股权法只用于金融机构，理由是股权现金流把经营和融资混在一起，负债率一变股权成本就得跟着变，很难保持一致。这个分歧的完整论证和取舍见 5.5.2.1.6.3，不同 DCF 模型怎么选见 5.5.3.3.6。
>
> 本体系的取舍与 5.5.2.1.6.3 相同：**非金融企业以企业 DCF 为主线**（5.5.3.3），股权法用于三种场合：金融机构；负债率长期稳定、受监管约束的公司；以及用目标负债比例简化式做交叉检验。两种方法算出的股权价值差距较大时，不要取平均数，先找出是哪个假设不一样，通常就在上表的五个来源里。

## 本节小结

| | DDM | FCFE 模型 | （对照）企业 DCF |
|---|---|---|---|
| 折现的现金流 | 实际股息（最好含回购） | 股东**能**拿到的现金 | 全体出资人的经营现金流 |
| 折现率 | 股权成本 | 股权成本 | WACC |
| 增长的来源 | 留存率 × ROE | 股权再投资率 × 非现金 ROE | 再投资率 × RONIC |
| 稳定期一致性 | 支付率 = $1 - g_n / \text{ROE}$ | 股权再投资率 = $g_n / \text{ROE}$ | 再投资率 = $g_n / \text{RONIC}$ |
| 最适合 | 金融机构；高分红、股息接近可分配现金的成熟公司 | 股息和可分配现金差得远的公司；负债率长期稳定的公司；交叉检验 | 非金融企业的主线，尤其负债率变化大时 |
| 最常见的坑 | 低分红公司的支付率不随增长放缓上调；忽略回购 | 稳定期再投资照搬高增长期或设为零 | 见 5.5.3.3 |

**三句话：**

1. 股权的价值最终来自分给股东的现金。DDM 数的是实际分了多少，FCFE 数的是本来能分多少，两者之差就是"谁决定分红"的价值。
2. 无论哪种形式，增长都不是免费的：增长率、支付率（或再投资率）和 ROE 必须同时成立。只有 ROE 高于股权成本，增长才增加价值。
3. 稳定期参数要"换挡"：支付率上升，再投资下降到 $g_n / \text{ROE}$，β 向 1 回归，增长率不超过经济增长。大多数离谱的估值结果，都出在终值的这几个参数上。
