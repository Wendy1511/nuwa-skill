到这里，你手里的工具已经太多了：股息模型、FCFE 模型、企业 DCF、经济利润模型、APV；PE、PB、PS、EV/EBITDA、PEG、每用户价值；清算价值、重置成本。同一家公司，用不同工具可以算出相差一倍的结果。

这时候最常见的两种做法都不对。一种是"挑一个我最熟的"：不管是银行还是创新药公司，一律两阶段 FCFF。另一种是"全都算一遍取平均"：DCF 20 元、PE 法 30 元、PB 法 12 元，平均 20.7 元，看上去很稳妥，其实这个数没有任何含义。

这一节回答三个问题：**先看什么决定用哪类方法；选定一类之后，具体用哪个模型、哪个倍数；最后几种方法的结论怎么放在一起。** 答案的核心可以先说出来：没有"最准确的模型"，只有**和这家公司、这次估值目的最匹配的模型**。最终的做法是选一个主模型承担内在价值判断，其他方法负责检验和托底。

## 5.5.5.1 先看公司和资产的特征

选方法的第一组问题是关于**被估的对象**的。四个特征最关键：资产能不能单独拿出来交易，现金流现在有没有、能不能预测，市场上有没有真正相似的公司，资本结构会不会大变。

先把结论放在一张表里，后面逐条解释：

| 特征 | 偏向 DCF（现金流折现） | 偏向相对估值 | 偏向资产法 |
|---|---|---|---|
| 可交易性 | 资产是一个整体、难以分拆出售 | 有活跃的同类资产市场价格 | 资产可以分开、单独卖，且有可靠的市场价 |
| 现金生成能力 | 现在或不久就有现金流（正负都行） | 资产本身不产生现金流 | 现金流和资产价值脱节（如停产、待处置） |
| 独特性 | 独一无二，找不到可比 | 一大群相似公司，差异小且能调整 | — |
| 资本结构 | 稳定 → 企业 DCF；剧变 → APV | 杠杆差异大 → 用企业价值倍数 | 杠杆高到可能违约 → 清算价值变重要 |

### 5.5.5.1.1 可交易性：有没有可靠市场价格和可比对象

"可交易性"问的是：这家公司的资产，能不能一块一块地拿出来，单独卖一个价？

一个极端是**资产可以分开交易**的公司。一家航运公司有十条船，每条船在二手船市场上都有成交价；一家持有物业出租的公司，每栋楼都可以单独出售；一家控股公司的主要资产是几家上市公司的股份，每一份都有收盘价。对这类公司，把各项资产按市价逐项加总、减去负债，就得到一个有经济含义的 NAV（资产净值）。用一个设想的航运公司算一下：

| 项目 | 金额（亿元） | 说明 |
|---|---|---|
| 10 条散货船 | 60 | 按近期同船型、同船龄的二手成交价，每条 6 亿 |
| 现金 | 8 | |
| 减：有息负债 | −30 | |
| 减：其他负债 | −3 | |
| **NAV** | **35** | |

如果这家公司的市值只有 25 亿元，你至少知道：把船全卖了，股东能拿回的比现在的市值多。这是资产法有用的典型场合。

另一个极端是**资产无法分开**的公司。一家消费品公司的价值主要来自品牌、渠道和管理能力，这些东西不能单独拿出来卖；就算能清楚地区分它的两条产品线，品牌价值也是同时嵌在两条线里的。这时资产法几乎无从下手：账面上的厂房设备只值很少一部分，真正值钱的东西不在资产负债表上（为什么账面价值不等于经济价值，见 5.5.1.3）。

高增长公司是同一个道理的延伸。它的价值大部分来自**还没有做出来的投资**，也就是未来的增长机会。增长机会没法打包卖给别人，所以高增长公司的清算价值或重置成本，和它的真实价值几乎没有关系。用 5.1.2.4 的三态来说：资产法估的是清算态，最多到持续经营态；成长态的价值，只有 DCF 能估。

"可交易性"还有第二层含义：**公司本身的股票有没有可靠的市场价格。** 非上市公司、长期停牌的股票、成交极其稀少的港股小盘股，它们的"市价"要么不存在，要么不可靠，用它们做可比公司，或者拿它们的价格去推隐含预期，都要打折扣。

### 5.5.5.1.2 现金生成能力：现金流当前是否为正、能否预测

按产生现金流的能力，资产可以分三组：

| 组别 | 例子 | 适合的方法 |
|---|---|---|
| 现在或不久就产生现金流 | 绝大多数上市公司，包括现金流暂时为负的年轻公司 | DCF |
| 现在没有，未来**在某种条件下**才产生 | 等待审批的新药、尚不可商用的技术、未开采的矿、未开发的土地 | 概率加权的 DCF / 决策树，辅以交易可比 |
| 不产生现金流 | 自住房、收藏品、艺术品 | 只能用相对估值 |

第一组里有一个常见误解：**现金流为负，不等于不能用 DCF。** 一家正在扩张期的新能源车企，或者一家还在亏损的生物科技平台公司，今天的现金流是负的，但只要你能讲清楚它什么时候、凭什么转正，就能折现。真正的问题不在正负，而在**能不能预测**。年轻公司怎么估，见 5.6.2.2。

第二组最需要小心。这类资产的价值取决于某个事件会不会发生：新药能不能获批，油价、矿价能不能涨到让开采划算。一个直接的办法是给事件设概率，把各种结果按概率加权。设想一家只有一个核心产品的创新药公司：

- 账上现金 8 亿元；
- 完成三期临床还要花 3 亿元（假设现在一次性投入）；
- 一年后出结果：获批概率 60%，获批后这个产品的 DCF 价值（在获批时点）为 50 亿元；失败则产品价值为零；
- 获批后的现金流已经按产品自身的风险折现过，这一年的等待按 10% 折一次。

$$
\text{价值} = 8 - 3 + \frac{60\% \times 50 + 40\% \times 0}{1.1} = 5 + 27.3 = 32.3 \text{ 亿元}
$$

这就是 5.5.2.5.4 决策树的最简形式。要注意两件事。第一，失败的风险已经通过 40% 的概率扣掉了，折现率里不要再加一层"失败风险溢价"，否则风险算了两遍。第二，这种做法有一个已知的缺陷：它没有算进"等一等、看情况再决定"的灵活性价值（比如油价不好时可以先不开采），所以对这类资产会**偏保守**。灵活性的另一种估法是期权定价，本体系不采用（立场第 14 条）；我们的处理方式是：承认这部分可能被低估，用情景分析把"情况好时加码、情况坏时止损"的决策写进各个情景，再用同类资产的交易价格（比如同阶段管线的授权交易对价、同类矿权的转让价）做旁证。

第三组在公司估值中很少遇到，但它说明了一个边界：**没有现金流的东西，DCF 无从谈起，价值只能来自"别人愿意出多少"**（5.6.4.2）。

### 5.5.5.1.3 独特性：是否存在真正相似的公司

市场上每天有几千只股票交易，几乎找不到完全没有参照物的公司。但"有参照物"和"有可比公司"是两回事。可以把公司排在一条线上：

- 一端是**一大群相似公司**中的一员，彼此差别不大，差别也容易调整。比如同一省份的几家区域性城商行、几家业务结构相近的高速公路公司。相对估值在这里最可靠。
- 另一端是**真正独一无二**的公司：拥有独家牌照、独特资源或者在细分行业里没有同类上市公司。比如香港唯一的证券交易所运营者港交所，全球虽有其他交易所上市公司，但监管环境、市场结构、与内地互联互通的业务都不同；又比如高端白酒里品牌力最强的那一家，同行虽多，没有一家的定价权、渠道打款模式和它真正相近。越靠近这一端，相对估值越不可靠，DCF 越有必要。

一个检验独特性的实用办法：**看可比组的倍数有多分散。** 设想目标公司下一年每股收益 1 元，你找到四家"同行业"公司，前瞻 PE（市盈率）分别是 12、18、25、45 倍。按它们估，每股价值从 12 元到 45 元，中位数 21.5 元。区间宽到这个程度，倍数已经不提供信息：要么这几家并不可比，要么目标公司本身就是独特的。这时候，与其在可比组里挑挑拣拣，不如承认相对估值只能做旁证，把主要精力放到 DCF 上。

反过来，也不要把"独特"当成拒绝一切比较的借口。即使没有业务相同的公司，你仍然可以拿**驱动因素**去比：它的利润率、ROIC（投入资本回报率）、增长在全市场同等规模的公司里排在什么位置？这些比较不直接给出价值，但能约束 DCF 里的假设（5.5.5.5.2）。

### 5.5.5.1.4 资本结构：未来是否大幅变化

资本结构影响三类方法的方式各不相同：

**对 DCF**：负债率大致稳定，用 WACC（加权平均资本成本）折现 FCFF（公司自由现金流）最省事；负债按金额和还款计划变化（杠杆收购、私有化、承诺降杠杆），用 APV（调整现值法）更自然。完整的选择逻辑在 5.5.3.3.6，5.5.5.3.4 只给判断规则。

**对相对估值**：股东口径的倍数（PE、PB 市净率、PS 市销率）会被杠杆扭曲。设想两家经营完全相同的公司，息税前利润都是 100，税率 25%，经营业务都值 1000（为了只看杠杆对倍数的影响，这里暂不考虑税盾带来的价值差异）：

| | 甲（无负债） | 乙（负债 500，利率 5%） |
|---|---|---|
| 利息 | 0 | 25 |
| 净利润 | $100 \times 75\% = 75$ | $(100 - 25) \times 75\% = 56.25$ |
| 股权价值 | 1000 | 500 |
| PE | $1000 / 75 = 13.3$ | $500 / 56.25 = 8.9$ |
| EV / 息税前利润 | 10 | 10 |

同一门生意，乙的 PE 比甲低三分之一，看起来"便宜"。其实乙的股东承担了更大的风险，低 PE 只是杠杆的结果。杠杆扭曲的方向还不固定：本例中甲的盈利收益率（PE 的倒数）$75/1000 = 7.5\%$，高于税后债务成本 $5\% \times 75\% = 3.75\%$，所以加杠杆压低了 PE；如果一家高 PE 公司的盈利收益率低于税后债务成本，加杠杆反而会抬高 PE。方向说不准，就没法在股权倍数上简单"修正"。可比组里各家公司杠杆差别大时，要换成企业价值倍数（5.5.4.2.4.2）。

**对资产法**：杠杆高到可能违约时，持续经营的假设本身就动摇了，清算价值从"参考"变成"可能的结局之一"。这时要把持续经营价值和清算价值按违约概率加权（5.6.2.3.4）。

> **投资者怎么用**：拿到一家公司，先花五分钟回答四个问题：它的资产能不能分开卖？现金流现在有没有、能不能预测？市场上有几家真正像它的公司？它的负债未来几年会大变吗？四个答案基本就决定了主模型是什么、哪种方法只能做旁证、哪种方法根本不该用。

## 5.5.5.2 再看分析者的目标和约束

同一家公司，不同的人来估，合适的方法也不同。这一点常被忽略：方法不只取决于公司，还取决于**你是谁、你为什么估、你怎么看市场**。

### 5.5.5.2.1 投资者时间跨度

几种方法隐含的时间观不同。DCF（现金流折现）把公司看成一直经营下去的实体，价值在很多年里逐步兑现；清算价值假设公司今天就停业；相对估值介于两者之间，它关心的是现在市场怎么给同类资产定价。

所以有一条朴素的规则：**持有期越长，越应该用 DCF；持有期越短，相对估值的权重越大。** 这也解释了为什么收购方（买下来就长期持有）几乎都做 DCF，而管理组合、频繁调仓的机构更多看倍数。

为什么时间跨度这么重要？因为 DCF 发现的价格偏差，**什么时候被市场纠正**你决定不了。设想你算出一只股票值 20 元，现价 15 元；你的估值是对的；假设公司不分红（或者你把分红全部再投回这只股票），股东的回报全部留在股价里，那么价值本身每年按 9% 的股权成本增长，市场在第 N 年把价格纠正到价值。你每年的回报是：

$$
r = \left( \frac{20 \times 1.09^N}{15} \right)^{1/N} - 1
$$

| 纠正需要的年数 N | 年化回报 | 超过 9% 股权成本的部分 |
|---|---|---|
| 1 | 45.3% | 36.3 个百分点 |
| 3 | 20.0% | 11.0 个百分点 |
| 5 | 15.5% | 6.5 个百分点 |
| 10 | 12.2% | 3.2 个百分点 |

同一个"低估 25%"的判断，一年兑现是一笔大生意，十年兑现每年只多赚 3 个百分点。（以 N = 5 为例复算：$1.09^5 = 1.539$，$20 \times 1.539 / 15 = 2.051$，开 5 次方得 1.155。）这张表有两层含义。对长期投资者，DCF 的结论是有意义的，因为你等得起；但你也要知道，低估幅度不大时，等待会吃掉大部分超额回报，这正是安全边际要求要和估值区间、确定性一起考虑的原因（5.7.4.5）。对短期投资者，DCF 的结论再正确也可能没用，他更需要知道"相对于同类，现在的价格是否偏离"，因为这种偏离通常纠正得更快。

### 5.5.5.2.2 实施估价的原因：投资·收购·公司金融

估值的三种主要用途（5.1.1.4）对方法的要求不同：

| 目的 | 要回答的问题 | 主要方法 | 补充 |
|---|---|---|---|
| 组合投资：行业研究员在同行中选股 | 这一组公司里谁最贵、谁最便宜 | 倍数 | 他的业绩也是和同行比，不必判断整个行业贵不贵 |
| 组合投资：为长期目标（如养老）积累财富的个人 | 这家公司本身值多少 | DCF | 倍数做检验 |
| 收购 | 独立价值、控制权价值、协同效应、最高可付价格 | DCF（按目标资本结构）；杠杆收购用 APV | 交易倍数看市场行情，不决定出价上限 |
| 公司金融（项目、融资、分红） | 某个决策让价值增加还是减少 | DCF / APV | — |

第一行和第二行的对比值得多想一下。一位只跟踪钢铁行业的卖方研究员，工作是从十几家钢铁股里挑出相对高估和低估的，他的建议也只会和其他钢铁研究员的建议比较；对他来说，倍数是最合适的工具，整个钢铁板块贵不贵不在他的考核范围里。而你作为个人投资者，买的不是"比别的钢铁股便宜"，而是这家公司未来的现金流。**你需要的是内在价值，不是相对排名。** 所以读券商研报时，要知道它回答的问题和你要回答的问题可能不一样。

估值目的还决定了一个容易被忽视的问题：**按现在的管理层估，还是按最优的管理层估？** 一家经营不善的公司，如果换一个管理层、砍掉亏损业务、卖掉闲置资产、调整资本结构，价值可能高得多。两种价值之差就是控制权的价值（完整内容见 5.7.2.4）。用哪一个，取决于你能不能、或者有多大可能促成改变：

- **打算收购并更换管理层的买方**：按最优管理估值。至于要不要为此付出溢价，取决于谈判地位和改善需要多久。
- **小额的少数股东**：你改变不了管理层。如果公司治理有效、控制权市场活跃，改善大概率会发生，可以给一部分改善价值；如果实际控制人地位稳固、几乎不可能被替换（A 股相当多公司属于这种情况，尤其是股权集中的国企和家族企业），就应该按现有管理层继续经营来估值。
- **有一定话语权的机构投资者**：介于两者之间，可以推动但不能决定变化。

把这个判断量化，可以用概率加权。设想按现状经营的每股价值 10 元，按最优方式经营 13 元，你判断三年内发生实质性改变（比如控股股东变更、引入有经验的战略投资者、国企改革落地）的概率是 20%。改变若在第三年发生，改善带来的 3 元要按 9% 的股权成本折三年。那么你愿意付的价值大约是 $10 + 20\% \times (13 - 10) / 1.09^3 = 10 + 0.46 = 10.46$ 元，而不是 13 元。很多"困境反转"的投资故事，错就错在把 13 元当成了价值，把一个小概率事件当成了确定的事。

### 5.5.5.2.3 对市场效率和市场价格信息含量的看法

每一种方法都隐含着一个关于市场的假设。用哪种方法，等于表明你相信市场在哪里会犯错：

| 方法 | 隐含的市场假设 | 你在押注什么 |
|---|---|---|
| DCF | 价格会偏离内在价值，偏差可能发生在单只股票、整个行业、甚至整个市场；但会随时间纠正 | 市场对这家公司未来现金流的判断错了 |
| 相对估值 | 市场整体上是对的，对整个行业、整个市场的定价公允；只是个别公司定价不当 | 这家公司相对同类的定价错了 |
| 资产法 | 实物资产市场和金融资产（股票）市场的定价会出现偏离，而且这种偏离可以利用 | 股价没有反映资产的市价 |

三者有一个共同前提：**市场最终会发现并纠正自己的错误。** 如果你认为市场永远不纠正，那么任何估值都没有用，因为你算出的价值永远不会变成你的回报。

这张表的实际用处是让你在用某种方法之前，先审视它的前提在当下成不成立：

- 用相对估值时问一句：**这个行业整体的定价可信吗？** 2015 年上半年的创业板、2021 年初的"核心资产"抱团，都是行业或风格整体被高估的时候。在那种环境里，"比同行便宜"没有多少意义（5.5.4.5.5.1）。
- 用资产法时问一句：**价格和资产价值之间的差距，靠什么收敛？** 港股有不少控股公司和地产公司长期以较大的折让于资产净值交易，A 股也有长期破净的银行和周期股。如果资产不会被出售、公司不会被收购、管理层不会回购或分派，折让可以持续很多年。没有收敛机制的低于资产价值，是"价值陷阱"的常见形式。
- 用 DCF 时问一句：**我和市场的分歧，能落到哪个具体假设上？** 如果说不出来，先怀疑自己（立场第 8 条；市场有效性的完整讨论见 5.7.1.4）。

> **投资者怎么用**：作为长期投资者，本体系以 DCF 为主模型，这对应的是"市场会在个股和行业层面犯错，但最终会纠正"的看法。但你仍然要知道市场怎么给同类公司定价，原因不是相信市场一定对，而是市场价格里含有你可能漏掉的信息。

## 5.5.5.3 选择恰当的 DCF 模型

决定以 DCF（现金流折现）为主模型之后，还有一串具体选择。顺序是：

```
先选现金流 → 再选盈利起点 → 再选增长模式 → 看资本结构定折现框架 → 金融机构单独处理
（股息/FCFE/FCFF） （当期/正常化）   （稳定/两阶段/三阶段/n阶段） （WACC 还是 APV）     （股权口径）
```

一个原则先说在前面：**让模型去适应公司，而不是让公司去适应模型。** 很多时间被浪费在把一家公司硬塞进某个"最好的模型"里：给一家利润为负的公司套稳定增长公式，给一家专利即将到期的药企套平滑衰减的三阶段模型。从来没有最好的模型，只有对这家公司合适的模型。

### 5.5.5.3.1 先选现金流：股息、FCFE 还是 FCFF

只要关于增长和杠杆的假设前后一致，先估公司再减债务（FCFF 即公司自由现金流路线）和直接估股权（FCFE 即股权自由现金流路线）应该得到同一个股权价值（条件见 5.5.3.2.7）。所以选哪条路线，是实际操作上的问题：

**负债率稳定的公司**：两条路线需要的数据基本一样，用你更顺手的一种。

**负债率会变的公司**（现在负债过高或过低，打算逐步调到目标水平）：FCFF 路线更方便。原因有两个：一是不用逐年预测利息和本金偿还；二是 WACC（加权平均资本成本）对负债率变化不那么敏感，而 $k_e$（股权成本）会随杠杆大幅变化，用 FCFE 路线时一旦负债率的路径写错，股权成本也跟着错。如果你习惯用"借多少钱、哪年还多少"来思考债务，而不是用负债率思考，就用 APV（调整现值法）。

**在股权口径内部，用股息还是 FCFE？** 默认用 FCFE（股权自由现金流），因为它衡量的是公司能付给股东多少，不受管理层"愿意付多少"的影响。只有两种情况应该考虑 DDM（股息贴现模型）：

1. **现金流估不准**：关于债务偿还和再投资的信息不全、互相矛盾，或者分不清哪些算债务。金融机构是典型（5.5.5.3.5）。
2. **股东拿不到股息以外的现金**：公司回购和其他返还方式受到严格限制，或者你无法判断管理层会怎么用留下的现金。这时你能从这笔投资里指望的现金，就只有管理层决定发的股息。

第二种情况在 A 股和港股并不罕见：账上常年躺着大量现金、分红率很低、又看不出投资计划的公司；或者存在大股东资金占用、关联交易输送利益风险的公司。对这类公司，FCFE 会高估你能拿到的东西。用一个极端的例子看差别有多大：设想某公司每年 FCFE 为 10 元，股权成本 10%，只发 4 元股息，留下的 6 元躺在账上，只能换来每年 2% 的税后利息收入，而且本金永远不会分给你。那么这 6 元在你手里的价值只有它带来的利息流的现值：$6 \times 2\% \div 10\% = 1.2$ 元，而不是 6 元。FCFE 模型会把每年的 6 元全算成你的；股息模型（加上利息带来的那一点股息增长）才接近你真正能拿到的。

> **投资者怎么用**：FCFE 估出的价值明显高于股息模型时，差距就是"公司能分但没分的现金"。问自己：这笔现金将来会以分红、回购或高回报投资的形式回到股东手里吗？如果答案是不确定，差距就要打折；如果答案是否定的，就以股息模型为准。

### 5.5.5.3.2 再选盈利起点：当期盈利还是标准化盈利

大多数估值从最近一年报告的盈利出发。但有些公司的当期盈利没法当起点：它为负，或者异常地高、异常地低（和公司自己的历史比明显反常）。这时可以用**标准化盈利**代替，也就是公司在正常状态下应该赚多少，通常参照公司历史或行业均值估算（为什么要正常化、报表上怎么剔除一次性项目，完整内容见 5.3.1.2.4；周期公司怎么跨周期正常化，见 5.6.2.1.2）。

关键的判断是：**盈利异常的原因是暂时的，还是持久的？** 只有暂时的才能正常化。

**可以正常化的情形**（前提是盈利能较快回到正常水平）：

- **周期性公司**：衰退期盈利低迷，繁荣期盈利高涨，两头都不代表真实的盈利能力。
- **有一次性大额支出**的公司：比如一笔诉讼赔偿、一次大额资产减值。
- **正在重组**的公司：为改善经营支付的裁员、关厂费用压低了当期盈利。

用一个设想的生猪养殖企业演示周期正常化：

| 年份 | 收入（亿元） | 净利率 | 净利润（亿元） |
|---|---|---|---|
| 1 | 100 | −8% | −8.0 |
| 2 | 110 | 4% | 4.4 |
| 3 | 125 | 20% | 25.0 |
| 4 | 140 | 9% | 12.6 |
| 5（最近一年） | 150 | −5% | −7.5 |

最近一年亏损 7.5 亿元，直接用它，公司没有价值；用第 3 年的高点 25 亿元，又会严重高估。跨周期正常化有两种算法：

- 平均净利润：$(-8 + 4.4 + 25 + 12.6 - 7.5) / 5 = 5.3$ 亿元；
- 平均净利率乘以当前收入：平均净利率 $(-8\% + 4\% + 20\% + 9\% - 5\%) / 5 = 4\%$，$150 \times 4\% = 6.0$ 亿元。

公司的规模在扩大，第二种算法更好：它用的是"一个周期的平均赚钱能力"乘以"今天的规模"，而平均净利润把小规模年份的利润也平均进来了，会低估。

**不能简单正常化的情形**：

- **长期问题**：经营、战略或财务上有持久性的毛病，比如技术被替代、行业需求永久性萎缩。设想一家传统产品的制造商，历史净利率 10%，被新技术替代后只剩 2%。如果你把它"正常化"回 10%，估值就是实际的约五倍。这时历史均值不是"正常"，而是"过去"。
- **杠杆极高、濒临违约**：持续经营本身存疑，价值应该按持续经营和违约清算两种结局加权（5.6.2.3.4）。
- **陷入困境但还不至于破产**：不要一步把利润率跳回正常水平，而是**让利润率逐年回升**。设想当前经营利润率 −5%，你判断四年后能恢复到行业正常的 6%，按直线回升，每年提高 $(6\% - (-5\%)) / 4 = 2.75$ 个百分点，四年依次是 −2.25%、0.5%、3.25%、6%。这四年的亏损和微利是真实的现金消耗，要算进价值里。
- **正在大规模建设的公司**：比如新建大型基础设施、新产能的公司，投资需要几年才能产生回报，期间盈利和现金流都为负，资本开支远大于折旧。这类公司要有价值，建设期结束后资本开支必须回落、利润率必须提升。模型里要显式写出"何时建完、建完后利润率多少"。
- **年轻公司**：处在把产品商业化的早期，亏损是常态。要假设收入高速增长、利润率逐步提高到成熟水平（5.6.2.2.4）。

| 盈利异常的原因 | 处理 |
|---|---|
| 周期、一次性支出、重组费用（暂时） | 用标准化盈利 |
| 技术替代、需求萎缩（持久） | 用当期水平或更低，不正常化 |
| 濒临违约 | 持续经营与清算按概率加权 |
| 困境但能修复 | 利润率逐年回升，不一步到位 |
| 大规模建设期、年轻公司 | 显式预测投资期和利润率爬坡 |

### 5.5.5.3.3 再选增长模式：稳定·两阶段·三阶段·逐步衰减

增长模式有四种选法：假设公司已进入稳定增长；高增长若干年后一步跳到稳定增长（两阶段）；中间加一个过渡期（三阶段）；或者从第一年起各参数就逐年变化（n 阶段）。每种形状的具体设定和"过渡时 RONIC（新增资本回报率）、再投资率要一起过渡"，见 5.5.2.2.3；增长率怎么衰减，见 5.4.1.7。这里只讲**怎么选**，看两件事。

**第一，看增长的势头。** 把公司最近几年的收入和盈利增长，和所在经济体的长期名义增长率比：

| 当前增长 | 选择 |
|---|---|
| 等于或低于经济的长期名义增长（甚至为负） | 稳定增长模型 |
| 略高于经济增长 | 两阶段：短暂的较高增长，然后稳定 |
| 远高于经济增长 | 三阶段或 n 阶段：需要一段过渡期慢慢降下来 |

参照的"经济增长率"要用你所在市场、你所用货币的长期名义增长。落到数字上，一个实用的锚是估值所用的无风险利率：稳定期增长率经验上不超过它（5.5.2.4.3.1）。比如按人民币估值、10 年期国债收益率在 2% 左右时，一家公司当前增长只有 2%~3%，基本就可以当作已进入稳定期；当前增长 15%，就属于"远高于"。

**第二，看增长的来源，它决定了衰减的形状。** 高增长来自两类优势：

- **法律或行政壁垒**：专利、特许经营权、牌照、收费权。这类优势在到期或被撤销时会**突然消失**，增长和回报在某个时点断崖式下降。适合两阶段模型，第二阶段一步跳下来。
- **一般性竞争优势**：品牌、规模带来的成本优势、渠道。这类优势随着竞争者进入**逐渐被侵蚀**，适合三阶段或逐步衰减的模型。

一般性竞争优势消失得多快，看三个因素：优势的性质（消费品牌可以维持很久，先发优势往往很快消失）、管理层的能力（好的管理层可以开拓新市场、找到新的优势来源，延缓衰减）、行业进入的难易（资本要求越高、技术门槛越高，优势流失越慢；竞争优势期的完整讨论见 5.2.2.1）。

用一个设想的药企看漏掉"专利到期会断崖"的后果。公司唯一的重磅药专利还剩 5 年，期间自由现金流从 10 亿元起每年增长 8%；第 6 年仿制药上市（在国内还可能叠加集采降价），自由现金流降到 5 亿元，此后每年增长 2%；折现率 9%。

前 5 年自由现金流为 10、10.8、11.66、12.60、13.60 亿元，现值合计 45.0 亿元（各年现值 9.17、9.09、9.01、8.92、8.84）。

| | 第 5 年末的终值 | 终值现值（÷ $1.09^5$ = 1.539） | 总价值 |
|---|---|---|---|
| 正确：按专利悬崖建模 | $5 / (9\% - 2\%) = 71.4$ | 46.4 | **91.5** |
| 错误：忽略专利到期，第 6 年起直接按 2% 增长 | $13.60 \times 1.02 / 7\% = 198.2$ | 128.8 | **173.9** |

只因为没看清"增长来自专利、到期会断崖"，估值几乎翻了一倍。A 股和港股里，同样性质的还有高速公路公司（收费权有经营期限，到期后不再收费，适合有限期限的模型，而不是永续增长）、依赖某一块牌照的公司（牌照到期续不续，是估值里最大的假设）。有法律保护期限的资产怎么估，见 5.6.4.1.3。

把两件事合起来：

| 增长势头 | 增长来源 | 建议的模型 |
|---|---|---|
| 稳定 | — | 稳定增长模型（Gordon 模型） |
| 略高 | 法律壁垒（到期确定） | 两阶段，期限 = 剩余保护期 |
| 略高 | 一般竞争优势 | 两阶段，期限按竞争优势期判断 |
| 很高 | 法律壁垒 | 高增长到保护期末，然后断崖到稳定 |
| 很高 | 一般竞争优势，进入壁垒高 | 三阶段，较长的过渡期 |
| 很高 | 一般竞争优势，进入壁垒低 | 三阶段或 n 阶段，较短的过渡期 |
| 很高、目前亏损 | — | n 阶段：逐年预测收入、利润率、再投资 |

### 5.5.5.3.4 资本结构稳定 → 企业 DCF；资本结构变化大 → APV

完整逻辑见 5.5.3.3.6.1–5.5.3.3.6.2，这里只留一个判断问题：**这家公司未来几年的债务，是按比例走，还是按金额走？**

- 按比例走：随业务增长借钱、维持大致稳定的负债率和信用评级。用 WACC 折现 FCFF 的企业 DCF，再用经济利润模型核对一遍。
- 按金额走：有明确的还款时间表、降杠杆承诺，或者是杠杆收购、私有化这类交易。用 APV，逐年算税盾，单独减困境成本。

（从不借钱的公司别套行业平均负债率，见 5.5.3.3.6.1 的提醒。）

### 5.5.5.3.5 金融机构 → 股权自由现金流/超额回报模型更自然

银行、保险公司的负债既是融资，也是它们的"原材料"，经营和融资分不开，"经营价值减债务"的企业口径失去了意义（为什么，见 5.5.3.3.6.3；完整的金融机构估值见 5.6.1.1）。可选的是三种股权口径的模型：

- **股息模型**：分红稳定、分红接近可分配现金时最自然。
- **FCFE 模型**：把满足监管资本要求所需的留存显式扣掉，剩下的才是股东可得现金。
- **超额回报模型**：股权价值 = 当前账面净资产 + 未来超额回报的现值，超额回报 = 净资产 ×（ROE − 股权成本）。

超额回报模型和 PB 的公式是同一件事。设想一家银行每股净资产 100 元，可持续 ROE（净资产收益率）12%，股权成本 10%，长期增长 4%，未来每年的超额回报按 4% 增长：

$$
\text{股权价值} = 100 + \frac{100 \times (12\% - 10\%)}{10\% - 4\%} = 100 + 33.3 = 133.3 \text{ 元}
$$

对应 PB（市净率）= 1.33，和 $\text{PB} = 1 + (\text{ROE} - k_e)/(k_e - g)$（5.5.4.3.1）算出的一样。这个模型对金融机构自然，是因为银行的资产主要是贷款、债券等金融资产，没有大量不入表的品牌、渠道之类无形资产，账面值和经济价值的差距通常比工商企业小，账面净资产可以当起点。但要注意，贷款和大部分持有到期的债券按摊余成本计量，不是按市价计量，账面净资产可信的前提是减值拨备计提充足。起点站住之后，它的价值几乎全部取决于"ROE 能否持续高于股权成本"这一个问题。

> **投资者怎么用**：DCF 模型的选择可以压缩成五个问题：股东能拿到股息以外的现金吗？当期盈利能代表正常水平吗？增长来自会到期的壁垒还是会被侵蚀的优势？债务按比例走还是按金额走？经营和融资能分开吗？五个答案定下来，模型就定下来了。

## 5.5.5.4 选择恰当的相对估价模型

决定用相对估值（不论是作为主模型还是作为检验），要回答两个问题：用哪个倍数？和谁比？

### 5.5.5.4.1 先确定要解释的是股权价值还是企业价值

倍数的分子决定了你在估什么。分子是股价或市值，估的是股权；分子是 EV（企业价值），估的是整个经营业务，之后还要减去净债务等才得到股权。规则只有一条：**分子和分母必须属于同一批出资人。** 股权价值配净利润、净资产（对应 PE 市盈率、PB 市净率）；企业价值配 EBITDA（息税折旧摊销前利润）、息税前利润、收入、投入资本。口径错配会造成系统性的偏差：比如用股权市值除以收入（PS，市销率），对高杠杆公司来说，收入是全部资本创造的，分子却只有股东那一部分，高杠杆公司的 PS 天然偏低（5.5.4.4.1.1）。

什么时候用哪种口径：

| 情形 | 口径 | 原因 |
|---|---|---|
| 可比公司杠杆相近 | 股权倍数（PE、PB、PS）也可以 | 杠杆的扭曲在各家之间大致抵消 |
| 可比公司杠杆差别大，或目标公司杠杆将大变 | 企业价值倍数（EV/EBITDA、EV/息税前利润、EV/收入） | 不受资本结构影响（见 5.5.5.1.4 的甲乙例子） |
| 银行、保险等金融机构 | 股权倍数（PB、PE） | 负债是经营的一部分，企业价值没有意义 |
| 持有大量现金、投资或少数股权的公司 | 企业价值倍数，并剔除非经营资产 | 否则非经营资产会扭曲倍数（5.5.4.5.1.4） |

### 5.5.5.4.2 选择与价值驱动因素最直接相关的分母

同一家公司，换一个倍数，估出来的价值就不一样。设想目标公司每股收益 1 元、每股净资产 8 元、每股收入 10 元，可比公司的中位数 PE 20 倍、PB 2 倍、PS 1.5 倍：

| 倍数 | 估出的每股价值 |
|---|---|
| PE 20 倍 × 1 元 | 20 元 |
| PB 2 倍 × 8 元 | 16 元 |
| PS 1.5 倍 × 10 元 | 15 元 |

面对这种分歧，有三种态度。

**各取所需。** 用最能支持自己观点的那个倍数：卖方报 20 元，买方报 15 元。这已经不是分析，而是在操纵数据，但它比你想象的普遍得多。防范的办法有两个：选倍数、选可比公司这两件事，自己要主动参与，不能全交给别人（交给谁，就是让谁定规则）；看到一个基于某倍数的结论时，总要问一句"换成别的倍数是多少"。

**烦琐论证。** 把十几种倍数全算一遍，然后取区间、取简单平均或加权平均。取区间的问题是区间往往太宽，无助于决策；取简单平均（上例是 17 元）等于给每个倍数相同的权重，可其中某个倍数可能明显更准；取加权平均，权重要么主观，要么用统计指标（如各倍数回归预测值的误差），前者容易回到"各取所需"，后者需要足够大的样本。

**最优乘数。** 找出最适合这家公司的那一个倍数，以它为主。这是本体系推荐的态度。找的方法有三种：

1. **基本面法**：选和价值关系最密切的那个变量做分母。消费品公司的当期盈利和价值高度相关，用 PE 有意义；年轻的科技公司当期盈利和价值几乎无关，PE 就没意义。银行的价值取决于净资产能赚多少超额回报，所以用 PB。
2. **统计法**：在一个行业里，把每个倍数分别对它的基本面驱动因素（增长、风险、ROE 净资产收益率或利润率等）做横截面回归，看哪个倍数被基本面解释得最好。衡量解释力的是 R²（决定系数）：它表示倍数在公司之间的差异中，有多大比例可以用这些驱动因素解释，0 表示完全解释不了，1 表示完全解释。R² 最高的倍数，就是这个行业里最"讲道理"的倍数。回归怎么做，见 5.5.4.3.2.2。
3. **惯例法**：某个行业用久了，会形成一个大家都用的倍数，比如分析银行用 PB。

最理想的情况是三种方法指向同一个倍数：和价值最相关的变量，回归的 R² 也最高，同时也是行业惯例。三者不一致时，惯例最不可靠（5.5.5.4.4）。

下面是 A 股、港股常见行业的主力倍数，作为起点而不是结论：

| 行业 | 常用倍数 | 理由 | 要小心的地方 |
|---|---|---|---|
| 银行 | PB（配合 ROE） | 资产以金融资产为主、表外无形资产少，账面净资产可作起点；价值取决于 ROE 与股权成本之差 | 贷款按摊余成本计量，净资产可信的前提是不良认足、拨备充足 |
| 保险 | P/EV（内含价值倍数）、PB | 保单未来利润不在当期利润里 | 内含价值依赖投资回报等精算假设 |
| 周期制造（钢铁、化工、养殖等） | 正常化 PE、周期低点看 PB | 当期盈利随周期大起大落 | 用错周期位置的盈利 |
| 消费品 | PE | 盈利稳定、和价值相关 | 增长差异大时要结合增长调整 |
| 高增长科技 | PEG、EV/收入 | 公司间增长差别太大，单看 PE 难以比较 | PEG 隐含风险和回报率相同 |
| 尚未盈利 | EV/收入、远期 PE | 当期利润为负 | 必须回答"成熟后利润率多少" |
| 基础设施、公用事业 | EV/EBITDA、股息率 | 早期亏损、折旧方法差异大 | 收费期限、管制回报的变化 |
| REITs（不动产投资信托） | P/FFO（营运现金流倍数）、分派率 | 折旧大，现金流比利润更有意义 | 剩余经营年限 |
| 零售 | PS（杠杆相近）、EV/收入（杠杆不同） | 利润率稳定时收入是好的规模代理 | 利润率差异大时失效 |

### 5.5.5.4.3 选择真正可比的公司或市场基准

可比公司怎么选，完整内容见 5.5.4.1.6。这里补充两个和"方法选择"直接相关的决定。

**第一，可比组定义得窄还是宽，取决于你打算怎么调整差异。** 打算凭判断逐一调整（"这家增长快一些，给 10% 溢价"），就要坚持窄定义：不仅同业务，规模和目标市场也相近，几家公司就够。打算用回归等统计方法调整，就可以用宽定义，样本越大越好，因为统计方法会自动控制增长、风险等差异。

**第二，和行业比，还是和整个市场比？** 和行业比回答"相对同行，它贵不贵"；和整个市场比回答"相对市场上所有公司，它贵不贵"。两者可以给出相反的结论。设想某行业中位数 PE 40 倍，全市场中位数 15 倍，目标公司 30 倍：相对行业它便宜了 25%，相对市场它贵了一倍。哪个结论对，取决于行业整体的定价是否合理，相对估值本身回答不了这个问题。

所以：如果你的任务只是在一个行业里挑股票（比如管理一个行业基金），用行业基准；如果你要在整个市场上找低估的股票，就要用市场基准，或者两者都看。作为个人投资者，你的钱可以投向任何行业，因此**至少要看一眼市场基准**，避免在一个整体高估的行业里买"最便宜的那一只"。

### 5.5.5.4.4 不能因为"行业惯例"就自动接受某个倍数

惯例倍数之所以成为惯例，是因为它在某个时期抓住了行业的价值驱动因素。但行业会变，惯例常常落后。当惯例倍数不再反映驱动因素时，按惯例估出的价值就会系统性出错，而且因为大家都这么用，这种错误很难被察觉。几个例子：

- **地产开发商的 P/NAV（资产净值倍数）**：NAV 依赖土地储备的估值和未来售价假设。行业下行时，土地和项目的可变现价值大幅下降，账面上的 NAV 还没跟上，"相对 NAV 打了五折"并不意味着便宜。
- **保险公司的 P/EV（股价 / 内含价值，此处 EV 指内含价值而非企业价值）**：内含价值依赖长期投资回报率等精算假设。近年不少险企下调了这些假设，内含价值随之调整；如果你只看倍数不看假设，就不知道分母本身变了多少。
- **周期股的 PE**：在景气顶点，周期股的 PE 往往最低，看起来最便宜；在景气底部，PE 很高甚至为负，看起来最贵。按惯例的 PE 在周期股上经常给出与正确方向相反的信号，所以才要用正常化 PE（5.5.5.3.2）。
- **互联网和平台公司的用户类指标**：每用户价值只有在用户能稳定转化为收入和利润时才有意义（5.5.4.4.2.2）。

检验一个惯例倍数，问三个问题：

| 问题 | 对应的价值驱动因素 |
|---|---|
| 这个倍数的分母，和行业今天的价值驱动因素还相关吗？ | ROIC / ROE、增长 |
| 分母本身的质量和口径变了吗（会计准则、精算假设、资产减值）？ | 口径 |
| 如果用基本面公式把这个倍数翻译回去，隐含的增长和回报率站得住吗？ | 增长、ROIC、风险 |

> **投资者怎么用**：看到"该股 PB 仅 0.5 倍，处于历史底部"这样的说法，先问：历史上的 PB 对应的 ROE 是多少，现在的 ROE 是多少？净资产里有多少需要打折？倍数在历史底部，可能是因为价格错了，也可能是因为分母和驱动因素都已经变了。

## 5.5.5.5 最终不是挑一个"最准确模型"，而是建立主模型 + 交叉验证

前面四个小节讲的是怎么选。这一小节讲选完以后怎么用。三类方法的分工在 5.5.1.4 已经定下：DCF（现金流折现）回答"经营基本面本身值多少"，相对估值回答"市场怎样给类似基本面定价"，资产法回答"底层资产能支撑多少价值"。本体系的立场是：**DCF 负责解释，倍数负责检验，资产法负责托底**（立场第 7 条）。下面讲每一层具体怎么做。

### 5.5.5.5.1 主模型承担核心内在价值判断

主模型是你把对公司的全部判断写进去的地方：增长多快、持续多久、回报率多高、风险多大。它必须满足两个条件：**你的关键判断在模型里是显式的变量**，以及**结果变化时你能说出是哪个判断变了**。

按前面四个小节的判断，常见公司类型的搭配大致如下：

| 公司类型 | 主模型 | 交叉验证 | 托底 / 特殊校验 |
|---|---|---|---|
| 成熟、资本结构稳定的工商企业 | 企业 DCF + 经济利润 | 前瞻 PE、EV/EBITDA | 一般不需要 |
| 周期性公司 | 正常化盈利的 DCF | 正常化 PE、周期低点的 PB | 重置成本、清算价值 |
| 高增长、尚未盈利 | n 阶段 DCF，配情景和生存概率 | EV/收入、远期倍数 | 现金余额与烧钱速度 |
| 银行、保险 | 超额回报模型 / FCFE / 股息 | PB-ROE、P/EV | 净资产质量 |
| 资产可分拆交易（控股、航运、持有型物业、资源） | DCF 或 NAV（看价值主要来自经营还是资产） | 同类资产交易价 | NAV、清算价值 |
| 杠杆将大幅变化（重组、私有化） | APV | EV/EBITDA | 违约情景下的清算价值 |
| 多业务集团 | 分部 DCF 加总（5.6.3.1） | 各分部的可比倍数 | — |

即使你把 DCF 作为主模型，也可以在 DCF 内部借用相对估值的长处，同时保持它不受市场情绪左右：

- **折现率**：用市场当前的隐含股权风险溢价（5.5.2.3.4.3），而不是历史平均值。这样你的估值是"在当前的市场风险定价下，这家公司值多少"，你的观点只集中在公司本身，而不夹带对整个市场贵贱的判断。反过来，如果你想对整个市场的定价表达观点，就要清楚自己在做的是这件事。
- **长期假设**：用可比公司成熟后的利润率、ROIC（投入资本回报率）、资本周转率作为目标公司稳定期的锚。

反过来，以相对估值为主的人也可以借用 DCF 的严谨性：在比较公司时，把增长、风险、ROE 这些基本面差异显式地调整进去，而不是只看倍数的高低（5.5.4.5.2）。

### 5.5.5.5.2 相对估值检验市场定价和预测合理性

具体的检验步骤（把 DCF（现金流折现）结果换算成隐含倍数、和可比中位数对比、把差距拆到假设上、先检查自己）见 5.5.4.1.7；DCF 各环节分别用哪个倍数检验，见 5.5.4.5.6。这里补充一个更上层的工具：**把 DCF 和相对估值的结论放进一张四格表。**

| | 相对估值：低估 | 相对估值：高估 |
|---|---|---|
| **DCF：低估** | 两种方法都说便宜。最理想的买入情形 | 整个行业被低估了，这家公司只是行业里相对贵的 |
| **DCF：高估** | 整个行业被高估了，这家公司只是行业里相对便宜的 | 两种方法都说贵 |

右上和左下两格最有信息量，它们说的其实是**行业整体的定价偏离了基本面**。一个经典的例子是 2000 年的亚马逊。2000 年 3 月，有人用 DCF 估算它每股约 30 美元，而股价约 70 美元，DCF 说明它被高估；但和当时其他电子商务公司相比，它的定价又是偏低的。这是"DCF 高估、相对低估"，背后是整个互联网板块的泡沫。到 2001 年 2 月底，亚马逊股价跌到约 15 美元，而其他互联网公司普遍下跌了近 90%。2001 年 3 月再做 DCF，结论是它被低估，相对估值却说它比同行贵，变成了"DCF 低估、相对高估"，背后是整个板块被过度抛售。

对长期投资者来说，这张表的用法是：

- **左上格**（两种都便宜）：你能同时从两种纠正中获益，一是市场随时间对这家公司的重新定价（DCF 的赚钱逻辑），二是公司之间相对定价的回归。
- **左下格**（DCF 贵、相对便宜）：不要因为"比同行便宜"就买，你买的是一个整体高估的板块里最不贵的那一只。
- **右上格**（DCF 便宜、相对贵）：可以买，但要准备好长时间等待，因为市场对整个行业的纠正可能比个股更慢；同时要再三确认，是行业真的被错杀，还是你的 DCF 漏掉了行业层面的坏消息。

### 5.5.5.5.3 资产价值提供底线或特殊情形的校验

资产法在大多数持续经营的公司里不是主模型，但它在三种场合有用。

**第一，提供底线。** 公司经营得再差，股东至少能拿到资产变现后偿还全部负债的剩余，前提是清算真的可能发生。设想一家经营困难的制造企业，市值 30 亿元，你按变现折扣估算清算价值：

| 项目 | 账面值（亿元） | 变现比例 | 变现值（亿元） |
|---|---|---|---|
| 现金 | 20 | 100% | 20.0 |
| 应收账款 | 15 | 70% | 10.5 |
| 存货 | 10 | 50% | 5.0 |
| 厂房设备 | 40 | 30% | 12.0 |
| 减：全部负债 | | | −25.0 |
| 减：清算费用（遣散、税费等） | | | −2.0 |
| **清算价值** | | | **20.5** |

市值 30 亿元，清算底线 20.5 亿元，最坏情况下的下跌空间约 32%（$1 - 20.5/30$）。这个"底线"有两个前提：一是有人能、也愿意启动清算或资产出售（"要有人能兑现"的一般说法见 5.5.1.4.3；在 A 股，这往往取决于实际控制人）；二是公司不会在此之前把现金烧掉。一家每年亏掉 5 亿元现金的公司，底线每年下降 5 亿元。

**第二，校验 DCF 的上限。** 用重置成本检查：DCF（现金流折现）价值超出重置成本的部分，就是你在为超额回报付的钱（5.5.1.4.3）。如果你的 DCF 价值远高于重新建一套同样产能的成本，就等于假设没有人会进来建新产能、分走超额回报。设想一家水泥企业 DCF 估值 120 亿元，重建同等产能需要 80 亿元，隐含的市值与重置成本之比约 1.5（托宾 Q 的思路，见 5.5.4.3.5）。这要求一个能阻止新进入者的理由。在国内水泥行业，产能置换等政策限制了新增产能，这可以是理由之一；如果你说不出这样的理由，DCF 里的高 ROIC（投入资本回报率）假设就需要更快地衰减。

**第三，资产本身就是价值主体的公司。** 控股公司、持有型物业公司、资源公司、航运公司，价值主要来自可分拆、有市价的资产，NAV（资产净值）可以和 DCF 并列，甚至作为主模型。即使如此，也要回答 5.5.5.2.3 那个问题：价格和资产价值之间的差距靠什么收敛。

### 5.5.5.5.4 不同模型分歧很大时，先找假设差异，不要机械求平均

回到本节开头的例子：DCF（现金流折现）20 元、PE（市盈率）法 30 元、PB（市净率）法 12 元。为什么不能取平均（20.7 元），对"方法"加权和对"情景"加权有什么区别，5.5.1.4.4 已经讲过：平均数没有经济含义，还会把错误摊薄，而不是把它找出来。这里不再重复，只演示用本节的工具把三个数各自放回原位。

做法仍然是**把每个结果翻译成同一种语言（隐含的增长、回报率和风险），再找分歧来自哪里**。设想目标公司下一年每股收益 1 元，每股净资产 6.67 元（ROE 即净资产收益率 15%），股权成本 9%。

**PE 法为什么是 30 元？** 可比公司前瞻 PE 30 倍，ROE 也在 15% 左右。套用 5.5.1.4.4 和 5.5.4.1.7 反推隐含增长的做法（稳定增长的 PE 公式见 5.5.4.2.1.3.2），30 倍隐含的永续增长率约 7.3%；你的 DCF 结果 20 元相当于前瞻 PE 20 倍，隐含约 6.0%。

*复算：令 $(1 - g/15\%)/(9\% - g) = 30$，解得 $g = 1.7 / 23.33 \approx 7.3\%$；把 30 换成 20，$g = 0.8 / 13.33 = 6.0\%$。*

这里的 6% 是把你包含高增长期和稳定期的整条路径压缩成的一个等效永续增长率，所以比你在 DCF 里设的稳定期增长率高。两者的分歧集中在"这组公司的长期增长有多高"这一个问题上。7.3% 的永续增长远高于站得住的长期名义增长（5.5.2.4.3.1），更可能是可比组整体被高估了。把这个结论接到 5.5.5.5.2 的四格表上：如果现价落在 20 元和 30 元之间，就是"DCF 贵、相对便宜"那一格，你买到的会是一个整体偏贵的板块里不那么贵的一只。

**PB 法为什么是 12 元？** 可比公司 PB 1.8 倍（$12 \div 6.67$），但它们的 ROE 平均只有 10% 左右，而目标公司是 15%。PB 的伴侣变量是 ROE（5.5.4.3.1），ROE 不同的公司不能直接套用同一个 PB。这个 12 元不是一个估值，而是一个可比性错误。

把 PB 用对，就是按目标公司自己的 ROE 重算。用 5.5.5.3.5 用过的 PB 公式，代入 DCF 的等效增长 6%：

$$
\text{PB} = 1 + \frac{\text{ROE} - k_e}{k_e - g} = 1 + \frac{15\% - 9\%}{9\% - 6\%} = 3.0 \text{ 倍}, \qquad 3.0 \times 6.67 \approx 20 \text{ 元}
$$

正好回到 DCF 的结果。反过来，用同一公式看可比组：ROE 10%、PB 1.8 倍，令 $1 + (10\% - 9\%)/(9\% - g) = 1.8$，解得 $9\% - g = 1.25\%$，$g = 7.75\%$。可比组的 PB 同样隐含了很高的永续增长，和 PE 法得到的 7.3% 指向同一件事：这组公司的定价偏高。

翻译完，结论就清楚了：DCF 是主结论；PE 法提示整个可比组可能偏贵，这一点值得记进投资备忘录，它意味着如果市场情绪回落，这家公司的价格也可能受到拖累；PB 法的 12 元应该剔除，按 ROE 修正后它回到 20 元，只起核对作用。没有一步需要求平均。

> **另一种看法**：也有人主张对多种方法的结果做加权平均，权重按各方法的精确程度来定，比如按回归预测的标准误差，误差越小权重越大，并认为这比主观挑一个更客观。本体系不采用这种做法作为结论，原因是：加权平均隐含的前提是，各种方法都在估**同一个东西**，只是各自带着独立的噪声；但 DCF 和相对估值估的本来就不是同一个东西，它们的差距往往是有信息的（比如揭示行业整体高估），平均会把这个信息抹掉。如果你确实想要一个综合数字，比如在同一类相对估值的几个倍数之间，加权平均可以接受，但前提仍然是先把每个结果的假设翻译出来、剔除有错误的那些。

最后，分歧本身值得记下来。你今天判断"可比组被高估、所以相对估值偏高"，一年后回头看，如果事实证明可比组的增长确实站得住，那么错的是你的 DCF 增长假设，这正是复盘时要区分的"业务判断错"（立场第 16 条，5.7.4.7）。

> **投资者怎么用**：几种方法的结果摆在面前时，不要问"哪个最准"或"平均是多少"，而要问"它们各自假设了什么，我同意哪一个，为什么"。能回答这个问题，你就有了投资逻辑；回答不了，说明你还没有理解这家公司，这时候最好的决策通常是不买。

## 本节小结

```
                           拿到一家公司
                                │
   ┌────────────────────────────┼────────────────────────────┐
 公司特征（5.5.5.1）                                  你的目标与约束（5.5.5.2）
 可交易性 · 现金流 · 独特性 · 资本结构                 时间跨度 · 估值目的 · 对市场的看法
   └────────────────────────────┬────────────────────────────┘
                                │
                    选主模型（通常是 DCF）
                                │
   DCF 内部（5.5.5.3）：现金流 → 盈利起点 → 增长模式 → WACC/APV → 金融机构用股权口径
                                │
   相对估值（5.5.5.4）：股权/企业口径 → 最优分母 → 窄/宽可比、行业/市场基准 → 检验惯例
                                │
   主模型 + 交叉验证（5.5.5.5）：DCF 解释 · 倍数检验（四格表）· 资产托底 / 校验上限
                                │
             分歧 → 翻译成隐含增长、回报率、风险 → 找出差异 → 不求平均
```

**四句话**：

1. 方法由两组因素决定：公司的特征（资产能否分拆交易、现金流能否预测、有无真正可比、资本结构是否会变），以及你自己的目标（持有多久、为什么估、相信市场在哪里犯错）。
2. DCF 内部按顺序选：股东能拿到股息以外的现金才用 FCFE；只有暂时性的异常才能正常化盈利；增长来自会到期的壁垒还是会被侵蚀的优势，决定衰减是断崖还是渐进；债务按比例走用企业 DCF，按金额走用 APV；金融机构用股权口径。
3. 相对估值先定口径（分子分母同属一批出资人），再找与价值驱动因素最相关的那个倍数，不各取所需，不全算一遍取平均；行业惯例倍数要翻译回驱动因素再接受；个人投资者至少要看一眼市场基准。
4. 最后是一个主模型加交叉验证：DCF 负责解释，倍数负责检验，资产法负责托底。两种方法结论相反时，往往说明行业整体定价偏离了基本面；结果分歧时，翻译成隐含假设去找原因，而不是求平均。

**选方法的问题清单**：

| 问题 | 对应的价值驱动因素 |
|---|---|
| 公司的价值主要来自现有资产还是未来增长？资产能不能单独卖？ | 增长、投入资本 |
| 现金流现在有没有？什么时候、凭什么转正？ | 自由现金流、ROIC |
| 当期盈利是暂时异常还是持久变化？ | 利润率、ROIC |
| 高增长来自会到期的壁垒，还是会被侵蚀的竞争优势？ | 增长、竞争优势期 |
| 债务未来按比例走还是按金额走？ | WACC、税盾 |
| 股东能拿到股息以外的现金吗？ | 自由现金流的分配 |
| 选的倍数和这个行业的价值驱动因素相关吗？可比组的定价本身合理吗？ | ROIC / ROE、增长、风险 |
| 我是按现有管理层还是按改善后的管理层在估？改善的概率有多大？ | 全部 |
| 我能等多久？低估幅度够不够补偿等待？ | 资本成本、安全边际 |
