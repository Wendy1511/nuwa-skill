# 文风与写作规则

> 定位：**讲义式正文**。读起来像一位懂行的人在给你讲课，不是百科条目，也不是要点堆砌。
> 风格以样章 [`content/5.2-价值怎么创造/5.2.1-价值创造的基本原理.md`](../content/5.2-价值怎么创造/5.2.1-价值创造的基本原理.md) 为准。规则和样章冲突时，以样章为准。

## 一、硬规则（审校会逐条检查）

1. **不重复主讲。** 写之前先查 [concepts.md](concepts.md)：概念的主讲位置不在本节，就只写一句"（见 5.x.x）"，接着写本节的新问题。
2. **每节开头有一个"本节定位"块**，内容固定为下面三行，其余部分不设固定结构：
   ```
   > **本节新教**：…（与台账一致）
   > **调用前文**：…（附编号）
   > **在估值流程中的位置**：5.1.1.5 的第 X 步
   ```
3. **标出处到章**：`［麦 3］`、`［达 11.4］`；属于自己的整合标 `［自］`。书中的数字例子可以复述，但要标明出处。
4. **直接引用原文不超过两句**，其余一律用自己的话转述。
5. **术语和符号以 concepts.md 第一节为准**；书里的叫法不同时，第一次出现注明一次即可。
6. **麦和达有分歧，或者说法不同时，要摆出来**，不能悄悄选一个。用"两本书怎么说"小段落呈现，然后写本体系的取舍（依据 [stance.md](stance.md)）。
7. **不写期权估值**（见 stance 第14条）。
8. **贯穿案例**：从 5.3 开始，每节至少有一处落到贯穿案例公司上，用 `〔案例：公司名〕` 标出。5.1 和 5.2 是原理章，用书中例子或自造的简单数字即可。

## 二、写法跟着节点类型走（不套模板）

| 节点类型 | 典型节点 | 写法 |
|---|---|---|
| 原理 | 5.2.1、5.2.2 | 先给一个反直觉的问题或小例子，再推出原理；公式放在直觉之后 |
| 口径 / 计算 | 5.3.2、5.5.2.1 | 先讲为什么要这样调整，再讲怎么算；配一张从报表到指标的推导表 |
| 方法 / 步骤 | 5.4.2、5.5.3 | 按步骤写，每一步说明输入、输出和最容易出错的地方 |
| 辨析 | 5.5.1.4、5.5.5 | 用对比表，再给判断规则 |
| 实证 / 证据 | 5.2.2.7、5.7.1.5 | 说明证据是什么、结论是什么、对投资者的启示是什么，三者分开写 |
| 投资者视角 / 清单 | 〔投资者视角〕、5.7.4 | 写成可以直接拿来用的问题清单，每个问题注明对应的价值驱动因素 |

## 三、语气

- 用"你"跟读者说话，可以设问，但不要每段都设问。
- 少用"总之""综上所述""值得注意的是""非常重要"。真重要的话，用例子证明，不靠形容词。
- 段落优先，列表只用于真正并列的条目。一节里连续三个以上的列表，说明写成了笔记，需要改回段落。
- 中文数字和单位：百分比用 `%`，金额写清币种；公式中的变量用英文符号。

## 四、长度

- 一个三级节点（如 5.2.1）通常 5000–12000 字，按信息量来，不凑字数。
- 只有标题、没有子节点的四级节点，可以只写一两段。
