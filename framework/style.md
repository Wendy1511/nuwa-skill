# 文风与写作规则

> 定位：**讲义式正文**。读起来像一位懂行的人在给你讲课，不是百科条目，也不是要点堆砌。
> 风格以样章 [`content/5.2-价值怎么创造/5.2.1-价值创造的基本原理.md`](../content/5.2-价值怎么创造/5.2.1-价值创造的基本原理.md) 为准。规则和样章冲突时，以样章为准。

## 〇、读者是谁（最重要）

**读者熟悉价值投资的理念，但实操细节只是入门水平。** 他听说过 ROIC、WACC、DCF，但不一定知道 WACC 的 10% 是怎么来的、投入资本里到底算哪些科目、永续增长公式为什么长这样。

所以：
- **每个第一次用到的工具都要讲清"它是什么、从哪里来、为什么这样算"**，用一个能手算的小例子讲。不能写"WACC 是资本的价格"就跳过去。
- 某个概念的完整主讲位置在后面章节时，本节仍要给出**够用的直觉版**（一两段加一个小例子），再说明完整内容在哪一节。直觉版和主讲版的区别在深度：直觉版讲"是什么、为什么"，主讲版讲"怎么估、有哪些坑、各种方法怎么选"。
- **宽度**：一个原理要列出常见的表现形式。比如"金融工程不创造价值"，就要把回购、送转、加杠杆、永续债、并购增厚 EPS 等常见手法都列出来。
- **详略由你判断**：最常见、最容易被误导的展开讲，配例子和数字；次要的点到即止，一两句话说清楚即可。

## 一、硬规则（审校会逐条检查）

1. **不重复主讲。** 写之前先查 [concepts.md](concepts.md)。主讲位置不在本节的概念，只给直觉版（见上），并注明"完整内容见 5.x.x"。
2. **每节开头有一个"本节定位"块**，内容固定为下面三行，其余部分不设固定结构：
   ```
   > **本节新教**：…（与台账一致）
   > **调用前文**：…（附编号）
   > **在估值流程中的位置**：5.1.1.5 的第 X 步
   ```
3. **正文不标书籍出处**（不写［麦 3］［达 11］这类标记），也不写"某本书里叫什么""两本书怎么说"。需要呈现不同观点时，直接写成"另一种看法""补充一个角度"。
   出处只写在文末的 HTML 注释里（渲染时不显示），供审校核对：
   ```
   <!-- 出处备查
   5.2.1.1：麦3（Fred 案例）
   …
   -->
   ```
4. **英文缩写在正文里出现时，后面加括号写中文**，如 WACC（加权平均资本成本）。规则：每个四级小节（`## 5.x.x.x`）里第一次出现时加注；同一小节后面再出现可以不加。公式和表格里不加。每节开头放一个"术语速查"小表。
5. **术语和符号以 concepts.md 第一节为准。**
6. **不写期权估值**（见 stance 第14条）。
7. **数字要能复算。** 书中的数字例子必须核对原文；自己构造的例子要写清假设。

## 二、例子

- 优先用 **A股、港股**的公司和现象（高送转、永续债、加盟模式、预收款、商誉减值潮等）。
- 真实公司只用**广为人知、可以核实的定性事实**（比如商业模式、某类公司行为）。**不要编造真实公司的财务数字**；需要数字时，要么核对过公开财报，要么改用"设想一家……"的构造例子，并明确说是设想。
- 例子可多可少，但必须贴合要讲的那一点。不需要固定一家贯穿全书的公司，按需要挑选最合适的。
- 书里的经典例子（比如价值公司和数量公司）可以保留，不标出处。

## 三、写法跟着节点类型走（不套模板）

| 节点类型 | 典型节点 | 写法 |
|---|---|---|
| 原理 | 5.2.1、5.2.2 | 先给一个反直觉的问题或小例子，再推出原理；公式放在直觉之后，公式里每个符号都要解释 |
| 口径 / 计算 | 5.3.2、5.5.2.1 | 先讲为什么要这样调整，再讲怎么算；配一张从报表到指标的推导表 |
| 方法 / 步骤 | 5.4.2、5.5.3 | 按步骤写，每一步说明输入、输出和最容易出错的地方 |
| 辨析 | 5.5.1.4、5.5.5 | 用对比表，再给判断规则 |
| 实证 / 证据 | 5.2.2.7、5.7.1.5 | 说明证据是什么、结论是什么、对投资者的启示是什么，三者分开写 |
| 清单 | 〔投资者视角〕、5.7.4 | 写成可以直接拿来用的问题清单，每个问题注明对应的价值驱动因素 |

## 四、语气

- 用"你"跟读者说话，可以设问，但不要每段都设问。
- 少用"总之""综上所述""值得注意的是""非常重要"。真重要的话，用例子证明，不靠形容词。
- 段落优先，列表只用于真正并列的条目。连续三个以上的列表，说明写成了笔记，需要改回段落或表格。
- 百分比用 `%`，金额写清币种；公式中的变量用英文符号。

## 五、长度

- 一个三级节点（如 5.2.1）通常 10000–25000 字，按信息量来，不凑字数。
- 只有标题、没有子节点的四级节点，可以只写一两段。
